# Задание 10 — Навигация: структура экранов и маршруты

## Контекст

Продолжаем разработку **CineTrack**. Сейчас все переходы сделаны через `Navigator.push` прямо в местах вызова, а поиск спрятан за кнопкой в `AppBar`. В этом задании вы выстроите полноценную навигационную структуру приложения: `BottomNavigationBar` с тремя вкладками, именованные маршруты и передачу данных между экранами в обе стороны.

## Задачи

### 1. Создать `MainScreen` с `BottomNavigationBar`

Создайте файл `lib/screens/main_screen.dart`. Этот экран будет корневым для всей навигации:

```dart
class MainScreen extends StatefulWidget {
  const MainScreen({super.key});

  @override
  State<MainScreen> createState() => _MainScreenState();
}

class _MainScreenState extends State<MainScreen> {
  int _currentIndex = 0;

  final List<Widget> _screens = [
    const HomeScreen(),
    const SearchScreen(),
    const FavoritesScreen(),
  ];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: _screens[_currentIndex],
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _currentIndex,
        onTap: (index) => setState(() => _currentIndex = index),
        items: const [
          BottomNavigationBarItem(icon: Icon(Icons.home), label: 'Главная'),
          BottomNavigationBarItem(icon: Icon(Icons.search), label: 'Поиск'),
          BottomNavigationBarItem(icon: Icon(Icons.favorite), label: 'Избранное'),
        ],
      ),
    );
  }
}
```

`BottomNavigationBar` — панель вкладок внизу экрана: `currentIndex` задаёт активную вкладку, а `onTap` сообщает, какую вкладку выбрал пользователь. Каждый экран вкладки сохраняет свой собственный `Scaffold` с `AppBar` — вложенные `Scaffold` здесь допустимы.

### 3. Настроить именованные маршруты

В `main.dart` замените `home: const HomeScreen()` на таблицу маршрутов. Свойство `home` нужно **удалить**: если одновременно задать `home` и маршрут `'/'`, Flutter завершится с ошибкой.

```dart
MaterialApp(
  title: 'CineTrack',
  theme: ThemeData(fontFamily: 'Nunito'),
  initialRoute: '/',
  routes: {
    '/': (context) => const MainScreen(),
    '/movie-detail': (context) => const MovieDetailScreen(),
    '/add-movie': (context) => const AddMovieScreen(),

```

Переведите кнопку добавления фильма на `HomeScreen` на именованный маршрут:

```dart
final movie = await Navigator.pushNamed<Movie>(context, '/add-movie');
```

Остальной код обработчика из Задания 9 не меняется.

### 4. Передача данных на `MovieDetailScreen` через `arguments`

Измените `MovieDetailScreen` так, чтобы он получал фильм не через конструктор, а через `ModalRoute.of(context)!.settings.arguments`:

```dart
class MovieDetailScreen extends StatelessWidget {
  const MovieDetailScreen({super.key});

  @override
  Widget build(BuildContext context) {
    final movie = ModalRoute.of(context)!.settings.arguments as Movie;
    // используйте movie для отображения — разметка из Задания 8 не меняется
  }
}
```

Переход на экран деталей теперь выглядит так — замените им `Navigator.push` из Задания 8 на `HomeScreen` и добавьте такой же `onTap` карточкам на `SearchScreen`:

```dart
Navigator.pushNamed(
  context,
  '/movie-detail',
  arguments: movie,
);
```

### 5. Передача данных обратно: личная оценка

На экране `MovieDetailScreen` добавьте кнопку «Оценить». По нажатию — диалоговое окно с полем ввода числа от 1 до 10. После подтверждения — возврат оценки на предыдущий экран.

Создайте диалог в `lib/widgets/rating_dialog.dart`: `StatefulWidget`, который возвращает `AlertDialog` с `TextField` (`keyboardType: TextInputType.number`) и двумя кнопками. «Отмена» закрывает диалог через `Navigator.pop(context)`, «Сохранить» — через `Navigator.pop(context, value)`, где `value` — введённое число типа `double` (если введено не число от 1 до 10, не закрывайте диалог).

```dart
// В MovieDetailScreen, в обработчике кнопки «Оценить»
final rating = await showDialog<double>(
  context: context,
  builder: (_) => const RatingDialog(),
);
if (rating != null && context.mounted) {
  Navigator.pop(context, rating); // возвращаем оценку на предыдущий экран
}
```

На `HomeScreen` храните личные оценки в состоянии экрана — в словаре «id фильма → оценка»:

```dart
// в _HomeScreenState
final Map<int, double> _userRatings = {};

// при переходе на экран деталей
final rating = await Navigator.pushNamed<double>(
  context,
  '/movie-detail',
  arguments: movie,
);
if (rating == null || !mounted) return;

setState(() => _userRatings[movie.id] = rating);
ScaffoldMessenger.of(context).showSnackBar(
  SnackBar(content: Text('Ваша оценка «${movie.title}»: $rating')),
);
```

Пока оценки живут только в памяти и пропадают при перезапуске приложения.
