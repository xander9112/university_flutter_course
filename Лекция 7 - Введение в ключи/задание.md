# Задание 7 — Ключи: управление списком фильмов

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы добавите интерактивность в список фильмов: возможность удалять карточки и перемешивать список. Именно здесь ключи (`Key`) становятся критически важны для корректной работы фреймворка.

---

## Задачи

### 1. Добавить `ValueKey` к карточкам в списке

В `HomeScreen` при построении `ListView` передайте `ValueKey` с уникальным идентификатором каждого фильма — полем `id`:

```dart
ListView.builder(
  itemCount: _movies.length,
  findChildIndexCallback: (key) {
    final index = _movies.indexWhere((m) => ValueKey(m.id) == key);
    return index == -1 ? null : index;
  },
  itemBuilder: (context, index) {
    final movie = _movies[index];
    return MovieCard(
      key: ValueKey(movie.id),
      movie: movie,
    );
  },
)
```

**Зачем:** без `ValueKey` Flutter не сможет корректно сопоставить виджеты с данными при изменении порядка в списке.

**Зачем `findChildIndexCallback`:** `ListView.builder` строит элементы лениво, по индексу, и сам не знает, на какой индекс переехал элемент с данным ключом. Колбэк подсказывает ему это: по ключу возвращает новый индекс фильма (или `null`, если фильма больше нет). Без колбэка ключ лишь не даст перепутать состояния разных фильмов, но при перестановке элемент будет пересоздан и его состояние сбросится. У `ListView(children: [...])` такой проблемы нет — он находит элементы по ключам сам.

### 2. Добавить кнопку «Перемешать»

Добавьте в `AppBar` кнопку `IconButton` с иконкой `Icons.shuffle`. По нажатию список фильмов перемешивается:

```dart
actions: [
  IconButton(
    icon: const Icon(Icons.shuffle),
    onPressed: () {
      setState(() {
        _movies.shuffle();
      });
    },
  ),
],
```

Запустите приложение и убедитесь, что при нажатии порядок карточек меняется.

### 3. Добавить удаление через `Dismissible`

Оберните каждый `MovieCard` в виджет `Dismissible`, чтобы пользователь мог смахнуть фильм влево для удаления. Теперь корнем элемента списка становится `Dismissible`, поэтому `ValueKey` переносится на него, а у `MovieCard` ключ больше не нужен:

```dart
Dismissible(
  key: ValueKey(movie.id),
  direction: DismissDirection.endToStart,
  background: Container(
    color: Colors.red,
    alignment: Alignment.centerRight,
    padding: const EdgeInsets.only(right: 16),
    child: const Icon(Icons.delete, color: Colors.white),
  ),
  onDismissed: (direction) {
    setState(() {
      _movies.removeAt(index);
    });
  },
  child: MovieCard(movie: movie),
)
```

### 4. Эксперимент: убедиться в важности ключей

Для эксперимента временно переделайте `MovieCard` в `StatefulWidget` и добавьте ему внутреннее состояние — например, цвет фона, который меняется при тапе. Отметьте тапом пару карточек и нажмите «Перемешать». Сравните два варианта элемента списка:

- **без ключа** — временно уберите `Dismissible` (у него `key` обязателен) и возвращайте из `itemBuilder` просто `MovieCard(movie: movie)`: состояние «прилипает» к позиции в списке, а не к фильму
- **с `ValueKey(movie.id)` и `findChildIndexCallback`** — состояние следует за конкретным фильмом
- **с `ValueKey(movie.id)`, но без `findChildIndexCallback`** — отметки после перемешивания пропадают: ключ не даёт отдать состояние чужому фильму, но список не может найти переехавший элемент и создаёт его заново

После эксперимента верните `Dismissible` с ключом. `MovieCard` можно снова сделать `StatelessWidget`.

## Критерии выполнения

- [ ] Каждый элемент списка (корневой виджет, возвращаемый из `itemBuilder`, — `Dismissible`) имеет уникальный `ValueKey(movie.id)`
- [ ] У `ListView.builder` задан `findChildIndexCallback`, возвращающий индекс фильма по ключу
- [ ] Кнопка «Перемешать» меняет порядок карточек
- [ ] Карточки удаляются свайпом влево с красным фоном и иконкой корзины
