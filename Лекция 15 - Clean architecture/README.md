# Лекция 15 - Clean architecture

Тема лекции — принципы чистой архитектуры (Clean Architecture) и их применение при построении Flutter-приложения.

В лекции рассматриваются основные принципы чистой архитектуры (независимость от фреймворка, UI и источников данных, тестируемость) и принципы SOLID, лежащие в её основе. Приложение разбирается по трём слоям — Presentation, Domain и Data: на примере приложения-счётчика показывается, как в слое Domain описываются бизнес-правила через UseCase, в слое Data реализуется доступ к данным, а слой Presentation отвечает за построение UI и его логику.
