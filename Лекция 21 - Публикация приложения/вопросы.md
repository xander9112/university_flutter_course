# Вопросы — Лекция 21: Публикация Flutter-приложения

1. В чём главное практическое отличие AAB (App Bundle) от APK?

   a) AAB работает только на новых версиях Android, APK — на всех
   b) APK подходит для Google Play, AAB — только для прямой установки
   c) ✓ AAB загружается в Google Play, который сам генерирует оптимальный APK под каждое устройство; APK используется для прямой установки
   d) AAB меньше весит на диске устройства, APK — при загрузке из магазина

2. Для чего нужен файл keystore при публикации Android-приложения?

   a) Для хранения API-ключей и токенов в зашифрованном виде
   b) Для настройки ProGuard и обфускации кода
   c) ✓ Для цифровой подписи приложения, подтверждающей, что все обновления выпущены одним и тем же разработчиком
   d) Для регистрации приложения в Google Play Console

3. Что означает версия `2.4.1+37` в `pubspec.yaml`?

   a) Версия Flutter SDK, major.minor и build number
   b) ✓ Semantic version `2.4.1` (major.minor.patch) и build number `37`; пользователи видят `2.4.1`, магазин использует `37` для сравнения сборок
   c) Дата сборки: 2-е число, 4-й месяц, 1-й год, 37-я минута
   d) Версия Dart SDK, которая требуется для запуска приложения

4. Что делает флаг `--obfuscate` при сборке релиза?

   a) Удаляет все комментарии и логи из кода
   b) Сжимает ресурсы (изображения, шрифты) для уменьшения размера APK
   c) Шифрует данные приложения на устройстве пользователя
   d) ✓ Переименовывает классы и методы в бессмысленные имена, чтобы затруднить декомпиляцию и анализ кода

5. Сколько стоит подписка Apple Developer Program?

   a) Бесплатно для студентов и некоммерческих проектов
   b) 25$ — единоразовый платёж, как и Google Play
   c) ✓ 99$ в год
   d) 299$ в год для юридических лиц

6. Сколько обычно занимает проверка приложения в App Store при первой публикации?

   a) Несколько минут — автоматическая проверка
   b) ✓ 1-3 рабочих дня (иногда дольше при первой публикации)
   c) Ровно 7 дней — фиксированный срок
   d) До 30 дней — длительная ручная проверка

7. Для чего нужен пакет `flutter_launcher_icons`?

   a) Для создания анимированных иконок на экране загрузки
   b) Для добавления значка приложения в системный трей на десктопе
   c) ✓ Для автоматической генерации иконок всех необходимых размеров под Android, iOS и другие платформы из одного исходного файла 1024×1024
   d) Для добавления иконок в интерфейс приложения из сторонних библиотек

8. Что даёт подключение Firebase Crashlytics к приложению?

   a) Автоматическое исправление крэшей без участия разработчика
   b) Защиту приложения от крэшей через обработку всех исключений
   c) Аналитику использования экранов и кнопок в приложении
   d) ✓ Автоматический сбор отчётов о крэшах с контекстом (стектрейс, устройство, действия пользователя), что позволяет находить и исправлять ошибки в продакшне
