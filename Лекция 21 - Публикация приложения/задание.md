# Задание 21 — Публикация: финальная сборка CineTrack

Это финальное задание курса. Подготавливаем CineTrack к реальному релизу.

---

## Задача 1. Установить финальную версию

Откройте `pubspec.yaml` и установите версию:

```yaml
name: cinetrack
description: Приложение для отслеживания фильмов

version: 1.0.0+1
#        ↑       ↑
#     semver  build number

environment:
  sdk: '>=3.0.0 <4.0.0'
```

---

## Задача 2. Настроить иконку приложения

1. Создайте или возьмите любое изображение 1024×1024 PNG (логотип, постер, символ плёнки).
2. Поместите его в `assets/icon/icon.png`.
3. Добавьте в `pubspec.yaml`:

```yaml
dev_dependencies:
  flutter_launcher_icons: ^0.14.0

flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/icon/icon.png"
  min_sdk_android: 21
  web:
    generate: true
    image_path: "assets/icon/icon.png"
```

4. Сгенерируйте иконки:

```bash
flutter pub get
flutter pub run flutter_launcher_icons
```

Убедитесь, что иконка обновилась в симуляторе.

---

## Задача 3. Настроить сплэш-экран

1. Подготовьте логотип для сплэш-экрана (рекомендуемый размер: 200×200 PNG).
2. Поместите в `assets/images/splash_logo.png`.
3. Добавьте в `pubspec.yaml`:

```yaml
dev_dependencies:
  flutter_native_splash: ^2.4.0

flutter_native_splash:
  color: "#1a1a2e"
  image: assets/images/splash_logo.png
  android_12:
    image: assets/images/splash_logo.png
    color: "#1a1a2e"
  fullscreen: true
```

4. Сгенерируйте сплэш:

```bash
flutter pub run flutter_native_splash:create
```

5. Обновите `main.dart`:

```dart
import 'package:flutter_native_splash/flutter_native_splash.dart';

void main() async {
  WidgetsBinding widgetsBinding = WidgetsFlutterBinding.ensureInitialized();
  FlutterNativeSplash.preserve(widgetsBinding: widgetsBinding);

  await configureDependencies();

  FlutterNativeSplash.remove();
  runApp(const CineTrackApp());
}
```

## Задача 4. Сгенерировать keystore и настроить подписание

**Шаг 4.1.** Сгенерируйте keystore (выполнить один раз):

```bash
keytool -genkey -v \
  -keystore ~/cinetrack-release.jks \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -alias cinetrack-key
```

Команда попросит:
- Пароль для keystore и для ключа (запомните их!)
- Имя, организацию, город, страну

**Шаг 4.2.** Создайте файл `android/key.properties` (не коммитить в Git!):

```properties
storePassword=ваш_пароль_keystore
keyPassword=ваш_пароль_ключа
keyAlias=cinetrack-key
storeFile=/Users/ВашеИмя/cinetrack-release.jks
```

**Шаг 4.3.** Добавьте в `.gitignore`:

```
*.jks
android/key.properties
```

**Шаг 4.4.** Обновите `android/app/build.gradle` — добавьте чтение `key.properties` и `signingConfigs`:

```groovy
def keystoreProperties = new Properties()
def keystorePropertiesFile = rootProject.file('key.properties')
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}

android {
    // ... существующие настройки ...

    signingConfigs {
        release {
            keyAlias keystoreProperties['keyAlias']
            keyPassword keystoreProperties['keyPassword']
            storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
            storePassword keystoreProperties['storePassword']
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true
            shrinkResources true
        }
    }
}
```

## Задача 5. Собрать подписанный релизный AAB

```bash
flutter build appbundle \
  --release \
  --obfuscate \
  --split-debug-info=build/debug-info/android
```

Если сборка прошла успешно, файл будет находиться по пути:

```
build/app/outputs/bundle/release/app-release.aab
```

Сохраните папку `build/debug-info/` — она понадобится для расшифровки стектрейсов из Crashlytics.

## Задача 6. Проверить сборку на устройстве

Соберите APK для проверки на реальном устройстве или эмуляторе:

```bash
flutter build apk --release
```

Установите APK:

```bash
# Через adb
adb install build/app/outputs/flutter-apk/app-release.apk

# Или скопируйте файл на устройство и установите вручную
```

Пройдите полный пользовательский сценарий:

1. Откройте приложение — проверьте сплэш-экран и иконку
2. Дождитесь загрузки списка популярных фильмов
3. Найдите фильм через поиск
4. Откройте детальную страницу фильма
5. Добавьте фильм в избранное
6. Перейдите на вкладку «Избранное» — фильм должен быть там
7. Отключите интернет — убедитесь, что данные из кэша отображаются
8. Снова включите интернет — убедитесь, что данные обновляются
