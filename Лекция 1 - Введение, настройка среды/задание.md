# Задание 1 — Создание проекта CineTrack

## Контекст

На протяжении всего курса вы будете разрабатывать приложение **CineTrack** — персональный трекер фильмов. К финальной лекции приложение будет уметь:

- показывать популярные фильмы из открытого API
- искать фильмы по названию
- добавлять в избранное и ставить личную оценку
- сохранять данные локально для работы офлайн
- быть покрытым тестами и выстроенным по Clean Architecture

В этом задании вы создаёте фундамент проекта.

---

## Задачи

### 1. Создание проекта

Создайте Flutter-проект командой:

```bash
flutter create cine_track
```

Откройте проект в VS Code и убедитесь, что он запускается на эмуляторе:

```bash
flutter run
```

### 2. Изучение структуры

Откройте папку проекта и ответьте письменно (в файле `notes.md` внутри папки с заданием или в комментарии) на следующие вопросы:

- За что отвечает директория `lib/`?
- Что описывает файл `pubspec.yaml`?
- Зачем нужны директории `android/` и `ios/`?
- Что происходит в папке `build/` при запуске проекта?

### 3. Настройка pubspec.yaml

Откройте `pubspec.yaml` и заполните мета-информацию о приложении:

```yaml
name: cine_track
description: Персональный трекер фильмов
version: 1.0.0+1
```

### 4. Очистка стартового кода

Удалите содержимое файла `lib/main.dart` и напишите минимальный запускаемый вариант:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      title: 'CineTrack',
      home: Scaffold(
        body: Center(
          child: Text('CineTrack — скоро здесь будут фильмы'),
        ),
      ),
    );
  }
}
```

Запустите приложение и убедитесь, что текст отображается по центру экрана.

### 5. Проверка flutter doctor

Выполните команду:

```bash
flutter doctor
```

Убедитесь, что нет критических ошибок (красных строк). Устраните замечания, если они есть.
