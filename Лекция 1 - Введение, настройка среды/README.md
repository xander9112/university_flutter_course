# Лекция 1 - Введение, настройка среды

Тема лекции — знакомство с Flutter и настройка окружения для разработки.

В лекции описывается установка Flutter SDK, Android Studio и настройка Android-эмулятора, а также установка и настройка VS Code для работы с проектом. Рассматривается создание нового Flutter-проекта, структура папок стандартного приложения и режимы Hot Reload и Hot Restart для быстрой разработки.
