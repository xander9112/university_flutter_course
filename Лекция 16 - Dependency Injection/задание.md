# Задание 16 — Dependency Injection: подключение GetIt к CineTrack

Берём проект CineTrack из Лекции 15 (Clean Architecture) и подключаем GetIt + Injectable, чтобы убрать ручное создание зависимостей.

## Задача 2. Создать injection.dart и вызвать configureDependencies() в main()

Создайте файл `lib/core/di/injection.dart`:

```dart
import 'package:get_it/get_it.dart';
import 'package:injectable/injectable.dart';
import 'injection.config.dart'; // будет сгенерирован

final sl = GetIt.instance;

@InjectableInit(
  initializerName: 'init',
  preferRelativeImports: true,
  asExtension: true,
)
Future<void> configureDependencies() async => sl.init();
```

Обновите `lib/main.dart`:

```dart
import 'core/di/injection.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await configureDependencies(); // регистрируем все зависимости до runApp
  runApp(const CineTrackApp());
}
```

## Задача 3. Зарегистрировать Dio через @module

Создайте файл `lib/core/di/app_module.dart`:

```dart
import 'package:dio/dio.dart';
import 'package:injectable/injectable.dart';

@module
abstract class AppModule {
  @lazySingleton
  Dio get dio => Dio()
    ..options.baseUrl = 'https://api.themoviedb.org/3'
    ..options.connectTimeout = const Duration(seconds: 15)
    ..options.receiveTimeout = const Duration(seconds: 15)
    ..options.headers = {
      'Authorization': 'Bearer YOUR_API_TOKEN',
      'Content-Type': 'application/json',
    }
    ..interceptors.add(LogInterceptor(
      requestBody: true,
      responseBody: true,
    ));
}
```

## Задача 8. Зарегистрировать MoviesBloc

```dart
// lib/features/movies/presentation/bloc/movies_bloc.dart
@injectable  // factory: новый экземпляр при каждом BlocProvider
class MoviesBloc extends Bloc<MoviesEvent, MoviesState> {
  MoviesBloc(
    this._getPopularMovies,
    this._searchMovies,
  ) : super(const MoviesInitial()) {
    on<LoadPopularMovies>(_onLoadPopularMovies);
    on<SearchMoviesRequested>(_onSearchMovies);
  }

  final GetPopularMovies _getPopularMovies;
  final SearchMovies _searchMovies;

  Future<void> _onLoadPopularMovies(
    LoadPopularMovies event,
    Emitter<MoviesState> emit,
  ) async {
    emit(const MoviesLoading());
    final result = await _getPopularMovies(page: event.page);
    result.fold(
      (failure) => emit(MoviesError(failure.message)),
      (movies) => emit(MoviesLoaded(movies: movies)),
    );
  }
}
```

## Задача 9. Заменить ручное создание BLoC на sl<MoviesBloc>()

До (было):

```dart
// main.dart или HomeScreen
BlocProvider(
  create: (_) => MoviesBloc(
    getPopularMovies: GetPopularMovies(
      MovieRepositoryImpl(
        remoteDataSource: MovieRemoteDataSourceImpl(
          Dio()..options.baseUrl = '...',
        ),
        localDataSource: MovieLocalDataSourceImpl(),
      ),
    ),
    searchMovies: SearchMovies(/* ... */),
  ),
  child: HomeScreen(),
)
```

После (стало):

```dart
// main.dart
import 'core/di/injection.dart';

MultiBlocProvider(
  providers: [
    BlocProvider(create: (_) => sl<MoviesBloc>()),
    BlocProvider(create: (_) => sl<FavoritesBloc>()),
  ],
  child: const MainScreen(),
)
```

## Задача 10. Запустить build_runner и проверить работу

```bash
# Генерируем injection.config.dart
flutter pub run build_runner build --delete-conflicting-outputs
```

После генерации в `lib/core/di/` появится файл `injection.config.dart`. Убедитесь, что он содержит все ваши классы.

Запустите приложение:

```bash
flutter run
```

Проверьте:
- Приложение запускается без ошибок
- Список фильмов загружается
- Поиск работает
- Избранное сохраняется
