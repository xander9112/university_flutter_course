# Лекция 16 - Dependency Injection

Тема лекции — внедрение зависимостей во Flutter-приложениях с помощью паттерна Service Locator и пакетов get_it и injectable.

Рассматриваются проблемы жёсткой связанности кода без DI, реализация Service Locator вручную, а затем работа с пакетом get_it: способы регистрации зависимостей (singleton, lazySingleton, factory), порядок регистрации и получение зависимостей из контейнера. Отдельное внимание уделяется пакету injectable, который через аннотации и кодогенерацию автоматизирует регистрацию классов в get_it, а также интеграции DI в Clean Architecture на примере полноценной цепочки слоёв фичи и особенностям тестирования кода, построенного на DI.
