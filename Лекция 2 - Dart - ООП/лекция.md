# Лекция 2 — Dart: объектно-ориентированное программирование

---

## 1. Зачем ООП

Объектно-ориентированное программирование (ООП) — это подход к написанию кода, при котором программа представляется как набор **объектов**, взаимодействующих друг с другом.

### Основные причины использовать ООП

**Структурирование кода.** Вместо тысяч разрозненных функций и переменных код организуется в логические блоки — классы. Каждый класс отвечает за свою область ответственности.

**Переиспользование.** Написанный однажды класс можно использовать в разных частях приложения и в разных проектах.

**Моделирование реального мира.** Приложение работает с реальными сущностями: пользователь, товар, заказ, фильм. ООП позволяет напрямую отображать эти сущности в код.

```dart
// Без ООП — разрозненные данные
String movieTitle = 'Inception';
int movieYear = 2010;
double movieRating = 8.8;

// С ООП — всё собрано в одном месте
class Movie {
  String title;
  int year;
  double rating;
}
```

## 2. Классы и объекты

### Объявление класса

Класс объявляется ключевым словом `class`. Внутри класса описываются **поля** (данные) и **методы** (поведение).

```dart
class Movie {
  // Поля (fields)
  String title;
  int year;
  double rating;

  // Метод
  void describe() {
    print('$title ($year) — рейтинг: $rating');
  }
}
```

### Создание объекта

Объект создаётся вызовом конструктора. В Dart ключевое слово `new` **необязательно** — его можно опустить.

```dart
void main() {
  // Оба варианта работают
  var movie1 = new Movie(); // устаревший стиль
  var movie2 = Movie();     // современный стиль Dart
}
```

### Конструктор по умолчанию

Если конструктор не объявлен явно, Dart создаёт пустой конструктор автоматически. Но обычно удобнее объявить свой:

```dart
class Movie {
  String title;
  int year;
  double rating;

  // Явный конструктор
  Movie(String title, int year, double rating) {
    this.title = title;
    this.year = year;
    this.rating = rating;
  }
}

void main() {
  var movie = Movie('Inception', 2010, 8.8);
  print(movie.title); // Inception
}
```

### Инициализирующие параметры (`this.field`)

Dart предоставляет сокращённый синтаксис — вместо присваивания вручную через `this` поля инициализируются прямо в сигнатуре конструктора:

```dart
class Movie {
  String title;
  int year;
  double rating;

  // Сокращённая запись — эквивалентна примеру выше
  Movie(this.title, this.year, this.rating);
}

void main() {
  var movie = Movie('The Matrix', 1999, 8.7);
  print(movie.year); // 1999
}
```

### Именованные конструкторы

Dart позволяет объявлять несколько конструкторов с разными именами. Это удобно, когда объект можно создать разными способами:

```dart
class Movie {
  String title;
  int year;
  double rating;

  Movie(this.title, this.year, this.rating);

  // Именованный конструктор — только по названию
  Movie.fromTitle(this.title)
      : year = 0,
        rating = 0.0;

  // Именованный конструктор — из Map
  Movie.fromMap(Map<String, dynamic> map)
      : title = map['title'],
        year = map['year'],
        rating = map['rating'].toDouble();
}

void main() {
  var m1 = Movie('Interstellar', 2014, 8.6);
  var m2 = Movie.fromTitle('Unknown Movie');
  var m3 = Movie.fromMap({'title': 'Dune', 'year': 2021, 'rating': 7.9});

  print(m2.title);  // Unknown Movie
  print(m2.rating); // 0.0
  print(m3.title);  // Dune
}
```

### `const` конструктор

Если объект неизменяем (все поля `final`) и значения известны на этапе компиляции, можно использовать `const` конструктор. Такие объекты создаются один раз и кешируются.

```dart
class Point {
  final double x;
  final double y;

  const Point(this.x, this.y);
}

void main() {
  const p1 = Point(0, 0);
  const p2 = Point(0, 0);

  print(identical(p1, p2)); // true — один и тот же объект в памяти
}
```

### `this` keyword

`this` ссылается на текущий объект. Используется для разрешения конфликта имён между полями и параметрами, а также для цепочки вызовов:

```dart
class Builder {
  String name = '';
  int value = 0;

  Builder setName(String name) {
    this.name = name; // this.name — поле, name — параметр
    return this;      // возвращаем сам объект для цепочки
  }

  Builder setValue(int value) {
    this.value = value;
    return this;
  }

  void build() => print('$name: $value');
}

void main() {
  Builder().setName('Test').setValue(42).build(); // Test: 42
}
```

## 3. Геттеры и сеттеры

### Синтаксис `get` и `set`

Геттеры и сеттеры позволяют контролировать доступ к полям класса. Внешне они выглядят как обычные свойства, но внутри выполняют код.

```dart
class Temperature {
  double _celsius; // приватное поле (начинается с _)

  Temperature(this._celsius);

  // Геттер
  double get celsius => _celsius;

  // Сеттер с валидацией
  set celsius(double value) {
    if (value < -273.15) {
      throw ArgumentError('Температура не может быть ниже абсолютного нуля');
    }
    _celsius = value;
  }

  // Вычисляемое свойство
  double get fahrenheit => _celsius * 9 / 5 + 32;
}

void main() {
  var temp = Temperature(100);
  print(temp.fahrenheit); // 212.0

  temp.celsius = 0;
  print(temp.fahrenheit); // 32.0

  // temp.celsius = -300; // выбросит исключение
}
```

### Вычисляемые свойства

Геттеры особенно полезны для свойств, которые вычисляются на основе других полей:

```dart
class Person {
  String firstName;
  String lastName;
  int birthYear;

  Person(this.firstName, this.lastName, this.birthYear);

  // Вычисляемое полное имя
  String get fullName => '$firstName $lastName';

  // Вычисляемый возраст
  int get age => DateTime.now().year - birthYear;
}

void main() {
  var person = Person('Иван', 'Петров', 1995);
  print(person.fullName); // Иван Петров
  print(person.age);      // зависит от текущего года
}
```

## 4. Наследование

### `extends`

Наследование позволяет создать новый класс на основе существующего. Дочерний класс получает все поля и методы родителя и может добавлять свои.

```dart
class Animal {
  String name;

  Animal(this.name);

  void speak() {
    print('$name издаёт звук');
  }

  void eat() {
    print('$name ест');
  }
}

class Dog extends Animal {
  String breed;

  Dog(String name, this.breed) : super(name); // вызов конструктора родителя

  @override
  void speak() {
    print('$name лает: Гав!');
  }

  void fetch() {
    print('$name приносит мяч');
  }
}

class Cat extends Animal {
  Cat(String name) : super(name);

  @override
  void speak() {
    print('$name мяукает: Мяу!');
  }
}

void main() {
  var dog = Dog('Рекс', 'Лабрадор');
  var cat = Cat('Мурка');

  dog.speak(); // Рекс лает: Гав!
  dog.eat();   // Рекс ест (унаследован от Animal)
  dog.fetch(); // Рекс приносит мяч

  cat.speak(); // Мурка мяукает: Мяу!
}
```

### `@override` — переопределение методов

Аннотация `@override` говорит Dart (и разработчикам), что мы намеренно переопределяем метод родителя. Если такого метода у родителя нет — компилятор выдаст предупреждение.

### `super` — вызов родительского метода

`super` позволяет обратиться к родительскому конструктору или методу:

```dart
class Animal {
  String name;
  Animal(this.name);

  void describe() {
    print('Животное: $name');
  }
}

class Dog extends Animal {
  String breed;

  Dog(String name, this.breed) : super(name);

  @override
  void describe() {
    super.describe();            // сначала вызываем родительский метод
    print('Порода: $breed');     // затем добавляем своё
  }
}

void main() {
  Dog('Рекс', 'Хаски').describe();
  // Животное: Рекс
  // Порода: Хаски
}
```

## 5. Абстрактные классы

### `abstract class`

Абстрактный класс — это класс, который нельзя создать напрямую. Он служит шаблоном для других классов, описывая **интерфейс** (набор методов), которые обязаны реализовать наследники.

```dart
abstract class Shape {
  // Абстрактный метод — нет тела, только сигнатура
  double area();
  double perimeter();

  // Обычный метод — есть реализация
  void describe() {
    print('Фигура с площадью ${area().toStringAsFixed(2)}');
  }
}

class Circle extends Shape {
  double radius;

  Circle(this.radius);

  @override
  double area() => 3.14159 * radius * radius;

  @override
  double perimeter() => 2 * 3.14159 * radius;
}

class Rectangle extends Shape {
  double width;
  double height;

  Rectangle(this.width, this.height);

  @override
  double area() => width * height;

  @override
  double perimeter() => 2 * (width + height);
}

void main() {
  // var s = Shape(); // ОШИБКА: нельзя создать экземпляр абстрактного класса

  var circle = Circle(5);
  var rect = Rectangle(4, 6);

  circle.describe();    // Фигура с площадью 78.54
  rect.describe();      // Фигура с площадью 24.00
}
```

## 6. Интерфейсы

### В Dart каждый класс — неявный интерфейс

В отличие от Java, в Dart нет ключевого слова `interface`. Вместо этого **любой класс** автоматически является интерфейсом. При использовании `implements` необходимо реализовать **все** публичные методы и свойства класса.

```dart
class Flyable {
  void fly() => print('Лечу!');
  void land() => print('Приземляюсь!');
}

class Swimmable {
  void swim() => print('Плыву!');
}

// Реализация нескольких интерфейсов
class Duck implements Flyable, Swimmable {
  @override
  void fly() => print('Утка летит');

  @override
  void land() => print('Утка приземляется');

  @override
  void swim() => print('Утка плывёт');
}
```

### `extends` vs `implements` vs `with`

| Ключевое слово | Что делает | Наследует реализацию? | Сколько раз? |
|---|---|---|---|
| `extends` | Наследование класса | Да | Один раз |
| `implements` | Реализация интерфейса | Нет (всё нужно написать самому) | Много раз |
| `with` | Подключение mixin | Да | Много раз |

```dart
class Animal {
  void breathe() => print('Дышу');
}

abstract class Swimmer {
  void swim();
}

mixin HasLegs {
  void walk() => print('Иду на лапах');
}

class Dog extends Animal implements Swimmer with HasLegs {
  @override
  void swim() => print('Собака плывёт');
}

void main() {
  var dog = Dog();
  dog.breathe(); // из Animal (extends)
  dog.swim();    // реализован сам (implements)
  dog.walk();    // из HasLegs (with)
}
```

## 7. Mixins

### Объявление mixin

Mixin — это набор методов и полей, который можно "подмешать" в любой класс без наследования. Это решает проблему множественного наследования.

```dart
mixin Serializable {
  Map<String, dynamic> toJson();

  String toJsonString() {
    return toJson().toString();
  }
}

mixin Loggable {
  void log(String message) {
    print('[${runtimeType}] $message');
  }
}
```

### `with` — подключение mixin

```dart
class Movie with Serializable, Loggable {
  String title;
  int year;

  Movie(this.title, this.year);

  @override
  Map<String, dynamic> toJson() => {
    'title': title,
    'year': year,
  };
}

void main() {
  var movie = Movie('Dune', 2021);
  movie.log('Фильм создан');        // [Movie] Фильм создан
  print(movie.toJsonString());      // {title: Dune, year: 2021}
}
```

### Когда использовать mixin

Mixin подходит, когда нужно **добавить поведение** нескольким несвязанным классам без общего родителя:

```dart
mixin Printable {
  void printInfo() {
    print('--- ${runtimeType} ---');
  }
}

mixin Comparable {
  int compareTo(covariant Object other);
}

class Book with Printable {
  String title;
  Book(this.title);
}

class Song with Printable {
  String name;
  Song(this.name);
}

void main() {
  Book('Война и мир').printInfo(); // --- Book ---
  Song('Yesterday').printInfo();  // --- Song ---
}
```

### Ограничения mixin

```dart
// Mixin может ограничить классы, к которым применяется
mixin AnimalBehavior on Animal {
  void forage() {
    print('$name ищет еду'); // можно обратиться к полям Animal
  }
}

class Bear extends Animal with AnimalBehavior {
  Bear(String name) : super(name);
}
```

## 8. Generics (обобщения)

### Зачем нужны Generics

Без Generics пришлось бы писать отдельный класс для каждого типа данных. Generics позволяют создать **универсальный** класс, параметризованный типом.

### `class Box<T>` — обобщённый класс

```dart
class Box<T> {
  T value;

  Box(this.value);

  T getValue() => value;

  void printValue() {
    print('Box содержит: $value (тип: ${value.runtimeType})');
  }
}

void main() {
  var intBox = Box<int>(42);
  var stringBox = Box<String>('Hello');
  var doubleBox = Box<double>(3.14);

  intBox.printValue();    // Box содержит: 42 (тип: int)
  stringBox.printValue(); // Box содержит: Hello (тип: String)

  int extracted = intBox.getValue(); // тип известен на этапе компиляции
}
```

### Generic методы

Обобщения можно применять и к отдельным методам:

```dart
T first<T>(List<T> list) {
  if (list.isEmpty) throw StateError('Список пуст');
  return list.first;
}

void main() {
  print(first<int>([1, 2, 3]));       // 1
  print(first<String>(['a', 'b']));   // a
  // Тип можно вывести автоматически:
  print(first([10, 20, 30]));         // 10
}
```

### Ограничение типа `<T extends ...>`

Можно ограничить параметр типа, чтобы разрешить только классы, реализующие определённый интерфейс:

```dart
class SortedList<T extends Comparable<T>> {
  final List<T> _items = [];

  void add(T item) {
    _items.add(item);
    _items.sort();
  }

  List<T> getAll() => List.unmodifiable(_items);
}

void main() {
  var numbers = SortedList<int>();
  numbers.add(5);
  numbers.add(2);
  numbers.add(8);
  print(numbers.getAll()); // [2, 5, 8]

  var words = SortedList<String>();
  words.add('банан');
  words.add('яблоко');
  words.add('апельсин');
  print(words.getAll()); // [апельсин, банан, яблоко]
}
```

## 9. Extensions (расширения)

### Зачем нужны Extensions

Extensions позволяют добавлять методы к **существующим** типам, не изменяя их исходный код. Это особенно полезно для стандартных типов (`String`, `int`, `List`) и для сторонних библиотек.

### Синтаксис

```dart
extension StringExtension on String {
  // Проверка, является ли строка email
  bool get isEmail => contains('@') && contains('.');

  // Капитализация первой буквы
  String capitalize() {
    if (isEmpty) return this;
    return '${this[0].toUpperCase()}${substring(1)}';
  }

  // Повторение строки N раз
  String repeat(int times) => this * times;
}

void main() {
  print('user@example.com'.isEmail); // true
  print('hello'.capitalize());       // Hello
  print('ab'.repeat(3));             // ababab
}
```

### Extension на `int`

```dart
extension IntExtension on int {
  bool get isEven => this % 2 == 0;
  bool get isOdd => !isEven;

  // Выполнить действие N раз
  void times(void Function(int) action) {
    for (int i = 0; i < this; i++) {
      action(i);
    }
  }
}

void main() {
  print(4.isEven);  // true
  print(7.isOdd);   // true

  3.times((i) => print('Итерация $i'));
  // Итерация 0
  // Итерация 1
  // Итерация 2
}
```

### Extension на `List`

```dart
extension ListExtension<T> on List<T> {
  // Разбить список на чанки заданного размера
  List<List<T>> chunked(int size) {
    final chunks = <List<T>>[];
    for (int i = 0; i < length; i += size) {
      chunks.add(sublist(i, i + size > length ? length : i + size));
    }
    return chunks;
  }
}

void main() {
  var numbers = [1, 2, 3, 4, 5, 6, 7];
  print(numbers.chunked(3)); // [[1, 2, 3], [4, 5, 6], [7]]
}
```

## 10. Enum (перечисление)

### Базовый enum

Enum — это именованный набор констант. Используется, когда переменная может принимать одно из ограниченного набора значений.

```dart
enum Direction {
  north,
  south,
  east,
  west,
}

void main() {
  var dir = Direction.north;

  print(dir);        // Direction.north
  print(dir.name);   // north
  print(dir.index);  // 0

  // Все значения enum
  print(Direction.values); // [Direction.north, Direction.south, ...]
}
```

### `switch` по enum

Компилятор Dart предупредит, если не обработаны все значения enum:

```dart
void describeDirection(Direction dir) {
  switch (dir) {
    case Direction.north:
      print('Иду на север');
    case Direction.south:
      print('Иду на юг');
    case Direction.east:
      print('Иду на восток');
    case Direction.west:
      print('Иду на запад');
  }
}
```

### Enum с полями и методами (Dart 2.17+)

Современный Dart позволяет добавлять в enum поля, конструкторы и методы:

```dart
enum MovieGenre {
  action('Боевик'),
  comedy('Комедия'),
  drama('Драма'),
  sciFi('Фантастика'),
  horror('Ужасы');

  // Поле
  final String label;

  // Конструктор — всегда const
  const MovieGenre(this.label);

  // Метод
  String get description => 'Жанр: $label';
}

void main() {
  var genre = MovieGenre.sciFi;

  print(genre.label);       // Фантастика
  print(genre.description); // Жанр: Фантастика

  // Итерация по всем жанрам
  for (var g in MovieGenre.values) {
    print('${g.name}: ${g.label}');
  }
}
```

## Итоги лекции

| Концепция | Ключевое слово | Назначение |
|---|---|---|
| Класс | `class` | Шаблон для объектов |
| Наследование | `extends` | Получить поведение родителя |
| Интерфейс | `implements` | Обязаться реализовать контракт |
| Mixin | `mixin` / `with` | Добавить поведение без наследования |
| Абстрактный класс | `abstract class` | Шаблон без прямого создания |
| Generics | `<T>` | Универсальный тип-параметр |
| Расширение | `extension on` | Добавить методы к чужому типу |
| Перечисление | `enum` | Набор именованных констант |
