## Задание 1. Абстрактный класс `Shape`

Создайте абстрактный класс `Shape` и реализуйте его в двух наследниках.

**Требования к `Shape`:**
- Абстрактный метод `double area()` — возвращает площадь фигуры.
- Конкретный метод `void describe()` — выводит название типа фигуры и её площадь, например:
  ```
  Circle: площадь = 78.54
  Rectangle: площадь = 24.00
  ```

**Требования к `Circle`:**
- Поле `double radius`.
- Реализация `area()` по формуле `π * r²` (используйте `3.14159`).

**Требования к `Rectangle`:**
- Поля `double width` и `double height`.
- Реализация `area()` по формуле `width * height`.

**Проверьте:**
```dart
void main() {
  List<Shape> shapes = [Circle(5), Rectangle(4, 6)];
  for (var shape in shapes) {
    shape.describe();
  }
}
```

Ожидаемый вывод:
```
Circle: площадь = 78.54
Rectangle: площадь = 24.00
```

## Задание 2. Mixin `Printable`

Создайте mixin `Printable` и примените его к классу `Movie`.

**Требования к mixin `Printable`:**
- Метод `void printInfo()` — выводит все поля объекта в читаемом виде, например:
  ```
  --- Movie ---
  title: Inception
  year: 2010
  rating: 8.8
  ```
  Используйте `runtimeType` для получения имени класса.

**Требования к классу `Movie`:**
- Поля: `String title`, `int year`, `double rating`.
- Подключите mixin `Printable` через `with`.
- При необходимости переопределите `printInfo()`, чтобы вывести все три поля.

**Проверьте:**
```dart
void main() {
  var movie = Movie('Inception', 2010, 8.8);
  movie.printInfo();
}
```

## Задание 3. Generic класс `Repository<T>`

Создайте универсальный класс-хранилище, который работает с любым типом объектов.

**Требования к `Repository<T>`:**
- Приватное поле `List<T> _items` — список элементов.
- Метод `void add(T item)` — добавляет элемент в список.
- Метод `T? findById(int index)` — возвращает элемент по индексу, или `null` если индекс за пределами списка.
- Метод `List<T> getAll()` — возвращает копию всего списка.

**Проверьте:**
```dart
void main() {
  var repo = Repository<Movie>();
  repo.add(Movie('Inception', 2010, 8.8));
  repo.add(Movie('The Matrix', 1999, 8.7));
  repo.add(Movie('Interstellar', 2014, 8.6));

  print(repo.findById(1)?.title); // The Matrix
  print(repo.findById(99));       // null
  print(repo.getAll().length);    // 3
}
```

## Задание 4. Extension на `List<Movie>`

Добавьте к типу `List<Movie>` метод сортировки через extension.

**Требования:**
- Объявите `extension MovieListExtension on List<Movie>`.
- Добавьте метод `List<Movie> sortedByRating()`, который возвращает **новый** список фильмов, отсортированных по полю `rating` от большего к меньшему. Исходный список не изменяется.

**Проверьте:**
```dart
void main() {
  var movies = [
    Movie('Inception', 2010, 8.8),
    Movie('Dune', 2021, 7.9),
    Movie('The Matrix', 1999, 8.7),
  ];

  var sorted = movies.sortedByRating();
  for (var m in sorted) {
    print('${m.title} — ${m.rating}');
  }
}
```

Ожидаемый вывод:
```
Inception — 8.8
The Matrix — 8.7
Dune — 7.9
```
