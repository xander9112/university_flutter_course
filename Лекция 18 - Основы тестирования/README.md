# Лекция 18 - Основы тестирования

Тема лекции — основы тестирования Flutter-приложений: unit-, widget- и integration-тесты.

Разбираются принципы написания unit-тестов для бизнес-логики с использованием пакета test, приёмы мокирования зависимостей и проверки поведения кода в изоляции. Отдельно рассматривается widget-тестирование с помощью WidgetTester и pumpWidget для проверки отображения и взаимодействия с UI, а также integration-тестирование, позволяющее проверить работу приложения целиком на реальном или эмулируемом устройстве.
