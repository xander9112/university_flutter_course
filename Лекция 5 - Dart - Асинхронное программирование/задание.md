# Задание 5 — Dart: асинхронное программирование

Все задания выполняются на чистом Dart в [DartPad](https://dartpad.dev) или локально.

---

## Задание 1. Имитация сетевого запроса

Напишите асинхронную функцию, имитирующую получение названия фильма по его идентификатору.

**Требования:**
- Функция `Future<String> fetchMovieTitle(int id)` должна использовать `Future.delayed(Duration(seconds: 2))` для имитации сетевой задержки.
- После задержки возвращайте любое название фильма в зависимости от `id` (например, используйте `Map<int, String>` или просто `'Фильм #$id'`).
- В `main()` вызовите функцию с `await` и выведите результат.
- Перед вызовом выведите `'Загружаю фильм...'`, после — `'Готово: <название>'`.

**Ожидаемый вывод:**
```
Загружаю фильм...
(пауза 2 секунды)
Готово: Inception
```

## Задание 2. Параллельные запросы с `Future.wait`

Напишите функцию, которая имитирует одновременную загрузку нескольких фильмов.

**Требования:**
- Создайте вспомогательную функцию `Future<String> fetchMovie(String title, int delaySeconds)`, которая возвращает строку вида `'[данные] $title'` после указанной задержки.
- Напишите `Future<List<String>> fetchMovies()`, которая использует `Future.wait` для **параллельного** запуска трёх вызовов `fetchMovie` с разными задержками (например, 1, 2, 3 секунды).
- В `main()` замерьте время выполнения: запустите `fetchMovies()` и выведите все результаты. Убедитесь, что общее время ≈ max из задержек, а не их сумма.

**Ожидаемый вывод:**
```
Загружаю 3 фильма параллельно...
(пауза ~3 секунды, а не 6)
[данные] Inception
[данные] Dune
[данные] The Matrix
```

## Задание 3. Обработка ошибок с запасным значением

Напишите функцию, которая надёжно возвращает данные даже при возможных сбоях.

**Требования:**
- Импортируйте `dart:math`.
- Напишите `Future<String> loadMovie()`, которая с вероятностью 50% (используйте `Random().nextBool()`) бросает `Exception('Сервер недоступен')`, а с вероятностью 50% возвращает строку `'Inception (2010)'`.
- Напишите `Future<String> loadMovieWithFallback()`, которая вызывает `loadMovie()` внутри блока `try/catch` и при ошибке возвращает запасное значение `'Фильм недоступен'` (не бросает исключение дальше).
- Вызовите `loadMovieWithFallback()` несколько раз в `main()`, чтобы увидеть оба случая.

**Ожидаемый вывод (при нескольких запусках):**
```
Результат: Inception (2010)
// или
Результат: Фильм недоступен (произошла ошибка: Сервер недоступен)
```

## Задание 4. Обратный отсчёт через `StreamController`

Создайте Stream, который отсчитывает от 5 до 0 с интервалом 1 секунда.

**Требования:**
- Создайте `StreamController<int>` (не Broadcast).
- В отдельной асинхронной функции (или сразу в `main`) запустите цикл, который добавляет числа от 5 до 0 через `controller.sink.add(i)` с задержкой `Duration(seconds: 1)` между каждым.
- После 0 закройте контроллер: `controller.close()`.
- Подпишитесь на `controller.stream` через `await for` и выводите каждое значение: для 0 — `'Пуск!'`, для остальных — `'До старта: $i'`.

**Ожидаемый вывод:**
```
До старта: 5
До старта: 4
До старта: 3
До старта: 2
До старта: 1
Пуск!
```

## Задание 5. Генератор оценок через `async*`

Напишите функцию-генератор потока, которая выдаёт фильмы с оценками по одному в секунду.

**Требования:**
- Напишите `Stream<String> generateRatings(List<String> movies) async*`.
- Для каждого фильма из списка: подождите `Duration(seconds: 1)` через `await Future.delayed`, затем выдайте строку вида `'$movie — оценка: ${rating}'`, где `rating` — случайное число от 6.0 до 9.9 (используйте `Random().nextDouble() * 4 + 6`). Форматируйте до одного знака: `rating.toStringAsFixed(1)`.
- В `main()` передайте список из 4–5 фильмов и выведите каждую строку по мере поступления через `await for`.

**Ожидаемый вывод:**
```
(пауза 1 сек) Inception — оценка: 8.4
(пауза 1 сек) Dune — оценка: 7.2
(пауза 1 сек) The Matrix — оценка: 9.1
(пауза 1 сек) Interstellar — оценка: 8.8
```

## Чеклист самопроверки

- [ ] В задании 1: слово `'Загружаю фильм...'` выводится **до** паузы, а не после.
- [ ] В задании 2: суммарное время выполнения равно наибольшей задержке, а не сумме всех — это подтверждает параллельность.
- [ ] В задании 3: функция `loadMovieWithFallback` **никогда** не бросает исключение — ошибка всегда перехватывается внутри.
- [ ] В задании 4: `controller.close()` вызывается после отправки последнего значения; без закрытия `await for` будет ждать вечно.
- [ ] В задании 5: используется `async*` и `yield`, а не `StreamController` — убедитесь в разнице подходов.
- [ ] Весь код компилируется без ошибок в DartPad.
