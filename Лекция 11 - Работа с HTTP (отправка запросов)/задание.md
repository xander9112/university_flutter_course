# Задание 11 — HTTP: загрузка фильмов из реального API

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы подключите реальный API для получения популярных фильмов. Вместо моковых данных приложение будет загружать актуальный список из интернета.

---

## Используемый API

Приложение будет работать с **The Movie Database (TMDB) API**:

1. Зарегистрируйтесь на https://www.themoviedb.org
2. В настройках профиля создайте API ключ: **Settings → API → Create → Developer**
3. Сохраните ключ — он понадобится при запуске приложения (см. задачу 3)

Пример запроса популярных фильмов:
```
GET https://api.themoviedb.org/3/movie/popular?api_key=ВАШ_КЛЮЧ&language=ru-RU&page=1
```

### 2. Обновить модель `Movie` для десериализации из JSON

Добавьте фабричный конструктор `fromJson` в класс `Movie`:

```dart
factory Movie.fromJson(Map<String, dynamic> json) {
  return Movie(
    id: json['id'] as int,
    title: json['title'] as String,
    overview: json['overview'] as String?,
    posterPath: json['poster_path'] as String?,
    backdropPath: json['backdrop_path'] as String?,
    voteAverage: (json['vote_average'] as num?)?.toDouble(),
    releaseDate: json['release_date'] as String? ?? '',
    genreIds: (json['genre_ids'] as List<dynamic>?)
            ?.map((e) => e as int)
            .toList() ??
        [],
  );
}
```

### 3. Создать `MovieApiService`

Создайте файл `lib/services/movie_api_service.dart`:

```dart
import 'dart:convert';
import 'package:http/http.dart' as http;
import '../models/movie.dart';

class MovieApiService {
  static const _baseUrl = 'https://api.themoviedb.org/3';

  // Ключ не хранится в коде, а передаётся при запуске через --dart-define
  static const _apiKey = String.fromEnvironment('TMDB_API_KEY');

  Future<List<Movie>> getPopularMovies({int page = 1}) async {
    final uri = Uri.parse(
      '$_baseUrl/movie/popular?api_key=$_apiKey&language=ru-RU&page=$page',
    );

    final response = await http.get(uri);

    if (response.statusCode == 200) {
      final data = jsonDecode(response.body) as Map<String, dynamic>;
      final results = data['results'] as List<dynamic>;
      return results.map((json) => Movie.fromJson(json as Map<String, dynamic>)).toList();
    } else {
      throw Exception('Ошибка загрузки: ${response.statusCode}');
    }
  }

  Future<List<Movie>> searchMovies(String query) async {
    if (query.isEmpty) return [];
    final uri = Uri.parse(
      '$_baseUrl/search/movie?api_key=$_apiKey&language=ru-RU&query=${Uri.encodeComponent(query)}',
    );
    final response = await http.get(uri);
    if (response.statusCode == 200) {
      final data = jsonDecode(response.body) as Map<String, dynamic>;
      final results = data['results'] as List<dynamic>;
      return results.map((json) => Movie.fromJson(json as Map<String, dynamic>)).toList();
    } else {
      throw Exception('Ошибка поиска: ${response.statusCode}');
    }
  }
}
```

**Почему ключ не пишется прямо в код.** Если записать ключ строкой (`static const _apiKey = 'abc123...'`), он попадёт в git вместе с остальным кодом — и любой, кто увидит репозиторий, сможет им пользоваться. Поэтому ключ передаётся при запуске, а в коде остаётся только его имя:

```bash
flutter run --dart-define=TMDB_API_KEY=ваш_ключ
```

`String.fromEnvironment('TMDB_API_KEY')` подставляет это значение при сборке. Если ключ не передать, вернётся пустая строка, TMDB ответит ошибкой `401`, и главный экран покажет её с кнопкой «Повторить».

Чтобы не вводить ключ каждый раз, в VS Code добавьте его в `.vscode/launch.json`:

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "cine_track",
      "request": "launch",
      "type": "dart",
      "args": ["--dart-define=TMDB_API_KEY=ваш_ключ"]
    }
  ]
}
```

Этот файл с настоящим ключом тоже не стоит коммитить — добавьте `.vscode/launch.json` в `.gitignore`.

> **Подсказка.** Чтобы вместо непонятной ошибки `401` сразу видеть причину, добавьте в начало обоих методов проверку: `if (_apiKey.isEmpty) throw Exception('Не задан ключ TMDB: запустите с --dart-define=TMDB_API_KEY=...');`

### 4. Обновить `HomeScreen` для загрузки данных из сети

Замените `mockMovies` на загрузку из сети. Список `_movies` остаётся в состоянии экрана — перемешивание, удаление свайпом, добавление фильма и личные оценки из Заданий 7–10 продолжают работать с ним без изменений. Добавляются только два поля — признак загрузки и текст ошибки:

```dart
class _HomeScreenState extends State<HomeScreen> {
  final _apiService = MovieApiService();
  List<Movie> _movies = [];
  bool _isLoading = true;
  String? _error;
  // _userRatings и остальные поля из прошлых заданий остаются

  @override
  void initState() {
    super.initState();
    _loadMovies();
  }

  Future<void> _loadMovies() async {
    try {
      final movies = await _apiService.getPopularMovies();
      if (!mounted) return;
      setState(() {
        _movies = movies;
        _isLoading = false;
      });
    } catch (e) {
      if (!mounted) return;
      setState(() {
        _error = e.toString();
        _isLoading = false;
      });
    }
  }

  void _retry() {
    setState(() {
      _isLoading = true;
      _error = null;
    });
    _loadMovies();
  }

  Widget _buildBody() {
    if (_isLoading) {
      return const Center(child: CircularProgressIndicator());
    }
    if (_error != null) {
      return Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            const Icon(Icons.error_outline, size: 48, color: Colors.red),
            const SizedBox(height: 8),
            Text('Ошибка: $_error'),
            TextButton(
              onPressed: _retry,
              child: const Text('Повторить'),
            ),
          ],
        ),
      );
    }
    // Разметка из Задания 8 без изменений: лента «Популярное» (например,
    // первые 5 фильмов — _movies.take(5)) и список «Все фильмы»
    // с Dismissible, жестами и переходами из Заданий 7–10.
    return Column(/* ... */);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(/* заголовок и кнопка «Перемешать» — как раньше */),
      body: _buildBody(),
      floatingActionButton: /* кнопка добавления фильма из Задания 10 */,
    );
  }
}
```

Удалите импорт `mock_movies.dart` из `HomeScreen` — тестовые данные больше не нужны на главном экране.

### 5. Обновить `SearchScreen` для поиска через API

Замените локальный поиск по мокам на запрос к API. Чтобы не отправлять запрос на каждый введённый символ, используйте `Timer` (debounce): запрос уходит, только если пользователь не печатал 500 мс.

```dart
void _onSearch(String query) {
  _debounce?.cancel();
  _debounce = Timer(const Duration(milliseconds: 500), () async {
    try {
      final results = await _apiService.searchMovies(query);
      if (!mounted) return;
      setState(() => _results = results);
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Ошибка поиска: $e')),
      );
    }
  });
}
```

Добавьте `import 'dart:async';`, поле `final _apiService = MovieApiService();` и поле `Timer? _debounce;` в состояние. В `dispose` отмените таймер: `_debounce?.cancel();`. Начальное значение `_results` замените на пустой список `[]` и удалите импорты `mock_movies.dart` и `movie_utils.dart` — до ввода запроса экран поиска теперь пуст.
