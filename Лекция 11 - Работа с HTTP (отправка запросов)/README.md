# Лекция 11 - Работа с HTTP (отправка запросов)

Тема лекции — выполнение сетевых запросов во Flutter-приложении и работа с форматом JSON.

В лекции рассматривается пакет http для отправки GET/POST-запросов и получения данных из сети (классы Future и http.Response), а также формат JSON как способ обмена данными. Разбирается ручная сериализация JSON — создание модели данных и разбор ответа сервера через jsonDecode/jsonEncode, а также автогенерируемая сериализация JSON с помощью пакетов json_serializable и build_runner, избавляющая от написания шаблонного кода вручную.
