# Лекция 20 — Адаптивный и отзывчивый UI

## 1. Responsive vs Adaptive

Два подхода к построению UI под разные устройства, которые часто путают:

| Подход | Что делает | Пример |
|--------|-----------|--------|
| **Responsive (отзывчивый)** | Изменяет _размеры_ и _компоновку_ в зависимости от ширины экрана | 1 колонка на телефоне → 3 колонки на планшете |
| **Adaptive (адаптивный)** | Изменяет _поведение_ и _компоненты_ под платформу | `Switch` на Android → `CupertinoSwitch` на iOS |

В реальных приложениях оба подхода применяются вместе: CineTrack должен одинаково хорошо выглядеть на телефоне, планшете и веб-браузере, и при этом использовать нативные элементы под каждую платформу.

## 2. MediaQuery

`MediaQuery` даёт информацию об экране устройства: размер, ориентацию, системные отступы.

```dart
@override
Widget build(BuildContext context) {
  final mediaQuery = MediaQuery.of(context);

  final screenWidth = mediaQuery.size.width;   // ширина в логических пикселях
  final screenHeight = mediaQuery.size.height; // высота в логических пикселях
  final pixelRatio = mediaQuery.devicePixelRatio; // физические пиксели / логические
  final systemPadding = mediaQuery.padding;    // нотч, статус-бар, home indicator
  final orientation = mediaQuery.orientation; // Orientation.portrait / .landscape

  return Container(
    width: screenWidth * 0.9, // 90% ширины экрана
    padding: EdgeInsets.only(top: systemPadding.top), // учитываем статус-бар
    child: /* ... */,
  );
}
```

### Breakpoints

Стандартные точки перехода (breakpoints) для Flutter:

```dart
class Breakpoints {
  static const double phone = 600;    // < 600 — телефон
  static const double tablet = 1200;  // 600–1200 — планшет
  // > 1200 — десктоп
}

// Использование
final width = MediaQuery.of(context).size.width;

if (width < Breakpoints.phone) {
  // Телефон: одноколоночный список
} else if (width < Breakpoints.tablet) {
  // Планшет: двухколоночная сетка
} else {
  // Десктоп: трёхколоночная сетка + боковая панель
}
```

### Пример: адаптивное количество колонок

```dart
int _getCrossAxisCount(BuildContext context) {
  final width = MediaQuery.of(context).size.width;
  if (width < 600) return 2;
  if (width < 900) return 3;
  return 4;
}

GridView.builder(
  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: _getCrossAxisCount(context),
    childAspectRatio: 0.7,
    crossAxisSpacing: 12,
    mainAxisSpacing: 12,
  ),
  itemBuilder: (_, i) => MovieCard(movie: movies[i]),
  itemCount: movies.length,
)
```

## 3. LayoutBuilder

`LayoutBuilder` даёт информацию о размере **контейнера**, а не экрана. Это важно, когда виджет находится не на полный экран (например, в боковой панели).

```dart
LayoutBuilder(
  builder: (BuildContext context, BoxConstraints constraints) {
    // constraints.maxWidth — максимальная доступная ширина
    // constraints.maxHeight — максимальная доступная высота
    // constraints.minWidth, constraints.minHeight — минимальные размеры

    if (constraints.maxWidth < 600) {
      return MovieListView(movies: movies); // узкий контейнер → список
    } else {
      return MovieGridView(movies: movies, columns: 3); // широкий → сетка
    }
  },
)
```

### MediaQuery vs LayoutBuilder

```
MediaQuery                   LayoutBuilder
───────────                  ─────────────
Размер всего экрана          Размер конкретного контейнера
Глобальный контекст          Локальный контекст
Доступен везде               Только внутри builder
Подходит для breakpoints     Подходит для компонентов
```

**Правило:** если компонент может размещаться в разных местах (колонка, список, диалог) — используйте `LayoutBuilder`. Если нужен глобальный breakpoint (выбрать навигацию) — `MediaQuery`.

## 4. SafeArea

`SafeArea` автоматически добавляет отступы, чтобы содержимое не перекрывалось системными элементами: нотчем, динамическим островом, статус-баром, навигационной панелью Android.

```dart
// Без SafeArea: контент может уходить под нотч
Scaffold(
  body: ListView(children: [...]),
)

// С SafeArea: Flutter сам добавит нужные отступы
Scaffold(
  body: SafeArea(
    child: ListView(children: [...]),
  ),
)

// Можно отключить отступы с конкретных сторон
SafeArea(
  top: true,     // отступ сверху (статус-бар, нотч) — включён
  bottom: false, // отступ снизу — выключен (Scaffold сам управляет)
  left: true,
  right: true,
  child: content,
)
```

`Scaffold` уже включает часть SafeArea-логики, но явное использование `SafeArea` даёт больше контроля, особенно в кастомных компоновках.

## 5. OrientationBuilder

`OrientationBuilder` перестраивает виджет при изменении ориентации устройства.

```dart
OrientationBuilder(
  builder: (context, orientation) {
    if (orientation == Orientation.portrait) {
      // Вертикально: постер сверху, детали снизу
      return Column(
        children: [
          MoviePoster(movie: movie, height: 300),
          Expanded(child: MovieDetails(movie: movie)),
        ],
      );
    } else {
      // Горизонтально: постер слева, детали справа
      return Row(
        children: [
          MoviePoster(movie: movie, width: 200),
          Expanded(child: MovieDetails(movie: movie)),
        ],
      );
    }
  },
)
```

## 6. Адаптивные виджеты компоновки

### GridView: count vs extent

```dart
// GridView.count — фиксированное число колонок
GridView.count(
  crossAxisCount: 2,          // всегда 2 колонки
  childAspectRatio: 0.7,
  children: movies.map((m) => MovieCard(movie: m)).toList(),
)

// GridView.extent — фиксированная максимальная ширина ячейки
// Число колонок определяется автоматически
GridView.extent(
  maxCrossAxisExtent: 200,    // каждая ячейка не шире 200px
  childAspectRatio: 0.7,      // на большом экране будет больше колонок
  children: movies.map((m) => MovieCard(movie: m)).toList(),
)
```

`GridView.extent` удобнее для адаптивных сеток: на телефоне получится 2 колонки, на планшете — 4, на десктопе — 6.

### Список или сетка в зависимости от ширины

```dart
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth < 600) {
      return ListView.builder(
        itemCount: movies.length,
        itemBuilder: (_, i) => MovieListTile(movie: movies[i]),
      );
    }
    return GridView.extent(
      maxCrossAxisExtent: 200,
      childAspectRatio: 0.7,
      padding: const EdgeInsets.all(16),
      children: movies.map((m) => MovieCard(movie: m)).toList(),
    );
  },
)
```

### Flexible и Expanded

```dart
Row(
  children: [
    // Expanded: занимает всё доступное пространство
    Expanded(
      child: TextField(hint: 'Поиск фильмов...'),
    ),
    const SizedBox(width: 8),
    // Кнопка занимает только свой размер
    IconButton(icon: const Icon(Icons.search), onPressed: _search),
  ],
)

Row(
  children: [
    // Flexible с flex: делим пространство в пропорции 2:1
    Flexible(flex: 2, child: MoviePoster(movie: movie)),
    Flexible(flex: 1, child: MovieDetails(movie: movie)),
  ],
)
```

## 7. Platform-specific UI

### Определение платформы

```dart
import 'dart:io' show Platform;

if (Platform.isIOS) {
  // iOS-специфичный код
}
if (Platform.isAndroid) {
  // Android-специфичный код
}
// Также: Platform.isMacOS, Platform.isWindows, Platform.isLinux
```

### Адаптивные компоненты

```dart
// Переключатель
Widget buildSwitch(bool value, ValueChanged<bool> onChanged) {
  if (Platform.isIOS) {
    return CupertinoSwitch(value: value, onChanged: onChanged);
  }
  return Switch(value: value, onChanged: onChanged);
}

// Индикатор загрузки
Widget buildLoader() {
  if (Platform.isIOS) {
    return const CupertinoActivityIndicator();
  }
  return const CircularProgressIndicator();
}

// Диалог подтверждения
Future<bool?> showConfirmDialog(BuildContext context, String message) {
  if (Platform.isIOS) {
    return showCupertinoDialog<bool>(
      context: context,
      builder: (_) => CupertinoAlertDialog(
        title: const Text('Подтверждение'),
        content: Text(message),
        actions: [
          CupertinoDialogAction(
            isDestructiveAction: true,
            onPressed: () => Navigator.pop(context, true),
            child: const Text('Удалить'),
          ),
          CupertinoDialogAction(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('Отмена'),
          ),
        ],
      ),
    );
  }
  return showDialog<bool>(
    context: context,
    builder: (_) => AlertDialog(
      title: const Text('Подтверждение'),
      content: Text(message),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(context, false),
          child: const Text('Отмена'),
        ),
        TextButton(
          onPressed: () => Navigator.pop(context, true),
          child: const Text('Удалить'),
        ),
      ],
    ),
  );
}
```

### Поддержка мыши

MouseRegion(

### Клавиатурные шорткаты

```dart
// Shortcuts + Actions — стандартный Flutter-способ
class HomeScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Shortcuts(
      shortcuts: {
        LogicalKeySet(LogicalKeyboardKey.keyF): const SearchIntent(),
        LogicalKeySet(LogicalKeyboardKey.escape): const CloseSearchIntent(),
      },
      child: Actions(
        actions: {
          SearchIntent: CallbackAction<SearchIntent>(
            onInvoke: (_) => _focusSearchField(),
          ),
          CloseSearchIntent: CallbackAction<CloseSearchIntent>(
            onInvoke: (_) => _closeSearch(),
          ),
        },
        child: Focus(
          autofocus: true,
          child: content,
        ),
      ),
    );
  }
}

class SearchIntent extends Intent {
  const SearchIntent();
}
```
