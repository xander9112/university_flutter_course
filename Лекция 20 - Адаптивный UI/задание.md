## Задача 1. GridView на широких экранах, ListView на узких

Секция «Все фильмы» на HomeScreen должна автоматически переключаться между списком и сеткой в зависимости от ширины. Ширину, доступную виджету, сообщает `LayoutBuilder`: он передаёт в `builder` ограничения (`constraints`) от родителя, и по `constraints.maxWidth` видно, сколько места есть именно у этого виджета.

### 1.1. Сделать главный экран прокручиваемым целиком

Сейчас HomeScreen — это `Column`: заголовок, лента «Популярное» высотой 200, ещё заголовок и список «Все фильмы» в `Expanded`. На телефоне в ландшафте высота экрана около 390 пикселей, и после AppBar, ленты и заголовков списку остаётся несколько пикселей, а с нижней панелью навигации места не остаётся совсем. Поэтому прокручиваться должен весь экран, а не только список.

Для этого используется `CustomScrollView`. Его дети — **слайверы** (sliver): части одной прокручиваемой области. Обычный виджет становится слайвером через `SliverToBoxAdapter`, список — `SliverList`, сетка — `SliverGrid`:

```dart
// lib/features/movies/presentation/screens/home_screen.dart, в _buildMovies
return RefreshIndicator(
  onRefresh: /* как в Задании 17 — через Completer */,
  child: CustomScrollView(
    slivers: [
      const SliverToBoxAdapter(child: /* заголовок «Популярное» */),
      SliverToBoxAdapter(
        child: SizedBox(height: 200, child: /* горизонтальная лента, как раньше */),
      ),
      const SliverToBoxAdapter(child: /* заголовок «Все фильмы» */),
      _MoviesGrid(movies: movies, itemBuilder: _buildMovieItem),
      // отступ снизу, чтобы FloatingActionButton не закрывал последнюю карточку
      const SliverPadding(padding: EdgeInsets.only(bottom: 88)),
    ],
  ),
);
```

Вынесите построение элемента «Все фильмы» — `Dismissible`, `GestureDetector` с переходом на детали и двойным тапом, `MovieCard` — в метод `_buildMovieItem(BuildContext context, Movie movie)`. Так и в списке, и в сетке сохраняются удаление, избранное и переход на экран деталей.

### 1.2. Список или сетка

`_MoviesGrid` стоит среди слайверов, поэтому и сам возвращает слайвер. Ширину ему даёт `SliverLayoutBuilder` — вариант `LayoutBuilder` для слайверов: доступная ширина лежит в `constraints.crossAxisExtent`.

```dart
// lib/features/movies/presentation/screens/home_screen.dart

class _MoviesGrid extends StatelessWidget {
  const _MoviesGrid({required this.movies, required this.itemBuilder});
  final List<Movie> movies;

  // Элемент списка: Dismissible → GestureDetector → MovieCard
  final Widget Function(BuildContext context, Movie movie) itemBuilder;

  @override
  Widget build(BuildContext context) {
    final delegate = SliverChildBuilderDelegate(
      (context, i) => itemBuilder(context, movies[i]),
      childCount: movies.length,
      // как в Задании 7: без этого колбэка переставленные элементы теряют состояние
      findChildIndexCallback: (key) {
        final index = movies.indexWhere((m) => ValueKey(m.id) == key);
        return index == -1 ? null : index;
      },
    );

    return SliverLayoutBuilder(
      builder: (context, constraints) {
        // Узкий экран (телефон) — список, как раньше
        if (constraints.crossAxisExtent < 600) {
          return SliverList(delegate: delegate);
        }

        // Широкий экран (планшет/десктоп) — сетка;
        // число колонок определяется автоматически
        return SliverPadding(
          padding: const EdgeInsets.symmetric(horizontal: 8),
          sliver: SliverGrid(
            delegate: delegate,
            gridDelegate: const SliverGridDelegateWithMaxCrossAxisExtent(
              maxCrossAxisExtent: 420, // ширина колонки — не больше 420
              mainAxisExtent: 142, // высота ячейки
            ),
          ),
        );
      },
    );
  }
}
```

`MovieCard` — горизонтальная карточка: постер 80×120 слева, текст и сердце справа. Поэтому у ячейки задаётся не пропорция (`childAspectRatio`), а высота: постер 120 плюс отступы карточки. Текст в ячейке фиксированной высоты не должен её переполнять, поэтому ограничьте название в `MovieCard` двумя строками:

```dart
Text(
  movie.title,
  maxLines: 2,
  overflow: TextOverflow.ellipsis,
  style: const TextStyle(fontSize: 18, fontWeight: FontWeight.bold),
),
```

> Две строки названия, год и рейтинг занимают около 104 пикселей: в Material 3 высота строки — 1,43 от размера шрифта. Если пользователь увеличил шрифт в настройках системы, текст вырастет. Высоту ячейки можно подстроить под него: `mainAxisExtent: 12 + math.max(120, MediaQuery.textScalerOf(context).scale(106) + 24)`.

Проверьте поведение, изменяя размер окна во Flutter Web или в симуляторе с разными размерами экрана, в том числе телефон в ландшафте.

```dart
// lib/features/movies/presentation/screens/movie_detail_screen.dart
@override
```

## Задача 3. OrientationBuilder на экране деталей

На экране деталей фильма показывайте разный макет в зависимости от ориентации. Сначала вынесите нижнюю часть экрана деталей из Задания 8 (год, жанр, описание, `Row` с характеристиками, личную оценку и кнопку «Оценить» из Заданий 10 и 12) в отдельный виджет `_MovieInfo({required Movie movie})`. Постер с `Hero` (Задание 19) остаётся в `_MovieDetailBody`.

Код ниже показывает только макет. В портрете вместо одиночного `Image.network` оставьте шапку из Задания 8 — постер с градиентом, а поверх него название и рейтинг. Во всех постерах сохраните `errorBuilder` из Задания 19. В ландшафте название и рейтинг поверх постера не видны, поэтому покажите их в правой колонке над `_MovieInfo`.

```dart
// lib/features/movies/presentation/screens/movie_detail_screen.dart

class _MovieDetailBody extends StatelessWidget {
  const _MovieDetailBody({required this.movie});
  final Movie movie;

  @override
  Widget build(BuildContext context) {
    return OrientationBuilder(
      builder: (context, orientation) {
        if (orientation == Orientation.portrait) {
          // Портрет: постер сверху, описание снизу
          return SingleChildScrollView(
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Hero(
                  tag: 'poster-${movie.id}',
                  child: Image.network(
                    movie.posterUrl,
                    width: double.infinity,
                    height: 300,
                    fit: BoxFit.cover,
                  ),
                ),
                Padding(
                  padding: const EdgeInsets.all(16),
                  child: _MovieInfo(movie: movie),
                ),
              ],
            ),
          );
        }

        // Ландшафт: постер слева, детали справа
        return Row(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            // Постер занимает 40% ширины
            Flexible(
              flex: 4,
              child: Hero(
                tag: 'poster-${movie.id}',
                child: Image.network(
                  movie.posterUrl,
                  height: double.infinity,
                  fit: BoxFit.cover,
                ),
              ),
            ),
            // Описание занимает 60% ширины
            Flexible(
              flex: 6,
              child: SingleChildScrollView(
                // Сверху — место под прозрачный AppBar, иначе текст начнётся под ним.
                // При extendBodyBehindAppBar Scaffold уже включил высоту AppBar
                // в padding.top, а SafeArea(top: false) этот отступ не забирает.
                padding: EdgeInsets.fromLTRB(
                  16,
                  MediaQuery.paddingOf(context).top,
                  16,
                  16,
                ),
                child: _MovieInfo(movie: movie), // + название и рейтинг сверху
              ),
            ),
          ],
        );
      },
    );
  }
}
```

## Задача 4. AdaptiveScaffold с NavigationRail на планшете

На телефонах показывайте `BottomNavigationBar`, на планшетах (ширина >= 600) — `NavigationRail` сбоку.

`NavigationRail` — вертикальная панель навигации у левого края экрана. По смыслу она повторяет `BottomNavigationBar` из Задания 10: `selectedIndex` — активный пункт, `onDestinationSelected` — обработчик выбора, `destinations` — список пунктов (`NavigationRailDestination` с иконкой и подписью). На широком экране боковая панель экономит место по вертикали, которого на планшете в ландшафте мало.

Здесь ширина берётся из `MediaQuery`, а не из `LayoutBuilder`: тип навигации зависит от размера всего экрана, а не от места, выделенного конкретному виджету.

```dart
// lib/core/widgets/adaptive_scaffold.dart

class AdaptiveScaffold extends StatelessWidget {
  const AdaptiveScaffold({
    super.key,
    required this.selectedIndex,
    required this.onDestinationSelected,
    required this.destinations,
    required this.body,
  });

  final int selectedIndex;
  final ValueChanged<int> onDestinationSelected;
  final List<AdaptiveDestination> destinations;
  final Widget body;

  @override
  Widget build(BuildContext context) {
    final width = MediaQuery.of(context).size.width;
    final isTablet = width >= 600;

    if (isTablet) {
      // Планшет: NavigationRail слева
      return Scaffold(
        body: Row(
          children: [
            NavigationRail(
              selectedIndex: selectedIndex,
              onDestinationSelected: onDestinationSelected,
              // Показываем лейблы рядом с иконками на широких экранах
              labelType: width >= 1200
                  ? NavigationRailLabelType.all
                  : NavigationRailLabelType.selected,
              destinations: destinations
                  .map((d) => NavigationRailDestination(
                        icon: Icon(d.icon),
                        selectedIcon: Icon(d.selectedIcon),
                        label: Text(d.label),
                      ))
                  .toList(),
            ),
            const VerticalDivider(thickness: 1, width: 1),
            // Левый вырез телефона в ландшафте уже обходит NavigationRail
            // (у неё внутри SafeArea). Убираем его из MediaQuery тела,
            // иначе SafeArea экранов отступили бы от него второй раз.
            Expanded(
              child: MediaQuery.removePadding(
                context: context,
                removeLeft: true,
                child: body,
              ),
            ),
          ],
        ),
      );
    }

    // Телефон: BottomNavigationBar
    return Scaffold(
      body: body,
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: selectedIndex,
        onTap: onDestinationSelected,
        items: destinations
            .map((d) => BottomNavigationBarItem(
                  icon: Icon(d.icon),
                  activeIcon: Icon(d.selectedIcon),
                  label: d.label,
                ))
            .toList(),
      ),
    );
  }
}

class AdaptiveDestination {
  const AdaptiveDestination({
    required this.icon,
    required this.selectedIcon,
    required this.label,
  });

  final IconData icon;
  final IconData selectedIcon;
  final String label;
}
```

Используйте в `MainScreen` вместо `Scaffold` с `BottomNavigationBar` из Задания 10:

```dart
// lib/features/main/presentation/screens/main_screen.dart

class MainScreen extends StatefulWidget {
  const MainScreen({super.key});

  @override
  State<MainScreen> createState() => _MainScreenState();
}

class _MainScreenState extends State<MainScreen> {
  int _selectedIndex = 0;

  static const _destinations = [
    AdaptiveDestination(
      icon: Icons.home_outlined,
      selectedIcon: Icons.home,
      label: 'Главная',
    ),
    AdaptiveDestination(
      icon: Icons.search_outlined,
      selectedIcon: Icons.search,
      label: 'Поиск',
    ),
    AdaptiveDestination(
      icon: Icons.favorite_outline,
      selectedIcon: Icons.favorite,
      label: 'Избранное',
    ),
  ];

  // Как в Задании 10: IndexedStack сохраняет состояние вкладок,
  // а ScaffoldMessenger у каждой вкладки не даёт SnackBar перекрыть её FAB.
  static const _screens = [
    ScaffoldMessenger(child: HomeScreen()),
    ScaffoldMessenger(child: SearchScreen()),
    ScaffoldMessenger(child: FavoritesScreen()),
  ];

  @override
  Widget build(BuildContext context) {
    return AdaptiveScaffold(
      selectedIndex: _selectedIndex,
      onDestinationSelected: (i) => setState(() => _selectedIndex = i),
      destinations: _destinations,
      // HeroMode и TickerMode из Задания 19 сохраняются
      body: IndexedStack(
        index: _selectedIndex,
        children: [
          for (var i = 0; i < _screens.length; i++)
            HeroMode(
              enabled: i == _selectedIndex,
              child: TickerMode(enabled: i == _selectedIndex, child: _screens[i]),
            ),
        ],
      ),
    );
  }
}
```
