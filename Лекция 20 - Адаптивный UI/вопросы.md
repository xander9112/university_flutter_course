# Вопросы — Лекция 20: Адаптивный и отзывчивый UI

1. В чём разница между `MediaQuery` и `LayoutBuilder`?

   a) `MediaQuery` работает только на мобильных, `LayoutBuilder` — на всех платформах
   b) `LayoutBuilder` предоставляет информацию об экране, `MediaQuery` — о контейнере
   c) ✓ `MediaQuery` возвращает размер всего экрана, а `LayoutBuilder` — размер конкретного контейнера, в котором размещён виджет
   d) Между ними нет разницы, оба возвращают одинаковые значения

2. Зачем нужен виджет `SafeArea`?

   a) Для создания безопасного (зашифрованного) хранилища данных
   b) Для ограничения доступа к отдельным экранам приложения
   c) ✓ Для автоматического добавления отступов, чтобы контент не перекрывался системными элементами: нотчем, динамическим островом, статус-баром
   d) Для проверки, что все дочерние виджеты находятся в пределах экрана

3. Какой breakpoint принято считать нижней границей планшета?

   a) 480 логических пикселей
   b) ✓ 600 логических пикселей
   c) 768 логических пикселей
   d) 1024 логических пикселя

4. Что возвращает `OrientationBuilder` в своём `builder`?

   a) Ширину и высоту экрана в текущей ориентации
   b) ✓ Значение типа `Orientation`: `Orientation.portrait` или `Orientation.landscape`
   c) Угол поворота устройства в градусах
   d) Булево значение: `true` для портретной ориентации

5. В чём разница между `GridView.count` и `GridView.extent`?

   a) `GridView.count` работает быстрее, `GridView.extent` — медленнее
   b) `GridView.extent` поддерживает только квадратные ячейки
   c) `GridView.count` поддерживает ленивую загрузку, `GridView.extent` — нет
   d) ✓ `GridView.count` задаёт фиксированное число колонок, `GridView.extent` — максимальную ширину ячейки, а число колонок определяется автоматически

6. Что такое адаптивный (adaptive) UI в отличие от отзывчивого (responsive)?

   a) Адаптивный UI работает на старых устройствах, отзывчивый — на новых
   b) ✓ Отзывчивый UI меняет компоновку под размер экрана, адаптивный — меняет поведение и компоненты под конкретную платформу (iOS, Android, Desktop)
   c) Адаптивный UI использует анимации, отзывчивый — нет
   d) Они означают одно и то же, это синонимы

7. Как использовать `Platform.isIOS` для показа нативного переключателя?

   a) `Platform.isIOS` доступен через `package:flutter/material.dart`
   b) Достаточно использовать `Switch` — он автоматически меняет вид под iOS
   c) ✓ Нужно импортировать `dart:io`, проверить `Platform.isIOS` и вернуть `CupertinoSwitch` для iOS и `Switch` для Android
   d) `Platform.isIOS` можно использовать только в `main.dart`

8. В чём разница между `Flexible` и `Expanded` в `Row`/`Column`?

   a) `Expanded` работает только в `Row`, `Flexible` — только в `Column`
   b) `Flexible` занимает всё доступное пространство, `Expanded` — только своё минимальное
   c) ✓ `Expanded` всегда занимает всё доступное пространство (равносильно `Flexible(fit: FlexFit.tight)`), `Flexible` может занять меньше, если дочерний виджет меньше доступного места
   d) Между ними нет разницы
