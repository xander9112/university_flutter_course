# Лекция 20 - Адаптивный UI

Тема лекции — построение адаптивного и отзывчивого интерфейса во Flutter, подстраивающегося под разные экраны и платформы.

Рассматриваются различия между responsive и adaptive подходами, работа с MediaQuery и LayoutBuilder для получения размеров экрана и построения breakpoints, а также использование SafeArea и OrientationBuilder. Отдельное внимание уделяется адаптивным виджетам компоновки (GridView, Flexible, Expanded), определению платформы и созданию platform-specific UI с Cupertino-виджетами, а также особенностям Flutter-приложений на desktop и web (поддержка мыши, клавиатурные шорткаты, минимальные размеры окна).
