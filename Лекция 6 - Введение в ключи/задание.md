# Задание 3 — Ключи: управление списком фильмов

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы добавите интерактивность в список фильмов: возможность удалять карточки и перемешивать список. Именно здесь ключи (`Key`) становятся критически важны для корректной работы фреймворка.

---

## Задачи

### 1. Добавить `ValueKey` к карточкам в списке

В `HomeScreen` при построении `ListView` передайте `ValueKey` с уникальным идентификатором каждого фильма (например, названием):

```dart
ListView.builder(
  itemCount: _movies.length,
  itemBuilder: (context, index) {
    final movie = _movies[index];
    return MovieCard(
      key: ValueKey(movie['title']),
      // ... остальные параметры
    );
  },
)
```

**Зачем:** без `ValueKey` Flutter не сможет корректно сопоставить виджеты с данными при изменении порядка в списке.

### 2. Добавить кнопку «Перемешать»

Добавьте в `AppBar` кнопку `IconButton` с иконкой `Icons.shuffle`. По нажатию список фильмов перемешивается:

```dart
actions: [
  IconButton(
    icon: const Icon(Icons.shuffle),
    onPressed: () {
      setState(() {
        _movies.shuffle();
      });
    },
  ),
],
```

Запустите приложение и убедитесь, что при нажатии порядок карточек меняется.

### 3. Добавить удаление через `Dismissible`

Оберните каждый `MovieCard` в виджет `Dismissible`, чтобы пользователь мог смахнуть фильм влево для удаления:

```dart
Dismissible(
  key: ValueKey(movie['title']),
  direction: DismissDirection.endToStart,
  background: Container(
    color: Colors.red,
    alignment: Alignment.centerRight,
    padding: const EdgeInsets.only(right: 16),
    child: const Icon(Icons.delete, color: Colors.white),
  ),
  onDismissed: (direction) {
    setState(() {
      _movies.removeAt(index);
    });
  },
  child: MovieCard(/* ... */),
)
```

### 4. Эксперимент: убедиться в важности ключей

Добавьте в `MovieCard` любое внутреннее состояние — например, счётчик нажатий или цвет фона, который меняется при тапе. Попробуйте перемешать список:

- **без `ValueKey`** — состояние «прилипает» к позиции, а не к карточке
- **с `ValueKey`** — состояние следует за конкретным фильмом

Опишите наблюдаемое поведение в коротком комментарии в коде или в `notes.md`.
