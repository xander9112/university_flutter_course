# Задание 12 — Provider: глобальное состояние фильмов, избранного и оценок

## Контекст

Продолжаем разработку **CineTrack**. Сейчас состояние приложения разбросано по отдельным виджетам через `setState`: список фильмов живёт внутри `HomeScreen`, двойной тап «в избранное» из Задания 9 только показывает `SnackBar` — вкладка «Избранное» об этом ничего не знает, а личные оценки из Задания 10 хранятся в `HomeScreen`, поэтому оценка, поставленная из поиска, теряется. В этом задании вы вынесете общее состояние в `Provider`, чтобы любой экран мог читать и изменять его.

## Задачи

### 1. Добавить пакет `provider`

В `pubspec.yaml`:

### 2. Создать `FavoritesProvider`

Создайте файл `lib/providers/favorites_provider.dart`:

```dart
import 'package:flutter/foundation.dart';
import '../models/movie.dart';

class FavoritesProvider extends ChangeNotifier {
  final List<Movie> _favorites = [];

  List<Movie> get favorites => List.unmodifiable(_favorites);

  bool isFavorite(int movieId) => _favorites.any((m) => m.id == movieId);

  void toggleFavorite(Movie movie) {
    if (isFavorite(movie.id)) {
      _favorites.removeWhere((m) => m.id == movie.id);
    } else {
      _favorites.add(movie);
    }
    notifyListeners();
  }
}
```

### 3. Создать `RatingsProvider`

Личные оценки из Задания 10 нужны сразу нескольким экранам: поставить оценку можно на экране деталей, открытом с главной, из поиска или из избранного. Поэтому словарь «id фильма → оценка» переезжает из `HomeScreen` в отдельный провайдер.

Создайте файл `lib/providers/ratings_provider.dart`:

```dart
import 'package:flutter/foundation.dart';

class RatingsProvider extends ChangeNotifier {
  final Map<int, double> _ratings = {};

  /// Личная оценка фильма или `null`, если фильм ещё не оценён.
  double? ratingOf(int movieId) => _ratings[movieId];

  void setRating(int movieId, double rating) {
    _ratings[movieId] = rating;
    notifyListeners();
  }
}
```

### 4. Создать `MoviesProvider`

Создайте файл `lib/providers/movies_provider.dart`:

```dart
import 'package:flutter/foundation.dart';
import '../models/movie.dart';
import '../services/movie_api_service.dart';

class MoviesProvider extends ChangeNotifier {
  final MovieApiService _apiService = MovieApiService();

  List<Movie> _movies = [];
  bool _isLoading = false;
  String? _error;

  List<Movie> get movies => _movies;
  bool get isLoading => _isLoading;
  String? get error => _error;

  Future<void> loadMovies() async {
    _isLoading = true;
    _error = null;
    notifyListeners();

    try {
      _movies = await _apiService.getPopularMovies();
    } catch (e) {
      _error = e.toString();
    } finally {
      _isLoading = false;
      notifyListeners();
    }
  }

  // Операции со списком, которые раньше делались через setState в HomeScreen

  void addMovie(Movie movie) {
    _movies.insert(0, movie);
    notifyListeners();
  }

  void removeMovie(int movieId) {
    _movies.removeWhere((m) => m.id == movieId);
    notifyListeners();
  }

  void shuffle() {
    _movies.shuffle();
    notifyListeners();
  }
}
```

### 5. Подключить провайдеры к дереву виджетов

void main() {

### 6. Перевести `HomeScreen` на `MoviesProvider`

Уберите из `_HomeScreenState` поля `_apiService`, `_movies`, `_isLoading`, `_error` и метод `_loadMovies` из Задания 11 — теперь всё это хранит `MoviesProvider`. Словарь личных оценок `_userRatings` из Задания 10 тоже уберите — оценки теперь хранит `RatingsProvider`, а экран деталей сохраняет их сам (задача 9). Поэтому переход на детали снова становится простым: `Navigator.pushNamed(context, '/movie-detail', arguments: movie)` без ожидания результата и без `setState`.

```dart
class _HomeScreenState extends State<HomeScreen> {
  @override
  void initState() {
    super.initState();
    // Загружаем фильмы при первом рендере
    Future.microtask(
      () => context.read<MoviesProvider>().loadMovies(),
    );
  }

  Widget _buildBody(MoviesProvider moviesProvider) {
    if (moviesProvider.isLoading) {
      return const Center(child: CircularProgressIndicator());
    }
    if (moviesProvider.error != null) {
      return Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text('Ошибка: ${moviesProvider.error}'),
            TextButton(
              onPressed: moviesProvider.loadMovies,
              child: const Text('Повторить'),
            ),
          ],
        ),
      );
    }
    final movies = moviesProvider.movies;
    // Разметка из Задания 8 («Популярное» + «Все фильмы»), но список берётся
    // из movies, а в onDismissed вместо setState вызывается
    // context.read<MoviesProvider>().removeMovie(movie.id)
    return Column(/* ... */);
  }

  @override
  Widget build(BuildContext context) {
    final moviesProvider = context.watch<MoviesProvider>();

    return Scaffold(
      appBar: AppBar(
        title: const Text('CineTrack'),
        actions: [
          IconButton(
            icon: const Icon(Icons.shuffle),
            onPressed: () => context.read<MoviesProvider>().shuffle(),
          ),
        ],
      ),
      body: _buildBody(moviesProvider),
      floatingActionButton: FloatingActionButton(
        onPressed: () async {
          final movie =
              await Navigator.pushNamed(context, '/add-movie') as Movie?;
          if (movie == null || !mounted) return;

          context.read<MoviesProvider>().addMovie(movie);
          ScaffoldMessenger.of(context).showSnackBar(
            SnackBar(content: Text('«${movie.title}» добавлен!')),
          );
        },
        child: const Icon(Icons.add),
      ),
    );
  }
}
```

Обратите внимание на разницу: в `build` используется `context.watch` — экран перестраивается при изменении списка. В обработчиках нажатий используется `context.read` — там нужно только вызвать метод, подписка не нужна.

### 7. Добавить кнопку «В избранное» на `MovieCard`

Кнопка отображает иконку сердца. Состояние читается через `context.watch`, поэтому иконка перерисовывается сразу после нажатия:

```dart
// в MovieCard.build
final favorites = context.watch<FavoritesProvider>();
final isFav = favorites.isFavorite(movie.id);

// ... в разметке карточки
IconButton(
  icon: Icon(
    isFav ? Icons.favorite : Icons.favorite_border,
    color: isFav ? Colors.red : null,
  ),
  onPressed: () => context.read<FavoritesProvider>().toggleFavorite(movie),
)
```

Двойной тап на карточке из Задания 9 теперь тоже должен по-настоящему менять избранное: в `onDoubleTap` вызовите `context.read<FavoritesProvider>().toggleFavorite(movie)` перед показом `SnackBar`.

### 8. Реализовать `FavoritesScreen`

Откройте `lib/screens/favorites_screen.dart` и отобразите список избранных фильмов:

```dart
class FavoritesScreen extends StatelessWidget {
  const FavoritesScreen({super.key});

  @override
  Widget build(BuildContext context) {
    final favorites = context.watch<FavoritesProvider>().favorites;

    if (favorites.isEmpty) {
      return const Scaffold(
        body: Center(child: Text('Нет избранных фильмов')),
      );
    }

    return Scaffold(
      appBar: AppBar(title: const Text('Избранное')),
      body: ListView.builder(
        itemCount: favorites.length,
        itemBuilder: (context, index) => MovieCard(movie: favorites[index]),
      ),
    );
  }
}
```

### 9. Сохранять личную оценку через `RatingsProvider`

В Задании 10 экран деталей возвращал оценку через `Navigator.pop(context, rating)`, и сохранить её мог только тот экран, который открыл детали. Теперь общее состояние доступно отовсюду, поэтому экран деталей сам записывает оценку в провайдер и остаётся открытым:

```dart
// В MovieDetailScreen, в обработчике кнопки «Оценить»
final rating = await showDialog<double>(
  context: context,
  builder: (_) => const RatingDialog(),
);
if (rating == null || !context.mounted) return;

context.read<RatingsProvider>().setRating(movie.id, rating);
ScaffoldMessenger.of(context).showSnackBar(
  SnackBar(content: Text('Ваша оценка «${movie.title}»: $rating')),
);
```

Покажите оценку на экране деталей — рядом с кнопкой. Через `context.watch` текст обновится сразу после сохранения:

```dart
// в MovieDetailScreen.build
final userRating = context.watch<RatingsProvider>().ratingOf(movie.id);

// ... в разметке, над кнопкой
Text(
  userRating == null
      ? 'Вы ещё не оценили этот фильм'
      : 'Ваша оценка: ${userRating.toStringAsFixed(1)}',
),
FilledButton.icon(
  onPressed: () => _rate(context, movie),
  icon: const Icon(Icons.star),
  label: Text(userRating == null ? 'Оценить' : 'Изменить оценку'),
),
```

Возврат результата через `Navigator.pop` из Задания 10 больше не нужен: когда данные лежат в общем состоянии, экранам не приходится передавать их друг другу.
