# Лекция 12 - Управление состоянием

Тема лекции — подходы к управлению состоянием в Flutter-приложениях: от локального состояния до общего состояния приложения.

В лекции разбираются понятия эфемерного состояния и состояния приложения (app state), а также подход lifting state up. Рассматриваются конкретные механизмы управления состоянием: setState в StatefulWidget для локального состояния, InheritedWidget для передачи данных вниз по дереву виджетов, и пакет Provider с его специализированными классами (ChangeNotifierProvider, StreamProvider, FutureProvider, ValueListenableProvider, MultiProvider, ProxyProvider) для организации общего состояния приложения.
