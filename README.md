# Курс по Flutter

Тема курса — разработка мобильных приложений на Flutter и Dart: от основ языка Dart до архитектуры, тестирования и публикации готового приложения.

Курс научит студентов писать приложения на Dart и Flutter, строить пользовательский интерфейс из виджетов и компоновать сложные экраны, а также организовывать навигацию, работу с сетью, локальное хранение данных и управление состоянием (Provider, BLoC). Помимо этого студенты освоят чистую архитектуру, dependency injection, генерацию кода, тестирование, анимации, адаптивный UI и публикацию приложения в магазины — то есть пройдут весь путь от идеи до релиза на примере одного сквозного проекта.
