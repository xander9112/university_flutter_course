# Лекция 17 - Генерация кода

Тема лекции — автоматическая генерация кода в Dart/Flutter с помощью build_runner и связанных пакетов: Freezed, Retrofit и Chopper.

Рассматривается принцип работы build_runner как инструмента запуска кодогенераторов, создание неизменяемых классов данных и union-типов с помощью Freezed, а также их использование совместно с BLoC для описания состояний и событий. Отдельно разбирается генерация типобезопасных HTTP-клиентов на основе аннотаций с помощью пакетов Retrofit и Chopper, что позволяет сократить рутинный код при работе с сетевыми запросами.
