# Лекция 17 - Генерация кода

Существует ряд пакетов, позволяющих автоматизировать написание шаблонного кода (boilerplate code), тем самым ускорив разработку и уменьшив количество ошибок в нем.

## build_runner

build_runner — это пакет Dart, предоставляющий конкретный способ создания файлов с использованием кода Dart. Этот пакет необходим для создания кода внутри файла dart. 

Обычно мы используем команды build и watch. 

Команда build создает файл только один раз. И после этого он существует. Команда watch постоянно отслеживает изменения в файлах. Если происходят какие-либо изменения, он снова создает этот файл.

 Чтобы использовать этот пакет, мы должны поместить его в dev_dependencies внутри файла pubspec.yaml.

Иногда при сборке файла выдает ошибку, что в файле обнаружен конфликт. Чтобы решить эту проблему, добавьте аргумент --delete-conflicting-outputs после команды сборки.

## Freezed

Freezed – это пакет для генерации кода, который помогает создавать классы данных в Dart.

 Иногда нам просто нужен класс, который получает свои значения в конструкторе, метод toString и, должен быть иммутабелен. Для этого нам нужен дополнительный метод copyWith. 

Freezed — надежный и масштабируемый генератор кода для классов данных. Он надежен, но имеет недостаток: новичкам действительно сложно найти правильное сочетание и необходимые функции для использования в логике своего приложения. Итак, Freezed — это один из пакетов, который используется для создания дата и union классов. Кроме того, его можно использовать для сериализации и десериализации данных JSON. 

До

```dart
class User {
  User({
    required this.id,
    required this.email,
    required this.firstName,
    required this.lastName,
    required this.avatar,
  });
  final int id;
  final String email;
  final String firstName;
  final String lastName;
  final String avatar;
  factory User.fromJson(Map<String, dynamic> json) => User(
        id: json["id"],
        email: json["email"],
        firstName: json["first_name"],
        lastName: json["last_name"],
        avatar: json["avatar"],

```


После

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'user.freezed.dart';
part 'user.g.dart';

@freezed
abstract class User with _$User {
  const factory User({
    required int id,
    required String name,
    required String email,
    required String avatar,
  }) = _User;

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
}
```

Начиная с Freezed 3, класс с одним конструктором объявляется как `abstract class`, а union-класс с несколькими вариантами (см. ниже) — как `sealed class`.

Используя пакет Freezed, мы можем избавиться от большого количества шаблонного кода.

Как использовать Freezed:

Во-первых, мы должны добавить в наш проект некоторые зависимости, с помощью которых мы можем легко использовать Freezed. 

```yaml
dependencies:
  freezed_annotation: ^3.1.0
  json_annotation: ^4.12.0

dev_dependencies:
  flutter_test:
    sdk: flutter
  build_runner: ^2.16.1
  freezed: ^4.0.1
  json_serializable: ^6.14.1
```

Freezed размещает аннотации `@JsonSerializable` и `@JsonKey` на параметрах конструктора, и анализатор предупреждает об этом (`invalid_annotation_target`). Так задумано авторами пакета — правило отключают в `analysis_options.yaml`:

```yaml
analyzer:
  errors:
    invalid_annotation_target: ignore
```

## BLoC и Freezed

Пакет freezed, а именно возможность генерации union классов можно, можно использовать для генерации эвентов и стейтов для Bloc, позволяя избежать написание шаблонного кода.

Для начала определимся что такое union класс. 

Идея в том, что вы можете создать класс с фиксированным набором подклассов, связывая вместе несколько отдельных типов в рамках одного основного класса.

В Dart 3 для этого есть `sealed`-классы: компилятор знает полный список подклассов и проверяет, что `switch` обработал каждый из них. Но сами подклассы, операторы равенства, `copyWith` и `toString` по-прежнему приходится писать вручную — их и генерирует для нас Freezed.

Рассмотрим простой блок Counter. У него будет два события: CounterIncremented и CounterDecremented. В чистом Dart нам пришлось бы сделать что-то вроде этого:

```dart
abstract class CounterEvent {}
class CounterIncremented extends CounterEvent {
  CounterIncremented(this.incrementBy);
  final int incrementBy;
}
class CounterDecremented extends CounterEvent {
  CounterDecremented(this.decrementBy);
  final int decrementBy;
}
```

Это хорошо, но есть пара заслуживающих внимания вопросов:

Для блоков с большим количеством событий вы можете видеть, насколько этот подход стал бы очень многословным и громоздким. 

В приведенном выше фрагменте не учитываются операторы равенства; это больше шаблонов, которые нам нужно добавить.

 Когда мы в конце концов реализуем этот блок, наш код будет полон приведения и проверки типов, с которыми легко запутаться.

Вот как будут выглядеть наши события счетчика при использовании freezed:

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'counter_event.freezed.dart';

@freezed
sealed class CounterEvent with _$CounterEvent {
  const factory CounterEvent.incremented(int incrementBy) = CounterIncremented;
  const factory CounterEvent.decremented(int decrementBy) = CounterDecremented;
}
```

С этой реализацией freezed предоставил нам два неизменяемых типа событий с корректно определенным operator ==. Он также генерирует бонусные вещи, такие как методы copyWith и toString. Это полностью готовая к использованию реализация нашего типа CounterEvent.

Также freezed предоставляет pattern-matching синтаксис, это значит что мы можем в обработчике эвента в блоке написать такую конструкцию:

```dart
event.when(
  incremented: (incrementBy) => emit(state + incrementBy),
  decremented: (decrementBy) => emit(state - decrementBy),
);
```

Так как `CounterEvent` — `sealed class`, то же самое можно записать и встроенным в Dart `switch`; компилятор тоже проверит, что обработаны все варианты:

```dart
switch (event) {
  case CounterIncremented(:final incrementBy):
    emit(state + incrementBy);
  case CounterDecremented(:final decrementBy):
    emit(state - decrementBy);
}
```

Этот синтаксис полезен по нескольким причинам. Во-первых, заставляет нас учитывать каждую возможность; в чистом Dart с приведением типов мы могли бы легко забыть или проигнорировать определенные типы событий. Во-вторых, это очень легко читать и понимать.

Давайте посмотрим на что-то более сложное: написание  стейтов с использованием freezed. Допустим, у нас есть некоторые данные для загрузки: нам, вероятно, понадобится начальное состояние, состояние ошибки и состояние успеха. Нам также нужен индикатор загрузки, чтобы показать пользователю, когда данные обновляются.

Используя freezed, мы можем реализовать такой класс состояния:

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'data_state.freezed.dart';

@freezed
sealed class DataState with _$DataState {
  const factory DataState.initial(bool isLoading) = DataInitial;
  const factory DataState.error(String message, bool isLoading) = DataError;
  const factory DataState.success(Data data, bool isLoading) = DataSuccess;
}
```

Затем мы можем реализовать BlocBuilder следующим образом:

```dart
BlocBuilder<DataBloc, DataState>(
  builder: (context, state) {
    return Column(
      children: [
        if (state.isLoading) _buildProgressIndicator(),
        state.when(
          initial: (_) => _buildInitial(),
          error: (message, _) => _buildError(message),
          success: (data, _) => _buildSuccess(data),
        ),
      ],
    );
  },
);
```

Здесь есть несколько замечаний:

Поскольку каждый тип стейта имеет свойство isLoading, мы можем получить к нему доступ, не зная, какой у нас подтип стейта. 

Опять же, pattern-matching синтаксис , предоставляемый  freezed, чрезвычайно полезен здесь, поскольку дает нам удобную читаемую конструкцию, которая заставляет нас обрабатывать все возможные состояния.

## Retrofit

Retrofit это пакет, использующий кодогенерацию для создания классов для RestAPI

Пакет позволяет быстро и качественно настроить взаимодействие вашего приложения с удаленным сервером с помощью RestAPI.

В качестве примера воспользуемся тестовым сервером https://gorest.co.in/

Go REST предоставляет нам тестовый ресурс по адресу 

https://gorest.co.in/public/v2/users

Для начала подключим необходимы зависимости

```yaml
dependencies:
  flutter:
    sdk: flutter
  freezed_annotation: ^3.1.0
  retrofit: ^4.10.0
  json_annotation: ^4.12.0
  dio: ^5.11.1

dev_dependencies:
  flutter_test:
    sdk: flutter
  build_runner: ^2.16.1
  freezed: ^4.0.1
  retrofit_generator: ^10.2.11
  json_serializable: ^6.14.1
```

Создадим с помощью freezed дата класс пользователя

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'user.freezed.dart';
part 'user.g.dart';

@freezed
abstract class User with _$User {
  const factory User({
    required int id,
    required String name,
    required String email,
    required String gender,
    required String status,
  }) = _User;

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
}
```

Запустим генерацию

```bash
dart run build_runner build --delete-conflicting-outputs
```

Далее создаем удаленный источник данных, который может запрашивать список пользователей у сервиса https://gorest.co.in/

Создадим файл user_remote_datasource.dart

```dart
import 'package:dio/dio.dart';
import 'package:learn_examples/user.dart';
import 'package:retrofit/retrofit.dart';

part 'user_remote_datasource.g.dart';

@RestApi(baseUrl: 'https://gorest.co.in/public/v2')
abstract class UserRemoteDatasource {
  factory UserRemoteDatasource(Dio dio, {String baseUrl}) =
      _UserRemoteDatasource;

  @GET('/users')
  Future<List<User>> getUsers();

  @GET('/users/{id}')
  Future<User> getUser(@Path() int id);
}
```

C помощью аннотации @RestApi мы помечаем наш класс для генерации, в параметр baseUrl передаем базовый url куда необходимо отправлять запросы.

Далее объявляем два метода

```dart
  @GET('/users')
  Future<List<User>> getUsers();
```

Этот метод будет отправлять GET запрос на https://gorest.co.in/public/v2/users  и получать список пользователей.

```dart
  @GET('/users/{id}')
  Future<User> getUser(@Path() int id);
```

Этот метод будет отправлять GET запрос на https://gorest.co.in/public/v2/users/{id} и получать пользователя с указанным id. 

После этого запускаем генерацию и пакет Retrofit сгенерирует готовую имплементацию необходимого нам источника данных, который можно сразу использовать.

```bash
dart run build_runner build --delete-conflicting-outputs
```

Теперь создадим экран, на котором будем запрашивать список пользователей и отображать его в списке.

```dart
class HomePage extends StatefulWidget {
  const HomePage({super.key});
  @override
  State<HomePage> createState() => _HomePageState();
}
class _HomePageState extends State<HomePage> {
  late UserRemoteDatasource datasource;
  late Future<List<User>> result;
  @override
  void initState() {
    super.initState();
    datasource = UserRemoteDatasource(Dio());
    result = datasource.getUsers();
  }
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(),
      body: SingleChildScrollView(
        child: FutureBuilder(
            future: result,
            builder: (context, snapshot) {
              if (snapshot.hasError) {
                return Center(
                  child: Column(
                    children: [
                      const Text('Data fetch error'),
                      ElevatedButton(
                          onPressed: () {
                            setState(() {
                              result = datasource.getUsers();
                            });
                          },
                          child: const Text('Retry'))
                    ],
                  ),
                );
              }
              if (snapshot.hasData) {
                final users = snapshot.data ?? [];
                return Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: users
                      .map((user) => Card(
                            child: SizedBox(
                              width: double.infinity,
                              child: Column(
                                crossAxisAlignment: CrossAxisAlignment.start,
                                children: [
                                  Text('ID: ${user.id}'),
                                  Text('Email: ${user.email}'),
                                  Text(
                                    'Name: ${user.name}',
                                  ),
                                  Text('Gender: ${user.gender}'),
                                  Text('Status: ${user.status}'),
                                ],
                              ),
                            ),
                          ))
                      .toList(),
                );
              }
              return const Center(
                child: CircularProgressIndicator(),
              );
            }),
      ),
    );
  }
}
```

## Chopper

Пакет Chopper является полным аналогом Retrofit, но в качестве сетевой библиотеки использует  вместо Dio пакет http. 

 Давайте перепишем с помощью него предыдущий пример.

Добавим в pubspec.yaml необходимые зависимости

```bash
flutter pub add chopper
flutter pub add dev:chopper_generator dev:build_runner
```

Далее создадим файл user_remote_datasource.dart

```dart
import 'package:chopper/chopper.dart';
import 'package:learn_examples/user.dart';

part 'user_remote_datasource.chopper.dart';

@ChopperApi(baseUrl: 'https://gorest.co.in/public/v2')
abstract class UserRemoteDatasource extends ChopperService {
  static UserRemoteDatasource create([ChopperClient? client]) =>
      _$UserRemoteDatasource(client);
  @Get(path: '/users')
  Future<Response<List<User>>> getUsers();
  @Get(path: '/users/{id}')
  Future<Response<User>> getUser({@Path('id') required int id});
}
```

И сгенерируем наш datasource

```bash
dart run build_runner build --delete-conflicting-outputs
```

Теперь создадим экран, на котором будем запрашивать список пользователей и отображать его в списке.

```dart
class HomePage extends StatefulWidget {
  const HomePage({super.key});
  @override
  State<HomePage> createState() => _HomePageState();
}
class _HomePageState extends State<HomePage> {
  late UserRemoteDatasource datasource;
  late Future<Response> result;
  @override
  void initState() {
    super.initState();
    datasource = UserRemoteDatasource.create(
        ChopperClient(converter: const JsonConverter()));
    result = datasource.getUsers();
  }
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(),
      body: SingleChildScrollView(
        child: FutureBuilder(
            future: result,
            builder: (context, snapshot) {
              if (snapshot.hasError) {
                return Center(
                  child: Column(
                    children: [
                      const Text('Data fetch error'),
                      ElevatedButton(
                          onPressed: () {
                            setState(() {
                              result = datasource.getUsers();
                            });
                          },
                          child: const Text('Retry'))
                    ],
                  ),
                );
              }
              if (snapshot.hasData) {
                final response = snapshot.data!;
                if (response.isSuccessful) {
                  final List<User> users =
                      response.body.map<User>((e) => User.fromJson(e)).toList();
                  return Column(
                      crossAxisAlignment: CrossAxisAlignment.start,
                      children: users
                          .map((user) => Card(
                                child: SizedBox(
                                  width: double.infinity,
                                  child: Column(
                                    crossAxisAlignment:
                                        CrossAxisAlignment.start,
                                    children: [
                                      Text('ID: ${user.id}'),
                                      Text('Email: ${user.email}'),
                                      Text(
                                        'Name: ${user.name}',
                                      ),
                                      Text('Gender: ${user.gender}'),
                                      Text('Status: ${user.status}'),
                                    ],
                                  ),
                                ),
                              ))
                          .toList());
                } else {
                  return Center(
                    child: Column(
                      children: [
                        const Text('Data fetch error'),
                        ElevatedButton(
                            onPressed: () {
                              setState(() {
                                result = datasource.getUsers();
                              });
                            },
                            child: const Text('Retry'))
                      ],
                    ),
                  );
                }
              }
              return const Center(
                child: CircularProgressIndicator(),
              );
            }),
      ),
    );
  }
}
```
