# Задание 17 — Кодогенерация: Freezed, Retrofit и build_runner

## Контекст

Продолжаем разработку **CineTrack**. Ручное написание `copyWith`, `==`, `hashCode`, `fromJson`/`toJson` и HTTP-клиентов — это бойлерплейт, подверженный ошибкам. В этом задании вы заменяете его кодогенерацией с помощью **Freezed** и **Retrofit**, а HTTP-клиент `http` — на **Dio**. `build_runner` у вас уже есть с Задания 16: теперь он будет генерировать не только DI-конфигурацию, но и модели и API-клиент.

### 2. Заменить `Movie` entity на Freezed-класс

Замените содержимое `lib/features/movies/domain/entities/movie.dart`:

```dart
import 'package:freezed_annotation/freezed_annotation.dart';

part 'movie.freezed.dart';

@freezed
class Movie with _$Movie {
  const factory Movie({
    required int id,
    required String title,
    String? overview,
    String? posterPath,
    String? backdropPath,
    double? voteAverage,
    @Default('') String releaseDate,
    @Default([]) List<int> genreIds,
  }) = _Movie;

  // Приватный конструктор нужен, чтобы в Freezed-классе можно было объявить свои геттеры
  const Movie._();

  String get year => releaseDate.length >= 4 ? releaseDate.substring(0, 4) : 'N/A';
  String get rating => voteAverage?.toStringAsFixed(1) ?? '—';
  String get posterUrl => posterPath != null ? 'https://image.tmdb.org/t/p/w500$posterPath' : '';
}
```

`@Default` задаёт значение по умолчанию для параметра. Код, создающий `Movie` (форма из Задания 9, `toEntity()`, `FavoritesDatabase`), продолжает работать без изменений, но теперь у сущности есть `copyWith`, `==` и `hashCode`.

### 3. Заменить `MovieDto` на Freezed + JsonSerializable

```dart
// lib/features/movies/data/models/movie_dto.dart
import 'package:freezed_annotation/freezed_annotation.dart';
import '../../domain/entities/movie.dart';

part 'movie_dto.freezed.dart';
part 'movie_dto.g.dart';

@freezed
class MovieDto with _$MovieDto {
  // fieldRename: snake — поле posterPath читается из JSON-ключа poster_path и т.д.
  @JsonSerializable(fieldRename: FieldRename.snake)
  const factory MovieDto({
    required int id,
    required String title,
    String? overview,
    String? posterPath,
    String? backdropPath,
    double? voteAverage,
    @Default('') String releaseDate,
    @Default([]) List<int> genreIds,
  }) = _MovieDto;

  factory MovieDto.fromJson(Map<String, dynamic> json) => _$MovieDtoFromJson(json);
}

extension MovieDtoMapper on MovieDto {
  Movie toEntity() => Movie(
        id: id,
        title: title,
        overview: overview,
        posterPath: posterPath,
        backdropPath: backdropPath,
        voteAverage: voteAverage,
        releaseDate: releaseDate,
        genreIds: genreIds,
      );
}
```

Метод `toJson()` теперь генерируется автоматически — `MovieLocalDataSourceImpl` из Задания 15 продолжает сохранять кэш без изменений.

### 4. Заменить BLoC события и состояния на Freezed

```dart
// lib/features/movies/presentation/blocs/movies_event.dart
import 'package:freezed_annotation/freezed_annotation.dart';
import '../../domain/entities/movie.dart';

part 'movies_event.freezed.dart';

@freezed
class MoviesEvent with _$MoviesEvent {
  const factory MoviesEvent.load() = LoadMovies;
  const factory MoviesEvent.refresh() = RefreshMovies;
  const factory MoviesEvent.search(String query) = SearchMoviesRequested;
  const factory MoviesEvent.add(Movie movie) = AddMovie;
  const factory MoviesEvent.remove(int movieId) = RemoveMovie;
  const factory MoviesEvent.shuffle() = ShuffleMovies;
}
```

```dart
// lib/features/movies/presentation/blocs/movies_state.dart
import 'package:freezed_annotation/freezed_annotation.dart';
import '../../domain/entities/movie.dart';

part 'movies_state.freezed.dart';

@freezed
class MoviesState with _$MoviesState {
  const factory MoviesState.initial() = MoviesInitial;
  const factory MoviesState.loading() = MoviesLoading;
  const factory MoviesState.loaded(List<Movie> movies) = MoviesLoaded;
  const factory MoviesState.error(String message) = MoviesError;
}
```

Имена после `=` (`LoadMovies`, `MoviesLoaded` и т.д.) совпадают с классами из Задания 13 — Freezed сгенерирует классы с этими именами. Поэтому обработчики `on<LoadMovies>(...)` в `MoviesBloc` и вызовы вида `context.read<MoviesBloc>().add(AddMovie(movie))` продолжают работать без изменений. Можно использовать и новую запись: `add(const MoviesEvent.load())`.

Главное преимущество union-типов — метод `.when`, который заставляет обработать **все** варианты. Перепишите `BlocBuilder` на `HomeScreen` через `state.when` вместо цепочки `if (state is ...)`:

```dart
BlocBuilder<MoviesBloc, MoviesState>(
  builder: (context, state) => state.when(
    initial: () => const SizedBox(),
    loading: () => const Center(child: CircularProgressIndicator()),
    error: (message) => Center(/* текст ошибки и кнопка «Повторить» */),
    loaded: (movies) => /* разметка «Популярное» + «Все фильмы» */,
  ),
)
```

Если в будущем добавить новое состояние, компилятор укажет на каждое место, где оно не обработано.

### 5. Создать Retrofit API-клиент

Создайте файл `lib/features/movies/data/datasources/movie_api_client.dart`:

```dart
import 'package:dio/dio.dart';
import 'package:retrofit/retrofit.dart';
import '../models/movie_list_response.dart';

part 'movie_api_client.g.dart';

@RestApi(baseUrl: 'https://api.themoviedb.org/3')
abstract class MovieApiClient {
  factory MovieApiClient(Dio dio, {String baseUrl}) = _MovieApiClient;

  @GET('/movie/popular')
  Future<MovieListResponse> getPopularMovies({
    @Query('api_key') required String apiKey,
    @Query('language') String language = 'ru-RU',
    @Query('page') int page = 1,
  });

  @GET('/search/movie')
  Future<MovieListResponse> searchMovies({
    @Query('api_key') required String apiKey,
    @Query('query') required String query,
    @Query('language') String language = 'ru-RU',
  });
}
```

`@Query('имя')` добавляет параметр в строку запроса: вызов `getPopularMovies(apiKey: key, page: 2)` превратится в `GET /movie/popular?api_key=...&language=ru-RU&page=2`.

Создайте модель ответа `MovieListResponse`:

```dart
// lib/features/movies/data/models/movie_list_response.dart
import 'package:freezed_annotation/freezed_annotation.dart';
import 'movie_dto.dart';

part 'movie_list_response.freezed.dart';
part 'movie_list_response.g.dart';

@freezed
class MovieListResponse with _$MovieListResponse {
  const factory MovieListResponse({
    required List<MovieDto> results,
    @Default(1) int page,
    @JsonKey(name: 'total_pages') @Default(1) int totalPages,
  }) = _MovieListResponse;

  factory MovieListResponse.fromJson(Map<String, dynamic> json) =>
      _$MovieListResponseFromJson(json);
}
```

### 6. Зарегистрировать Dio и `MovieApiClient` в DI

В `lib/core/di/app_module.dart` из Задания 16 замените `http.Client` на `Dio` и добавьте фабрику API-клиента. `MovieApiClient` — абстрактный класс с генерируемой реализацией, поэтому его удобнее создавать в модуле, а не через аннотацию на самом классе:

```dart
import 'package:dio/dio.dart';
import 'package:injectable/injectable.dart';
import '../../features/movies/data/datasources/movie_api_client.dart';

@module
abstract class AppModule {
  @lazySingleton
  Dio get dio => Dio(
        BaseOptions(
          connectTimeout: const Duration(seconds: 15),
          receiveTimeout: const Duration(seconds: 15),
        ),
      )..interceptors.add(LogInterceptor(requestBody: true));

  @lazySingleton
  MovieApiClient movieApiClient(Dio dio) => MovieApiClient(dio);
}
```

Пакет `http` больше не используется — удалите его из `pubspec.yaml`.

### 7. Обновить `MovieRemoteDataSourceImpl` для работы с `MovieApiClient`

Интерфейс `MovieRemoteDataSource` из Задания 15 не меняется — меняется только реализация. Ручной разбор JSON больше не нужен:

```dart
@LazySingleton(as: MovieRemoteDataSource)
class MovieRemoteDataSourceImpl implements MovieRemoteDataSource {
  final MovieApiClient _client;
  static const _apiKey = 'ВАШ_API_КЛЮЧ';

  MovieRemoteDataSourceImpl(this._client);

  @override
  Future<List<MovieDto>> getPopularMovies({int page = 1}) async {
    final response = await _client.getPopularMovies(apiKey: _apiKey, page: page);
    return response.results;
  }

  @override
  Future<List<MovieDto>> searchMovies(String query) async {
    if (query.isEmpty) return [];
    final response = await _client.searchMovies(apiKey: _apiKey, query: query);
    return response.results;
  }
}
```

При ответе сервера с ошибкой Dio сам бросает исключение `DioException` — `MovieRepositoryImpl` перехватит его и вернёт кэш, как и раньше.

### 8. Запустить кодогенерацию

```bash
dart run build_runner build --delete-conflicting-outputs
```

Или для автоматической пересборки при изменениях:

```bash
dart run build_runner watch --delete-conflicting-outputs
```

После генерации в проекте появятся файлы `*.freezed.dart` и `*.g.dart`, а `injection.config.dart` обновится — **не редактируйте их вручную**.
