# Задание 3 — Null Safety: модель данных фильма

## Контекст

Продолжаем разработку **CineTrack**. До этого момента данные о фильмах хранились как `Map<String, dynamic>`. Это неудобно и небезопасно. В этом задании вы создадите полноценную модель данных `Movie` с применением Null Safety, замените хардкоженные `Map` на объекты и добавите вспомогательные методы для работы со списком.

---

## Задачи

### 1. Создать модель `Movie`

Создайте файл `lib/models/movie.dart`:

```dart
class Movie {
  final int id;
  final String title;
  final String? overview;       // nullable: описание может отсутствовать
  final String? posterPath;     // nullable: постер может отсутствовать
  final String? backdropPath;   // nullable: фоновое изображение
  final double? voteAverage;    // nullable: рейтинг может быть не выставлен
  final String releaseDate;
  final List<int> genreIds;

  const Movie({
    required this.id,
    required this.title,
    this.overview,
    this.posterPath,
    this.backdropPath,
    this.voteAverage,
    required this.releaseDate,
    this.genreIds = const [],
  });

  String get year => releaseDate.isNotEmpty ? releaseDate.substring(0, 4) : 'N/A';

  String get rating => voteAverage != null ? voteAverage!.toStringAsFixed(1) : '—';

  String get posterUrl => posterPath != null
      ? 'https://image.tmdb.org/t/p/w500$posterPath'
      : '';
}
```

### 3. Использовать Null-aware операторы

В `MovieCard` и `MovieDetailScreen` замените обращение к полям через операторы `??` и `?.`:

```dart
// Вместо: movie.overview == null ? 'Описание отсутствует' : movie.overview!
Text(movie.overview ?? 'Описание отсутствует')

// Вместо: movie.voteAverage == null ? '—' : movie.voteAverage!.toStringAsFixed(1)
Text('⭐ ${movie.voteAverage?.toStringAsFixed(1) ?? '—'}')
```

### 4. Добавить вспомогательные функции в `lib/utils/movie_utils.dart`

```dart
import '../models/movie.dart';

/// Фильтрует фильмы с рейтингом выше порога
List<Movie> filterByRating(List<Movie> movies, double minRating) {
  return movies.where((m) => (m.voteAverage ?? 0) >= minRating).toList();
}

/// Сортирует фильмы по рейтингу (по убыванию)
List<Movie> sortByRating(List<Movie> movies) {
  final sorted = [...movies];
  sorted.sort((a, b) => (b.voteAverage ?? 0).compareTo(a.voteAverage ?? 0));
  return sorted;
}

/// Возвращает фильмы, в названии которых есть строка query (без учёта регистра)
List<Movie> searchByTitle(List<Movie> movies, String query) {
  if (query.isEmpty) return movies;
  return movies.where((m) => m.title.toLowerCase().contains(query.toLowerCase())).toList();
}
```
