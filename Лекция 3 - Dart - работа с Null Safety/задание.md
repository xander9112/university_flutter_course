# Задание 3 — Null Safety: модель данных фильма

## Контекст

Продолжаем разработку **CineTrack**, начатую в Задании 1. В Задании 2 фильмы хранились в `Map<String, double>` — для пары «название → рейтинг» этого хватало, но у настоящего фильма десяток полей, и часть из них может отсутствовать (нет постера, не выставлен рейтинг). Хранить такое в `Map` неудобно и небезопасно: опечатка в ключе или `null` в неожиданном месте обнаружатся только во время работы программы.

В этом задании вы создадите полноценную модель данных `Movie` с применением Null Safety, набор тестовых фильмов и вспомогательные функции для работы со списком. Это чистый Dart без виджетов — экраны появятся в Задании 6 и сразу будут работать с моделью `Movie`.

## Задачи

### 1. Создать модель `Movie`

Создайте файл `lib/models/movie.dart`:

```dart
class Movie {
  final int id;
  final String title;
  final String? overview;       // nullable: описание может отсутствовать
  final String? posterPath;     // nullable: постер может отсутствовать
  final String? backdropPath;   // nullable: фоновое изображение
  final double? voteAverage;    // nullable: рейтинг может быть не выставлен
  final String releaseDate;
  final List<int> genreIds;

  const Movie({
    required this.id,
    required this.title,
    this.overview,
    this.posterPath,
    this.backdropPath,
    this.voteAverage,
    required this.releaseDate,
    this.genreIds = const [],
  });

  String get year => releaseDate.isNotEmpty ? releaseDate.substring(0, 4) : 'N/A';

  String get rating => voteAverage?.toStringAsFixed(1) ?? '—';

  String get posterUrl => posterPath != null
      ? 'https://image.tmdb.org/t/p/w500$posterPath'
      : '';
}
```

### 3. Добавить вспомогательные функции в `lib/utils/movie_utils.dart`

```dart
import '../models/movie.dart';

/// Фильтрует фильмы с рейтингом выше порога
List<Movie> filterByRating(List<Movie> movies, double minRating) {
  return movies.where((m) => (m.voteAverage ?? 0) >= minRating).toList();
}

/// Сортирует фильмы по рейтингу (по убыванию)
List<Movie> sortByRating(List<Movie> movies) {
  final sorted = [...movies];
  sorted.sort((a, b) => (b.voteAverage ?? 0).compareTo(a.voteAverage ?? 0));
  return sorted;
}

/// Возвращает фильмы, в названии которых есть строка query (без учёта регистра)
List<Movie> searchByTitle(List<Movie> movies, String query) {
  if (query.isEmpty) return movies;
  return movies.where((m) => m.title.toLowerCase().contains(query.toLowerCase())).toList();
}
```

### 4. Проверить модель и Null-aware операторы

Экранов со списком фильмов пока нет, поэтому проверьте модель через консоль. Временно добавьте в начало `main()` в `lib/main.dart` (перед `runApp`) вывод тестовых данных. Для nullable-полей используйте операторы `??` и `?.` вместо явных проверок на `null` и `!`:

```dart
import 'data/mock_movies.dart';
import 'utils/movie_utils.dart';

void main() {
  for (final movie in mockMovies) {
    // Вместо: movie.voteAverage == null ? '—' : movie.voteAverage!.toStringAsFixed(1)
    print('${movie.title} (${movie.year}) — ⭐ ${movie.voteAverage?.toStringAsFixed(1) ?? '—'}');

    // Вместо: movie.overview == null ? 'Описание отсутствует' : movie.overview!
    print('  ${movie.overview ?? 'Описание отсутствует'}');
  }

  print(filterByRating(mockMovies, 8.5).map((m) => m.title));
  print(sortByRating(mockMovies).map((m) => m.title));
  print(searchByTitle(mockMovies, 'in').map((m) => m.title));

  runApp(const MyApp());
}
```

Запустите приложение и убедитесь, что в консоли для `Parasite` выводятся «—» и «Описание отсутствует», а не `null`.
