# Задание 8 — Компоновка UI: главный экран и экран деталей

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы создадите полноценный макет приложения: главный экран с горизонтальной лентой «Популярное» и вертикальным списком, а также экран деталей фильма с постером, рейтингом и описанием.

---

## Задачи

### 1. Переработать `HomeScreen`

Разделите экран на две секции с помощью `Column`:

**Секция 1 — «Популярное» (горизонтальная лента):**
- Заголовок «Популярное»
- Горизонтальный `ListView` из 5 карточек-превью (высота ~200)

**Секция 2 — «Все фильмы» (вертикальный список):**
- Заголовок «Все фильмы»
- Вертикальный `ListView.builder`

Используйте `Expanded` для вертикального списка, чтобы он занимал оставшееся пространство:

Column(

### 2. Создать `MovieDetailScreen`

Создайте файл `lib/screens/movie_detail_screen.dart`.

Экран получает один фильм (`Movie`) через конструктор и отображает:

**Верхняя часть — `Stack` с постером и оверлеем:**
- Постер на всю ширину экрана (высота ~300)
- Поверх постера — градиентный оверлей (снизу вверх, от чёрного к прозрачному)
- Поверх оверлея — название фильма и рейтинг белым текстом

```dart
Stack(
  children: [
    Image.network(
      movie.posterUrl,
      width: double.infinity,
      height: 300,
      fit: BoxFit.cover,
      errorBuilder: (context, error, stackTrace) =>
          Container(height: 300, color: Colors.grey.shade800),
    ),
    Positioned.fill(
      child: DecoratedBox(
        decoration: BoxDecoration(
          gradient: LinearGradient(
            begin: Alignment.topCenter,
            end: Alignment.bottomCenter,
            colors: [Colors.transparent, Colors.black87],
          ),
        ),
      ),
    ),
    Positioned(
      bottom: 16,
      left: 16,
      right: 16,
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(movie.title, style: TextStyle(color: Colors.white, fontSize: 24, fontWeight: FontWeight.bold)),
          Text('⭐ ${movie.rating}', style: TextStyle(color: Colors.amber)),
        ],
      ),
    ),
  ],
)
```

**Нижняя часть — детали:**
- Год выпуска (`movie.year`), жанр (можно захардкодить)
- Описание фильма (несколько строк); если описания нет — текст-заглушка: `Text(movie.overview ?? 'Описание отсутствует')`
- Горизонтальный `Row` с характеристиками: длительность, страна, язык

### 3. Настроить переход между экранами

При нажатии на `MovieCard` — открывать `MovieDetailScreen` через `Navigator.push`. `GestureDetector` (обработка нажатий) подробно разберём в Лекции 9, а навигацию — в Лекции 10; пока используйте готовый фрагмент. В списке из Задания 7 `GestureDetector` располагается внутри `Dismissible`: `Dismissible` → `GestureDetector` → `MovieCard`.

```dart
GestureDetector(
  onTap: () {
    Navigator.push(
      context,
      MaterialPageRoute(
        builder: (_) => MovieDetailScreen(movie: movie),
      ),
    );
  },
  child: MovieCard(movie: movie),
)
```

### 4. Добавить отступы

Убедитесь, что все текстовые элементы имеют отступы от краёв экрана (минимум 16 пикселей). Используйте `Padding` или `EdgeInsets` в `Container`.
