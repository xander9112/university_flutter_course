# Лекция 8 - Основы компоновки UI

Тема лекции — базовые виджеты компоновки в Flutter: Padding, Align, Center, Container, Row/Column, Expanded, Stack и ListView.

После этой лекции студенты научатся выстраивать интерфейс из готовых виджетов, управлять отступами, выравниванием и размерами элементов, а также комбинировать линейные (Row/Column) и наложенные (Stack) макеты для создания сложных экранов. Они поймут, как распределять свободное пространство между виджетами с помощью Expanded и организовывать списки прокручиваемого контента через ListView.
