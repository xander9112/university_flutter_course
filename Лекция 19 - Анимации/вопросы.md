# Вопросы — Лекция 19: Анимации в Flutter

1. В чём главное отличие имплицитных анимаций от явных?

   a) Имплицитные анимации работают только с цветом и размером
   b) Явные анимации нельзя зациклить
   c) ✓ Имплицитные анимации работают автоматически при изменении значения, явные требуют создания `AnimationController` для ручного управления
   d) Имплицитные анимации требуют `TickerProviderStateMixin`

2. Что контролирует `AnimationController`?

   a) Тип кривой анимации (easeIn, bounceOut и т. д.)
   b) ✓ Время и прогресс анимации: запуск, остановку, реверс и значение от 0.0 до 1.0
   c) Виджеты, которые будут анимированы
   d) Только длительность анимации в миллисекундах

3. Для чего нужен параметр `vsync` в `AnimationController`?

   a) Для синхронизации анимации между двумя контроллерами
   b) Для указания начального значения анимации
   c) Для определения кривой анимации
   d) ✓ Для синхронизации анимации с частотой обновления экрана, чтобы не тратить ресурсы, когда виджет невидим

4. Что будет, если на двух разных карточках фильмов использовать одинаковый Hero-тег?

   a) Flutter автоматически разрешит конфликт и выберет ближайший виджет
   b) Анимация просто не сработает
   c) ✓ Flutter выбросит ошибку о дублирующихся Hero-тегах на одном экране
   d) Анимация воспроизведётся для обоих виджетов одновременно

5. Как ведёт себя `Curves.bounceOut`?

   a) Начинает медленно и ускоряется к концу
   b) Равномерная скорость на протяжении всей анимации
   c) Резиновый эффект в начале анимации
   d) ✓ К концу анимации значение несколько раз отскакивает от целевого, имитируя прыжок

6. Для чего используется `AnimatedSwitcher`?

   a) Для анимации перехода между экранами
   b) Для синхронного воспроизведения нескольких анимаций
   c) ✓ Для анимированной замены одного дочернего виджета другим при изменении `child`
   d) Для переключения между явными и имплицитными анимациями

7. В каком формате хранятся Lottie-анимации?

   a) MP4 — видеофайл
   b) SVG — векторная графика
   c) GIF — анимированное изображение
   d) ✓ JSON — описание векторной анимации, экспортированное из After Effects

8. Когда стоит использовать `TweenAnimationBuilder` вместо `AnimatedContainer`?

   a) Когда нужно анимировать только размер виджета
   b) Когда анимация должна зациклиться
   c) ✓ Когда нужно имплицитно анимировать произвольное значение (угол, цвет, число), которое не является встроенным свойством какого-либо виджета
