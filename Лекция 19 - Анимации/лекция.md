# Лекция 19 — Анимации в Flutter

## 1. Зачем анимации

Анимации — не украшение, а инструмент коммуникации с пользователем:

- **Обратная связь (feedback):** нажатие кнопки, добавление в избранное, загрузка данных
- **Ориентация в пространстве:** переходы между экранами показывают, «откуда пришёл» новый экран
- **Ощущение живости:** статичный UI кажется мёртвым, анимированный — отзывчивым
- **Акцент внимания:** движение направляет взгляд пользователя на важный элемент

Flutter имеет два уровня анимаций: **имплицитные** (простые, встроенные) и **явные** (гибкие, с ручным управлением).

## 2. Имплицитные анимации

Имплицитные анимации работают автоматически: вы просто меняете значение свойства, а Flutter плавно переходит от старого к новому. Контроллер создавать не нужно.

### AnimatedContainer

Плавно анимирует изменение размера, цвета, отступов, скруглений и других свойств `Container`.

```dart
class MovieCard extends StatefulWidget {
  const MovieCard({super.key});

  @override
  State<MovieCard> createState() => _MovieCardState();
}

class _MovieCardState extends State<MovieCard> {
  bool _isSelected = false;

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: () => setState(() => _isSelected = !_isSelected),
      child: AnimatedContainer(
        duration: const Duration(milliseconds: 300),
        curve: Curves.easeInOut,
        width: _isSelected ? 200 : 120,
        height: _isSelected ? 280 : 170,
        decoration: BoxDecoration(
          color: _isSelected ? Colors.deepPurple : Colors.grey[800],
          borderRadius: BorderRadius.circular(_isSelected ? 16 : 8),
          boxShadow: _isSelected
              ? [BoxShadow(blurRadius: 12, color: Colors.black45)]
              : [],
        ),
        child: const FlutterLogo(),
      ),
    );
  }
}
```

### AnimatedOpacity

Плавно меняет прозрачность виджета.

```dart
AnimatedOpacity(
  opacity: _isLoaded ? 1.0 : 0.0,
  duration: const Duration(milliseconds: 500),
  child: MovieCard(movie: movie),
)
```

### AnimatedPadding и AnimatedAlign

```dart
// Плавное изменение отступов
AnimatedPadding(
  padding: _isExpanded
      ? const EdgeInsets.all(24)
      : const EdgeInsets.all(8),
  duration: const Duration(milliseconds: 300),
  child: Text(movie.overview),
)

// Плавное перемещение виджета внутри родителя
AnimatedAlign(
  alignment: _showDetails
      ? Alignment.topCenter
      : Alignment.bottomCenter,
  duration: const Duration(milliseconds: 400),
  curve: Curves.easeOut,
  child: PosterWidget(movie: movie),
)
```

### AnimatedSwitcher

Анимирует смену одного виджета другим. Важно задавать `key` для виджетов, чтобы Flutter понял, что они разные.

```dart
AnimatedSwitcher(
  duration: const Duration(milliseconds: 300),
  transitionBuilder: (child, animation) => ScaleTransition(
    scale: animation,
    child: child,
  ),
  child: isFavorite
      ? const Icon(Icons.favorite, key: ValueKey('fav'), color: Colors.red)
      : const Icon(Icons.favorite_border, key: ValueKey('not-fav')),
)
```

### TweenAnimationBuilder

Универсальный builder для имплицитной анимации любого типа (цвет, угол, смещение).

```dart
TweenAnimationBuilder<double>(
  tween: Tween<double>(begin: 0, end: _rating / 10),
  duration: const Duration(milliseconds: 800),
  curve: Curves.easeOut,
  builder: (context, value, child) {
    return LinearProgressIndicator(value: value);
  },
)

// Анимация цвета через ColorTween
TweenAnimationBuilder<Color?>(
  tween: ColorTween(
    begin: Colors.grey,
    end: movie.isNew ? Colors.amber : Colors.white,
  ),
  duration: const Duration(milliseconds: 500),
  builder: (context, color, child) {
    return Text(
      movie.title,
      style: TextStyle(color: color),
    );
  },
)
```

## 3. Явные анимации

Явные анимации дают полный контроль: запуск, остановка, реверс, зацикливание. Необходим `AnimationController`.

### AnimationController

```dart
class LoadingWidget extends StatefulWidget {
  const LoadingWidget({super.key});

  @override
  State<LoadingWidget> createState() => _LoadingWidgetState();
}

class _LoadingWidgetState extends State<LoadingWidget>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      duration: const Duration(seconds: 1),
      vsync: this, // this реализует TickerProvider через mixin
    );
    _controller.repeat(); // зациклить
  }

  @override
  void dispose() {
    _controller.dispose(); // ВАЖНО: всегда освобождать контроллер
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return RotationTransition(
      turns: _controller, // значение 0..1 = 0°..360°
      child: const Icon(Icons.movie, size: 48),
    );
  }
}
```

### vsync и TickerProviderStateMixin

`vsync` — синхронизация анимации с частотой экрана (обычно 60 fps). Без `vsync` анимация тратила бы ресурсы, даже когда виджет не виден.

- Один контроллер → `SingleTickerProviderStateMixin`
- Несколько контроллеров → `TickerProviderStateMixin`

### Tween — диапазон значений

```dart
// Анимация от 0.0 до 1.0 (прозрачность)
final Animation<double> _fadeAnimation = Tween<double>(
  begin: 0.0,
  end: 1.0,
).animate(_controller);

// Анимация смещения
final Animation<Offset> _slideAnimation = Tween<Offset>(
  begin: const Offset(0, 1),  // снизу экрана
  end: Offset.zero,           // исходное положение
).animate(_controller);

// Анимация цвета
final Animation<Color?> _colorAnimation = ColorTween(
  begin: Colors.transparent,
  end: Colors.black87,
).animate(_controller);
```

### AnimatedBuilder — перестройка части дерева

`AnimatedBuilder` перестраивает только то, что указано в `builder`, остальное дерево (`child`) остаётся неизменным и не пересоздаётся — это эффективно.

```dart
AnimatedBuilder(
  animation: _controller,
  // child не зависит от анимации — создаётся один раз
  child: const Icon(Icons.movie, size: 48),
  builder: (context, child) {
    return Transform.rotate(
      angle: _controller.value * 2 * math.pi, // 0..1 → 0..360°
      child: child,
    );
  },
)
```

### Управление контроллером

```dart
_controller.forward();            // воспроизвести вперёд (0 → 1)
_controller.reverse();            // воспроизвести назад (1 → 0)
_controller.repeat();             // зациклить
_controller.repeat(reverse: true); // зациклить с отскоком
_controller.stop();               // остановить
_controller.reset();              // вернуть в начало (value = 0)

// Слушать статус
_controller.addStatusListener((status) {
  if (status == AnimationStatus.completed) {
    _controller.reverse();
  }
});
```

## 4. Кривые (Curves)

Кривые определяют, как меняется значение анимации во времени — равномерно, с разгоном, с отскоком.

```dart
// CurvedAnimation — обёртка над контроллером с кривой
final Animation<double> curved = CurvedAnimation(
  parent: _controller,
  curve: Curves.easeInOut,
);

final Animation<double> bouncy = CurvedAnimation(
  parent: _controller,
  curve: Curves.bounceOut,
);
```

| Кривая | Поведение |
|--------|-----------|
| `Curves.linear` | Равномерная скорость |
| `Curves.easeIn` | Начинает медленно, ускоряется |
| `Curves.easeOut` | Начинает быстро, замедляется |
| `Curves.easeInOut` | Медленно → быстро → медленно |
| `Curves.bounceOut` | В конце отскакивает |
| `Curves.elasticIn` | Резиновый эффект в начале |
| `Curves.fastOutSlowIn` | Стандарт Material Design |

```dart
// Пример: slide-анимация с easeOut
final _slideAnimation = Tween<Offset>(
  begin: const Offset(0, 0.3),
  end: Offset.zero,
).animate(
  CurvedAnimation(parent: _controller, curve: Curves.easeOut),
);

SlideTransition(position: _slideAnimation, child: content)
```

## 5. Hero-анимации

Hero-анимация автоматически перемещает виджет с одного экрана на другой при навигации. Нужно только задать одинаковый `tag` на обоих экранах.

```dart
// HomeScreen — карточка фильма
Hero(
  tag: 'movie-poster-${movie.id}', // уникальный тег для каждого фильма
  child: ClipRRect(
    borderRadius: BorderRadius.circular(8),
    child: Image.network(
      movie.posterUrl,
      width: 120,
      height: 170,
      fit: BoxFit.cover,
    ),
  ),
)

// MovieDetailScreen — постер на экране деталей
Hero(
  tag: 'movie-poster-${movie.id}', // тот же тег!
  child: Image.network(
    movie.posterUrl,
    width: double.infinity,
    height: 300,
    fit: BoxFit.cover,
  ),
)
```

При переходе Flutter сам анимирует постер из одного положения в другое. Никакого дополнительного кода не нужно.

**Важно:** теги должны быть уникальными — если на экране несколько одинаковых тегов, Flutter выбросит ошибку.

## 6. Кастомные переходы между экранами

Стандартный `MaterialPageRoute` использует переход, принятый на платформе: на Android — плавное появление с увеличением (zoom), на iOS — сдвиг нового экрана справа. Чтобы сделать свой переход — используем `PageRouteBuilder`.

```dart
// Fade-переход (постепенное появление)
Navigator.push(
  context,
  PageRouteBuilder(
    pageBuilder: (context, animation, secondaryAnimation) =>
        MovieDetailScreen(movie: movie),
    transitionsBuilder: (context, animation, secondaryAnimation, child) {
      return FadeTransition(
        opacity: animation,
        child: child,
      );
    },
    transitionDuration: const Duration(milliseconds: 400),
  ),
);

// Slide-переход снизу вверх
PageRouteBuilder(
  pageBuilder: (_, animation, __) => MovieDetailScreen(movie: movie),
  transitionsBuilder: (_, animation, __, child) {
    final tween = Tween<Offset>(
      begin: const Offset(0, 1), // начальная позиция: ниже экрана
      end: Offset.zero,
    ).chain(CurveTween(curve: Curves.easeOut));

    return SlideTransition(
      position: animation.drive(tween),
      child: child,
    );
  },
)

// Scale-переход (появление из точки)
PageRouteBuilder(
  pageBuilder: (_, animation, __) => MovieDetailScreen(movie: movie),
  transitionsBuilder: (_, animation, __, child) {
    return ScaleTransition(
      scale: Tween<double>(begin: 0.8, end: 1.0).animate(
        CurvedAnimation(parent: animation, curve: Curves.easeOut),
      ),
      child: FadeTransition(opacity: animation, child: child),
    );
  },
)
```

В примерах выше экран создаётся через конструктор. Если в приложении используются именованные маршруты (как в CineTrack с Лекции 10), маршрут с собственным переходом создают в `onGenerateRoute` у `MaterialApp`: имя маршрута убирают из таблицы `routes`, а в `PageRouteBuilder` передают `settings: settings`, чтобы экран по-прежнему получал `arguments` через `ModalRoute.of(context)`.

## 7. Lottie-анимации

Lottie — формат векторных анимаций из After Effects (JSON-файл). Выглядят профессионально и весят мало.

### Установка

```yaml
dependencies:
  lottie: ^3.1.0
```

### Использование

```dart
// Из assets
Lottie.asset('assets/animations/loading.json')

// Из сети
Lottie.network(
  'https://assets.lottiefiles.com/packages/lf20_xxxx.json',
)

// Управление воспроизведением
class LottieExample extends StatefulWidget {
  @override
  State<LottieExample> createState() => _LottieExampleState();
}

class _LottieExampleState extends State<LottieExample>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(vsync: this);
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Lottie.asset(
      'assets/animations/empty_favorites.json',
      controller: _controller,
      onLoaded: (composition) {
        _controller
          ..duration = composition.duration
          ..repeat();
      },
      width: 200,
      height: 200,
    );
  }
}
```

Добавьте в `pubspec.yaml`:

```yaml
flutter:
  assets:
    - assets/animations/
```

Бесплатные анимации: [lottiefiles.com](https://lottiefiles.com) — ищите «loading», «empty», «success», «error».
