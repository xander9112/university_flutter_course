# Лекция 2 - Dart - Синтаксис и основы

Тема лекции — базовый синтаксис языка Dart: переменные, типы данных, операторы, управляющие конструкции и функции.

В лекции рассматриваются основные типы данных (int, double, String, bool), ключевые слова var, final и const, работа со строками и их интерполяция, арифметические и логические операторы, конструкции if/else, switch и циклы (for, for-in, while, do-while). Отдельно разбираются функции с позиционными и именованными параметрами, стрелочный синтаксис, коллекции (List, Set, Map) и основы null safety — nullable-типы и операторы `??` и `?.`.
