## 1. Что такое Dart

**Dart** — это язык программирования, созданный компанией **Google**. Он был разработан специально для того, чтобы писать быстрые и удобные приложения.

Главная особенность Dart — он умеет **компилироваться** (то есть превращаться в машинный код) двумя способами:
- В **нативный код** — программа запускается напрямую на устройстве (телефоне, компьютере) и работает очень быстро.
- В **JavaScript** — программа может запускаться в браузере.

Для нас самое важное: именно Dart используется во **Flutter** — фреймворке для создания мобильных, веб- и десктопных приложений. Если вы хотите делать приложения на Flutter, Dart — это первый шаг.

### Как начать без установки: DartPad

Чтобы попробовать Dart прямо сейчас, не нужно ничего устанавливать. Откройте браузер и перейдите по адресу:

**https://dartpad.dev**

Это онлайн-редактор кода. Вы пишете программу слева — нажимаете кнопку **Run** — видите результат справа. Именно в DartPad мы будем отрабатывать все примеры этой лекции.

Вот самая первая программа на Dart — она просто выводит текст на экран:

```dart
void main() {
  print('Привет, мир!');
}
```

Что здесь происходит:
- `void main()` — точка входа в программу. Каждая Dart-программа начинает выполнение с функции `main`.
- `print(...)` — встроенная команда, которая выводит текст в консоль.
- Строки текста в Dart заключаются в кавычки: `'Привет, мир!'`.
- В конце каждой команды ставится точка с запятой `;`.

Скопируйте этот код в DartPad и нажмите Run. Вы должны увидеть:

```
Привет, мир!
```

Поздравляем — вы только что запустили свою первую программу!

## 2. Переменные и типы данных

**Переменная** — это именованная ячейка памяти, в которой хранится какое-то значение. Представьте коробку с наклейкой: наклейка — это имя переменной, а то, что лежит внутри — её значение.

В Dart каждая переменная имеет **тип** — то есть заранее известно, что именно в ней хранится: число, текст, флаг "да/нет" и так далее.

### int — целые числа

`int` хранит целые числа: ..., -2, -1, 0, 1, 2, 3, ...

```dart
void main() {
  int age = 20;
  int year = 2024;
  int temperature = -5;

  print(age);         // 20
  print(year);        // 2024
  print(temperature); // -5
}
```

### double — числа с дробной частью

`double` хранит числа с плавающей точкой (дроби):

```dart
void main() {
  double height = 1.75;
  double pi = 3.14159;
  double discount = 0.15;

  print(height);   // 1.75
  print(pi);       // 3.14159
  print(discount); // 0.15
}
```

Важно: в Dart (и в большинстве языков программирования) дробная часть отделяется **точкой**, а не запятой.

### String — строки (текст)

`String` хранит текст — любую последовательность символов:

```dart
void main() {
  String name = 'Алексей';
  String city = 'Москва';
  String greeting = 'Добро пожаловать!';

  print(name);     // Алексей
  print(city);     // Москва
  print(greeting); // Добро пожаловать!
}
```

### bool — логическое значение (истина/ложь)

`bool` хранит одно из двух значений: `true` (истина) или `false` (ложь):

```dart
void main() {
  bool isStudent = true;
  bool isMarried = false;
  bool hasDiscount = true;

  print(isStudent);   // true
  print(isMarried);   // false
  print(hasDiscount); // true
}
```

Тип `bool` очень важен — он используется в условиях (`if`, `while` и т.д.), которые мы рассмотрим позже.

### var — автоматическое определение типа

Когда вы пишете `var`, Dart сам определяет тип переменной по тому значению, которое вы присваиваете. Это называется **выводом типа** (type inference):

```dart
void main() {
  var name = 'Мария';    // Dart понимает: это String
  var age = 21;          // Dart понимает: это int
  var gpa = 4.8;         // Dart понимает: это double
  var isActive = true;   // Dart понимает: это bool

  print(name);     // Мария
  print(age);      // 21
  print(gpa);      // 4.8
  print(isActive); // true
}
```

После того как тип определён через `var`, изменить его нельзя. Если `name` — это `String`, то нельзя записать в неё число:

```dart
void main() {
  var name = 'Мария';
  name = 123; // ОШИБКА! name — это String, нельзя записать int
}
```

### final — значение нельзя изменить после присвоения

Иногда нужно создать переменную, которая получит значение один раз и больше не изменится. Для этого используется `final`:

```dart
void main() {
  final String country = 'Россия';
  final int foundingYear = 2024;

  print(country);      // Россия
  print(foundingYear); // 2024

  // country = 'США'; // ОШИБКА! final-переменную нельзя переприсвоить
}
```

С `final` можно не указывать тип — Dart определит его сам:

```dart
void main() {
  final name = 'Иван';
  final pi = 3.14159;
  print(name); // Иван
  print(pi);   // 3.14159
}
```

### const — константа времени компиляции

`const` похож на `final`, но строже: значение должно быть известно **до запуска программы**, в момент компиляции.

```dart
void main() {
  const double pi = 3.14159;
  const int maxScore = 100;
  const String appName = 'МойПроект';

  print(pi);       // 3.14159
  print(maxScore); // 100
  print(appName);  // МойПроект
}
```

### Разница между final и const

Это важное различие, которое часто проверяют на экзаменах:

| | `final` | `const` |
|---|---|---|
| Когда определяется значение | во время выполнения программы | во время компиляции |
| Можно ли использовать результат функции | да | нет |
| Можно ли переприсвоить | нет | нет |

```dart
void main() {
  // final может получить значение во время выполнения:
  final currentTime = DateTime.now(); // OK! Время вычисляется при запуске
  print(currentTime);

  // const должна знать значение ЕЩЁ ДО запуска:
  // const time = DateTime.now(); // ОШИБКА! DateTime.now() неизвестен заранее

  const maxSpeed = 300; // OK! 300 — это литерал, известен заранее
  print(maxSpeed);
}
```

Правило на практике: используйте `const` для магических чисел и строк, которые никогда не меняются (например, цвета, заголовки, URL). Используйте `final` для всего остального, что не должно изменяться.

### dynamic — динамический тип

`dynamic` — особый тип: переменная с таким типом может хранить **любое значение любого типа**, и этот тип может меняться:

```dart
void main() {
  dynamic value = 'привет';
  print(value); // привет

  value = 42;
  print(value); // 42

  value = true;
  print(value); // true
}
```

Звучит удобно, но на практике `dynamic` — это плохая практика. Почему?

1. Dart теряет возможность проверить ошибки заранее.
2. Среда разработки не подсказывает, какие методы доступны.
3. Программа может упасть с ошибкой там, где Dart мог бы предупредить вас ещё при написании кода.

**Вывод:** используйте конкретные типы или `var`. Избегайте `dynamic`, если нет весомой причины.

## 3. Строки

Строки в Dart — это объекты типа `String`. У них есть множество встроенных возможностей.

### Одинарные и двойные кавычки

В Dart строку можно заключить как в одинарные, так и в двойные кавычки — результат одинаковый:

```dart
void main() {
  String s1 = 'Одинарные кавычки';
  String s2 = "Двойные кавычки";

  print(s1); // Одинарные кавычки
  print(s2); // Двойные кавычки
}
```

Если внутри строки нужна кавычка того же типа — используйте обратный слеш `\` для экранирования:

```dart
void main() {
  String s1 = 'Он сказал: \'Привет!\'';
  String s2 = "Размер: 5\"";

  print(s1); // Он сказал: 'Привет!'
  print(s2); // Размер: 5"
}
```

Или просто используйте другой тип кавычек:

```dart
void main() {
  String s1 = "Он сказал: 'Привет!'";  // внутри двойных — одинарные
  String s2 = 'Размер экрана: 6"';     // внутри одинарных — двойные
  print(s1);
  print(s2);
}
```

### Многострочные строки

Если текст занимает несколько строк, используйте тройные кавычки `'''...'''` или `"""..."""`:

```dart
void main() {
  String poem = '''
  Буря мглою небо кроет,
  Вихри снежные крутя;
  То, как зверь, она завоет,
  То заплачет, как дитя.
  ''';

  print(poem);
}
```

### Интерполяция строк

**Интерполяция** — это вставка значения переменной прямо в строку. В Dart для этого используется знак `$`:

```dart
void main() {
  String name = 'Анна';
  int age = 19;

  String message = 'Привет, $name! Тебе $age лет.';
  print(message); // Привет, Анна! Тебе 19 лет.
}
```

Если нужно вставить результат **выражения** (не просто переменную), используйте фигурные скобки `${}`:

```dart
void main() {
  String name = 'анна';
  double price = 199.9;
  int count = 3;

  // Вызов метода внутри строки
  print('Имя заглавными буквами: ${name.toUpperCase()}');
  // Имя заглавными буквами: АННА

  // Арифметическое выражение
  print('Итого: ${price * count} рублей');
  // Итого: 599.7 рублей
}
```

Правило: одиночная переменная — `$name`, любое выражение — `${...}`.

### Основные методы строк

У типа `String` есть много полезных методов. Разберём самые нужные:

```dart
void main() {
  String text = '  Привет, Flutter!  ';

  // .length — количество символов в строке
  print(text.length); // 20 (включая пробелы)

  // .trim() — убирает пробелы в начале и конце
  String trimmed = text.trim();
  print(trimmed); // 'Привет, Flutter!'

  // .toUpperCase() — все буквы в верхний регистр
  print(trimmed.toUpperCase()); // ПРИВЕТ, FLUTTER!

  // .toLowerCase() — все буквы в нижний регистр
  print(trimmed.toLowerCase()); // привет, flutter!

  // .contains() — содержит ли строка подстроку
  print(trimmed.contains('Flutter')); // true
  print(trimmed.contains('React'));   // false

  // .split() — разбить строку на список по разделителю
  String csv = 'яблоко,груша,банан,слива';
  List<String> fruits = csv.split(',');
  print(fruits); // [яблоко, груша, банан, слива]

  // .replaceAll() — заменить все вхождения
  String result = trimmed.replaceAll('Flutter', 'Dart');
  print(result); // Привет, Dart!

  // .startsWith() и .endsWith()
  print(trimmed.startsWith('Привет')); // true
  print(trimmed.endsWith('!'));        // true
}
```

## 4. Операторы

**Операторы** — это специальные символы, которые выполняют операции над значениями.

### Арифметические операторы

```dart
void main() {
  int a = 17;
  int b = 5;

  print(a + b);  // 22  — сложение
  print(a - b);  // 12  — вычитание
  print(a * b);  // 85  — умножение
  print(a / b);  // 3.4 — деление (результат всегда double!)
  print(a ~/ b); // 3   — целочисленное деление (отбрасывает дробь)
  print(a % b);  // 2   — остаток от деления (17 = 5*3 + 2)
}
```

Обратите особое внимание на оператор `~/` (тильда-слеш) — он делит и **отбрасывает дробную часть**, результат всегда `int`. Это не то же самое, что `/`, который всегда даёт `double`.

```dart
void main() {
  print(10 / 3);   // 3.3333... (double)
  print(10 ~/ 3);  // 3        (int)
  print(10 % 3);   // 1        (остаток: 10 = 3*3 + 1)
}
```

### Операторы сравнения

Эти операторы **сравнивают** два значения и возвращают `bool` (`true` или `false`):

```dart
void main() {
  int x = 10;
  int y = 7;

  print(x == y); // false — равны ли?
  print(x != y); // true  — не равны ли?
  print(x > y);  // true  — x больше y?
  print(x < y);  // false — x меньше y?
  print(x >= y); // true  — x больше или равно y?
  print(x <= y); // false — x меньше или равно y?
}
```

### Логические операторы

Используются для объединения нескольких условий:

```dart
void main() {
  bool isSunny = true;
  bool isWarm = false;
  bool isRaining = false;

  // && (И) — оба условия должны быть истинными
  print(isSunny && isWarm);    // false (одно из условий ложно)
  print(isSunny && !isRaining); // true  (оба истинны)

  // || (ИЛИ) — хотя бы одно условие должно быть истинным
  print(isSunny || isWarm);   // true  (хотя бы одно истинно)
  print(isWarm || isRaining); // false (оба ложны)

  // ! (НЕ) — инверсия
  print(!isSunny);   // false
  print(!isRaining); // true
}
```

### Операторы присваивания

```dart
void main() {
  int score = 10;

  score += 5;  // то же, что score = score + 5; → 15
  score -= 3;  // то же, что score = score - 3; → 12
  score *= 2;  // то же, что score = score * 2; → 24
  score ~/= 4; // то же, что score = score ~/ 4; → 6

  print(score); // 6

  // Инкремент и декремент
  score++;  // score = score + 1 → 7
  score--;  // score = score - 1 → 6
  print(score); // 6
}
```

## 5. Управляющие конструкции

Программы не всегда выполняются строчка за строчкой. Управляющие конструкции позволяют **принимать решения** и **повторять действия**.

### if / else if / else

Самая базовая конструкция — условие. "Если ... то ... иначе ...":

```dart
void main() {
  int score = 75;

  if (score >= 90) {
    print('Отлично');
  } else if (score >= 75) {
    print('Хорошо');
  } else if (score >= 60) {
    print('Удовлетворительно');
  } else {
    print('Неудовлетворительно');
  }
  // Выведет: Хорошо
}
```

Dart проверяет условия сверху вниз и выполняет **первый** подходящий блок. Остальные игнорируются.

### Тернарный оператор

Это краткая форма `if/else` для случаев, когда нужно выбрать одно из двух значений:

```dart
// Синтаксис: условие ? значение_если_истина : значение_если_ложь

void main() {
  int age = 20;
  String status = age >= 18 ? 'взрослый' : 'несовершеннолетний';
  print(status); // взрослый

  int temperature = -3;
  String weather = temperature > 0 ? 'плюсовая температура' : 'минусовая температура';
  print(weather); // минусовая температура
}
```

### switch / case

Когда нужно проверить одну переменную на несколько конкретных значений, `switch` удобнее, чем длинная цепочка `if/else if`:

```dart
void main() {
  // Пример с числом
  int day = 3;

  switch (day) {
    case 1:
      print('Понедельник');
      break;
    case 2:
      print('Вторник');
      break;
    case 3:
      print('Среда');
      break;
    case 4:
      print('Четверг');
      break;
    case 5:
      print('Пятница');
      break;
    default:
      print('Выходной');
  }
  // Выведет: Среда
}
```

```dart
void main() {
  // Пример со строкой
  String command = 'старт';

  switch (command) {
    case 'старт':
      print('Запускаем программу...');
      break;
    case 'стоп':
      print('Останавливаем программу...');
      break;
    case 'пауза':
      print('Программа на паузе');
      break;
    default:
      print('Неизвестная команда: $command');
  }
}
```

Ключевое слово `break` обязательно в конце каждого `case` — оно говорит "выйти из switch". Без него выполнение "провалится" в следующий `case`.

### Цикл for (классический)

Цикл позволяет **повторить** блок кода несколько раз:

```dart
void main() {
  // Напечатаем числа от 1 до 5
  for (int i = 1; i <= 5; i++) {
    print('Число: $i');
  }
  // Число: 1
  // Число: 2
  // Число: 3
  // Число: 4
  // Число: 5
}
```

Разбор структуры `for (начало; условие; шаг)`:
- `int i = 1` — создаём переменную-счётчик `i`, начинаем с 1
- `i <= 5` — продолжаем, пока `i` не превысит 5
- `i++` — после каждого шага увеличиваем `i` на 1

```dart
void main() {
  // Таблица умножения на 3
  for (int i = 1; i <= 10; i++) {
    print('3 × $i = ${3 * i}');
  }
}
```

### Цикл for-in

Если нужно пройтись по каждому элементу коллекции (списка, множества), удобен `for-in`:

```dart
void main() {
  List<String> cities = ['Москва', 'Казань', 'Екатеринбург', 'Новосибирск'];

  for (String city in cities) {
    print('Город: $city');
  }
  // Город: Москва
  // Город: Казань
  // Город: Екатеринбург
  // Город: Новосибирск
}
```

### Цикл while

Цикл `while` повторяется, пока условие истинно. Удобен, когда не знаем заранее, сколько раз нужно повторить:

```dart
void main() {
  int count = 0;

  while (count < 5) {
    print('Итерация: $count');
    count++; // не забудьте изменять условие, иначе цикл бесконечный!
  }
  // Итерация: 0
  // Итерация: 1
  // ...
  // Итерация: 4
}
```

### Цикл do-while

Отличие от `while`: тело цикла выполнится **хотя бы один раз**, а потом проверяется условие:

```dart
void main() {
  int number = 10;

  do {
    print('Значение: $number');
    number--;
  } while (number > 8);
  // Значение: 10
  // Значение: 9
  // (условие number > 8 стало ложным, цикл завершился)
}
```

### break и continue

`break` — **прервать** цикл досрочно:

```dart
void main() {
  for (int i = 1; i <= 10; i++) {
    if (i == 5) {
      break; // выходим из цикла, когда i == 5
    }
    print(i);
  }
  // 1, 2, 3, 4
}
```

`continue` — **пропустить** текущую итерацию и перейти к следующей:

```dart
void main() {
  for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
      continue; // пропускаем чётные числа
    }
    print(i);
  }
  // 1, 3, 5, 7, 9
}
```

## 6. Функции

**Функция** — это именованный блок кода, который выполняет определённую задачу и может быть вызван многократно. Функции помогают избежать повторения одного и того же кода.

### Объявление функции с типами

```dart
// Синтаксис:
// тип_результата имяФункции(тип_параметра имя_параметра) {
//   тело функции
//   return результат;
// }

int add(int a, int b) {
  return a + b;
}

double circleArea(double radius) {
  return 3.14159 * radius * radius;
}

void main() {
  int sum = add(5, 3);
  print(sum); // 8

  double area = circleArea(7.0);
  print(area); // 153.938...
}
```

### Функция без возвращаемого значения (void)

Если функция ничего не возвращает (только выполняет действия), используется ключевое слово `void`:

```dart
void printGreeting(String name) {
  print('Привет, $name! Добро пожаловать на курс.');
}

void printLine() {
  print('----------------------------');
}

void main() {
  printLine();
  printGreeting('Дмитрий');
  printLine();
  printGreeting('Екатерина');
  printLine();
}
```

`void` означает "пустота" — функция работает, но ничего не возвращает.

### Позиционные параметры

Параметры, которые передаются по порядку — это **позиционные параметры**:

```dart
String buildProfile(String name, int age, String city) {
  return '$name, $age лет, г. $city';
}

void main() {
  // Аргументы передаются в том же порядке, что параметры
  print(buildProfile('Ольга', 22, 'Санкт-Петербург'));
  // Ольга, 22 лет, г. Санкт-Петербург

  print(buildProfile('Максим', 25, 'Казань'));
  // Максим, 25 лет, г. Казань
}
```

### Именованные параметры

Именованные параметры заключаются в фигурные скобки `{}`. При вызове нужно указывать **имя** параметра:

```dart
// required — параметр обязателен
// int age = 0 — параметр необязателен, есть значение по умолчанию
String createCard({required String name, required String role, int experience = 0}) {
  return '$name | $role | Опыт: $experience лет';
}

void main() {
  // При вызове указываем имена параметров
  print(createCard(name: 'Наталья', role: 'Разработчик', experience: 3));
  // Наталья | Разработчик | Опыт: 3 лет

  // experience не указан — используется значение по умолчанию (0)
  print(createCard(name: 'Артём', role: 'Дизайнер'));
  // Артём | Дизайнер | Опыт: 0 лет

  // Порядок именованных параметров не важен!
  print(createCard(role: 'Менеджер', experience: 5, name: 'Светлана'));
  // Светлана | Менеджер | Опыт: 5 лет
}
```

Преимущество именованных параметров: код при вызове читается как предложение — понятно, что передаётся.

### Опциональные позиционные параметры

Параметры в квадратных скобках `[]` необязательны. Они позиционные (без имени при вызове), но могут быть пропущены:

```dart
String greetUser(String name, [String? title]) {
  if (title != null) {
    return 'Здравствуйте, $title $name!';
  }
  return 'Здравствуйте, $name!';
}

void main() {
  print(greetUser('Иванов'));          // Здравствуйте, Иванов!
  print(greetUser('Петрова', 'доктор')); // Здравствуйте, доктор Петрова!
}
```

### Стрелочный синтаксис (=>)

Если тело функции состоит из **одного выражения**, можно использовать сокращённую запись со стрелкой `=>`:

```dart
// Полная запись:
int square(int x) {
  return x * x;
}

// Стрелочная запись — то же самое:
int squareShort(int x) => x * x;

bool isAdult(int age) => age >= 18;

String getInitials(String first, String last) => '${first[0]}.${last[0]}.';

void main() {
  print(square(5));           // 25
  print(squareShort(5));      // 25
  print(isAdult(20));         // true
  print(isAdult(15));         // false
  print(getInitials('Иван', 'Петров')); // И.П.
}
```

### Функции как объекты первого класса

В Dart функции — это **объекты**. Это значит, что функцию можно:
- сохранить в переменную
- передать в другую функцию как параметр
- вернуть из функции

```dart
void sayHello(String name) {
  print('Привет, $name!');
}

void sayBye(String name) {
  print('Пока, $name!');
}

// Функция принимает другую функцию как параметр
void greetAll(List<String> names, void Function(String) greetFunction) {
  for (String name in names) {
    greetFunction(name);
  }
}

void main() {
  List<String> students = ['Алиса', 'Борис', 'Вера'];

  greetAll(students, sayHello);
  // Привет, Алиса!
  // Привет, Борис!
  // Привет, Вера!

  print('---');

  greetAll(students, sayBye);
  // Пока, Алиса!
  // Пока, Борис!
  // Пока, Вера!
}
```

### Анонимные функции и лямбды

Анонимная функция — функция **без имени**. Часто используется там, где функция нужна только один раз:

```dart
void main() {
  List<int> numbers = [1, 2, 3, 4, 5];

  // Анонимная функция передаётся в forEach
  numbers.forEach((number) {
    print('Число: $number, квадрат: ${number * number}');
  });

  // То же самое стрелочной нотацией (лямбда)
  numbers.forEach((n) => print('$n * $n = ${n * n}'));

  // Сохранение анонимной функции в переменную
  var double = (int x) => x * 2;
  print(double(7)); // 14
}
```

## 7. Коллекции

**Коллекции** — это структуры данных для хранения нескольких значений.

### List — список

`List` — упорядоченная последовательность элементов. Элементы нумеруются с нуля (индекс 0, 1, 2, ...).

```dart
void main() {
  // Создание списка
  List<String> fruits = ['яблоко', 'груша', 'банан', 'апельсин'];
  List<int> scores = [85, 92, 78, 95, 88];

  // Доступ по индексу (нумерация с 0!)
  print(fruits[0]); // яблоко
  print(fruits[2]); // банан

  // Количество элементов
  print(fruits.length); // 4

  // Добавить в конец
  fruits.add('слива');
  print(fruits); // [яблоко, груша, банан, апельсин, слива]

  // Удалить элемент
  fruits.remove('груша');
  print(fruits); // [яблоко, банан, апельсин, слива]

  // Проверить наличие элемента
  print(fruits.contains('банан')); // true
  print(fruits.contains('манго')); // false

  // Перебор элементов
  for (String fruit in fruits) {
    print('Фрукт: $fruit');
  }

  // Полезные методы
  print(scores.first);  // 85 — первый элемент
  print(scores.last);   // 88 — последний элемент
  scores.sort();
  print(scores); // [78, 85, 88, 92, 95] — отсортированный
}
```

### Set — множество

`Set` — коллекция **уникальных** элементов. Повторяющиеся значения автоматически игнорируются. Порядок элементов не гарантирован.

```dart
void main() {
  // Создание множества
  Set<String> tags = {'dart', 'flutter', 'mobile', 'dart'}; // 'dart' дважды!
  print(tags); // {dart, flutter, mobile} — дубликат удалён!

  // Добавить элемент
  tags.add('google');
  print(tags); // {dart, flutter, mobile, google}

  // Добавить уже существующий — ничего не изменится
  tags.add('flutter');
  print(tags.length); // 4 (не 5!)

  // Проверить наличие
  print(tags.contains('dart'));    // true
  print(tags.contains('android')); // false

  // Удалить
  tags.remove('google');
  print(tags); // {dart, flutter, mobile}

  // Операции над множествами
  Set<int> setA = {1, 2, 3, 4, 5};
  Set<int> setB = {3, 4, 5, 6, 7};

  print(setA.intersection(setB)); // {3, 4, 5} — пересечение
  print(setA.union(setB));        // {1, 2, 3, 4, 5, 6, 7} — объединение
  print(setA.difference(setB));   // {1, 2} — разность
}
```

Когда использовать `Set` вместо `List`? Когда важна уникальность элементов и не важен порядок (например: уникальные теги, ID пользователей, коды купонов).

### Map — словарь (ключ — значение)

`Map` хранит пары "ключ → значение". Ключи уникальны.

```dart
void main() {
  // Создание Map
  Map<String, int> ages = {
    'Алексей': 22,
    'Мария': 19,
    'Дмитрий': 25,
    'Екатерина': 21,
  };

  // Доступ по ключу
  print(ages['Мария']); // 19

  // Добавить или изменить
  ages['Сергей'] = 23;
  ages['Алексей'] = 23; // обновляем значение

  // Проверить наличие ключа
  print(ages.containsKey('Дмитрий')); // true
  print(ages.containsKey('Иван'));    // false

  // Проверить наличие значения
  print(ages.containsValue(19)); // true

  // Все ключи и все значения
  print(ages.keys);   // (Алексей, Мария, Дмитрий, Екатерина, Сергей)
  print(ages.values); // (23, 19, 25, 21, 23)

  // Количество пар
  print(ages.length); // 5

  // Перебор всех пар
  ages.forEach((name, age) {
    print('$name — $age лет');
  });

  // Удалить по ключу
  ages.remove('Сергей');
}
```

### Spread-оператор (...)

Оператор `...` позволяет "развернуть" коллекцию и вставить её элементы в другую коллекцию:

```dart
void main() {
  List<int> firstHalf = [1, 2, 3];
  List<int> secondHalf = [4, 5, 6];

  // Объединяем два списка в один
  List<int> all = [...firstHalf, ...secondHalf];
  print(all); // [1, 2, 3, 4, 5, 6]

  // Можно добавлять и обычные элементы
  List<String> base = ['яблоко', 'груша'];
  List<String> extra = ['манго'];
  List<String> menu = [...base, 'банан', ...extra, 'слива'];
  print(menu); // [яблоко, груша, банан, манго, слива]
}
```

### Collection if и collection for

В Dart можно использовать `if` и `for` прямо внутри создания коллекции:

```dart
void main() {
  bool showAdmin = true;

  // Collection if — элемент добавляется условно
  List<String> menuItems = [
    'Главная',
    'Профиль',
    'Настройки',
    if (showAdmin) 'Администрирование', // добавится только если showAdmin == true
  ];
  print(menuItems);
  // [Главная, Профиль, Настройки, Администрирование]

  // Collection for — генерация элементов из другой коллекции
  List<int> numbers = [1, 2, 3, 4, 5];
  List<String> labels = [
    for (int n in numbers) 'Элемент $n',
  ];
  print(labels);
  // [Элемент 1, Элемент 2, Элемент 3, Элемент 4, Элемент 5]
}
```

## 8. Null Safety — безопасность от null

**Null** — это специальное значение, означающее "ничего", "отсутствие значения". В старых языках программирования переменная могла неожиданно оказаться `null`, что вызывало ошибки. Dart решает эту проблему системой **Null Safety**.

### Все типы по умолчанию не-nullable

В Dart по умолчанию ни одна переменная не может быть `null`. Если вы объявили `String name`, в ней **гарантированно** будет строка:

```dart
void main() {
  String name = 'Алексей';
  // name = null; // ОШИБКА! String не может быть null

  int age = 20;
  // age = null; // ОШИБКА! int не может быть null
}
```

### Nullable-типы: String?

Если переменная **может** быть `null`, добавьте `?` к типу:

```dart
void main() {
  String? nickname = null; // OK! String? может быть null
  print(nickname); // null

  nickname = 'FlutterDev';
  print(nickname); // FlutterDev

  int? phoneExtension;
  print(phoneExtension); // null (неинициализированная nullable переменная = null)
}
```

### Оператор ?? — значение по умолчанию

Оператор `??` ("если null, то...") возвращает левый операнд, если он не null, иначе — правый:

```dart
void main() {
  String? userName = null;
  String displayName = userName ?? 'Гость';
  print(displayName); // Гость (userName был null)

  String? city = 'Москва';
  String location = city ?? 'Местоположение неизвестно';
  print(location); // Москва (city не null, возвращается он)

  int? score = null;
  int finalScore = score ?? 0;
  print(finalScore); // 0
}
```

### Оператор ?. — безопасный вызов

Если переменная может быть `null`, нельзя вызывать её методы напрямую — это вызовет ошибку. Используйте `?.`:

```dart
void main() {
  String? name = 'привет';

  // Безопасный вызов: если name не null — вызовет toUpperCase()
  // если name null — вернёт null, ошибки не будет
  print(name?.toUpperCase()); // ПРИВЕТ

  name = null;
  print(name?.toUpperCase()); // null (не ошибка!)
  print(name?.length);        // null

  // Комбинация ?. и ??
  String result = name?.toUpperCase() ?? 'ИМЯ НЕ УКАЗАНО';
  print(result); // ИМЯ НЕ УКАЗАНО
}
```

Это один из важнейших паттернов в Dart при работе с данными, которые могут отсутствовать — например, при получении данных из сети.
