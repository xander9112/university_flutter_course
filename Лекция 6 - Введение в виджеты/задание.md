# Задание 6 — Первые виджеты: карточка фильма и главный экран

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы создадите первые визуальные компоненты: виджет карточки фильма и главный экран со списком фильмов. Данные пока будут захардкожены — подключение к API будет в Лекции 11.

---

## Задачи

### 1. Подключить шрифт

Скачайте шрифт **Nunito** (или любой другой из Google Fonts) и подключите его через `pubspec.yaml`:

```yaml
flutter:
  fonts:
    - family: Nunito
      fonts:
        - asset: assets/fonts/Nunito-Regular.ttf
        - asset: assets/fonts/Nunito-Bold.ttf
          weight: 700
```

Установите его как шрифт по умолчанию в `MaterialApp`:

```dart
theme: ThemeData(
  fontFamily: 'Nunito',
),
```

### 2. Создать `MovieCard` (StatelessWidget)

Создайте файл `lib/widgets/movie_card.dart`.

Виджет принимает параметры:
- `title` (String) — название фильма
- `year` (String) — год выпуска
- `rating` (double) — рейтинг от 0 до 10
- `imageUrl` (String) — ссылка на постер (пока используйте placeholder)

Карточка должна содержать:
- Изображение постера (используйте `Image.network` с `errorBuilder` для placeholder)
- Название фильма жирным шрифтом
- Год выпуска серым цветом
- Рейтинг со звёздочкой (например: ⭐ 8.4)

Пример минимальной структуры:

```dart
class MovieCard extends StatelessWidget {
  final String title;
  final String year;
  final double rating;
  final String imageUrl;

  const MovieCard({
    super.key,
    required this.title,
    required this.year,
    required this.rating,
    required this.imageUrl,
  });

  @override
  Widget build(BuildContext context) {
    // Ваша реализация
  }
}
```

### 3. Создать `HomeScreen` (StatefulWidget)

Создайте файл `lib/screens/home_screen.dart`.

Экран содержит:
- `AppBar` с названием «CineTrack»
- `ListView` с 5 хардкоженными карточками фильмов

Хардкоженные данные (добавьте в тело класса):

```dart
final List<Map<String, dynamic>> _movies = [
  {'title': 'Inception', 'year': '2010', 'rating': 8.8, 'imageUrl': ''},
  {'title': 'Interstellar', 'year': '2014', 'rating': 8.6, 'imageUrl': ''},
  {'title': 'The Dark Knight', 'year': '2008', 'rating': 9.0, 'imageUrl': ''},
  {'title': 'Parasite', 'year': '2019', 'rating': 8.5, 'imageUrl': ''},
  {'title': 'Dune', 'year': '2021', 'rating': 8.0, 'imageUrl': ''},
];
```

### 4. Подключить `HomeScreen` как стартовый экран

В `main.dart` замените заглушку на `HomeScreen`:

```dart
home: const HomeScreen(),
```

### 5. Добавить placeholder-изображение (необязательно, но желательно)

Добавьте локальное изображение-заглушку в `assets/images/placeholder.png` и используйте его в `errorBuilder` у `Image.network`.
