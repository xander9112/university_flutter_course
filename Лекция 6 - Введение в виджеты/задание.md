# Задание 6 — Первые виджеты: карточка фильма и главный экран

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы создадите первые визуальные компоненты: виджет карточки фильма и главный экран со списком фильмов. Данные пока будут захардкожены — подключение к API будет в Лекции 11.

---

## Задачи

### 1. Подключить шрифт

Скачайте шрифт **Nunito** (или любой другой из Google Fonts) и подключите его через `pubspec.yaml`:

```yaml
flutter:
  fonts:
    - family: Nunito
      fonts:
        - asset: assets/fonts/Nunito-Regular.ttf
        - asset: assets/fonts/Nunito-Bold.ttf
          weight: 700
```

Установите его как шрифт по умолчанию в `MaterialApp`. Уберите `const` перед `MaterialApp` из Задания 1 — объект `ThemeData` не константный:

```dart
theme: ThemeData(
  fontFamily: 'Nunito',
),
```

### 2. Создать `MovieCard` (StatelessWidget)

Создайте файл `lib/widgets/movie_card.dart`.

Виджет принимает через конструктор объект `Movie` — модель, созданную в Задании 3.

Карточка должна содержать:
- Изображение постера по `movie.posterUrl` (используйте `Image.network` с `errorBuilder` для placeholder — у тестовых фильмов постера пока нет)
- Название фильма жирным шрифтом
- Год выпуска (`movie.year`) серым цветом
- Рейтинг со звёздочкой (например: ⭐ 8.4); если рейтинга нет — «⭐ —»

Пример минимальной структуры:

```dart
import '../models/movie.dart';

class MovieCard extends StatelessWidget {
  final Movie movie;

  const MovieCard({super.key, required this.movie});

  @override
  Widget build(BuildContext context) {
    // Ваша реализация
    // Для nullable-полей используйте ?? и ?. — например:
    // Text('⭐ ${movie.voteAverage?.toStringAsFixed(1) ?? '—'}')
  }
}
```

### 3. Создать `HomeScreen` (StatefulWidget)

Создайте файл `lib/screens/home_screen.dart`.

Экран содержит:
- `AppBar` с названием «CineTrack»
- `ListView` с карточками 5 тестовых фильмов

В качестве данных используйте `mockMovies` из Задания 3. Сделайте копию в изменяемый список в состоянии экрана — в следующем задании список будет перемешиваться и из него будут удаляться фильмы:

```dart
import '../data/mock_movies.dart';
import '../models/movie.dart';

// в классе _HomeScreenState:
final List<Movie> _movies = [...mockMovies];
```

Если в Задании 3 вы добавляли временный вывод в консоль в `main()`, удалите его.

### 4. Подключить `HomeScreen` как стартовый экран

В `main.dart` замените заглушку на `HomeScreen`:

```dart
home: const HomeScreen(),
```

### 5. Добавить placeholder-изображение (необязательно, но желательно)

Добавьте локальное изображение-заглушку в `assets/images/placeholder.png`, зарегистрируйте папку в `pubspec.yaml` (секция `flutter:` → `assets: - assets/images/`) и используйте изображение в `errorBuilder` у `Image.network`:

```dart
Image.network(
  movie.posterUrl,
  errorBuilder: (context, error, stackTrace) =>
      Image.asset('assets/images/placeholder.png'),
)
```
