# Лекция 13 - BLoC

Тема лекции — паттерн BLoC (Business Logic Component) для управления состоянием и вынесения бизнес-логики из UI.

В лекции сначала разбираются основы работы с потоками (Stream) в Dart как фундамент, на котором строится BLoC. Далее на практике, с использованием пакета flutter_bloc, показывается создание событий (Events) и состояний (States), а также самого блока (класс Bloc), обрабатывающего события через метод on<Event> и генерирующего новые состояния через emit. Отдельно упоминается упрощённый вариант Cubit, где входной поток событий заменён обычными методами.
