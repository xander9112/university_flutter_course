# Задание 13 — BLoC: рефакторинг управления состоянием

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы заменяете `MoviesProvider` на архитектурный паттерн **BLoC** (Business Logic Component). BLoC чётко разделяет UI-события, бизнес-логику и состояния — это важно для масштабируемости приложения.

Всё, что умел `MoviesProvider` (загрузка, добавление, удаление, перемешивание), превращается в события, а поиск из Задания 11 переезжает в тот же `MoviesBloc`. `FavoritesProvider` остаётся без изменений.

### 2. Создать события (Events)

Создайте файл `lib/blocs/movies/movies_event.dart`:

```dart
import '../../models/movie.dart';

abstract class MoviesEvent {}

/// Загрузить популярные фильмы
class LoadMovies extends MoviesEvent {}

/// Обновить список (pull-to-refresh)
class RefreshMovies extends MoviesEvent {}

/// Пользователь ввёл поисковый запрос
class SearchMoviesRequested extends MoviesEvent {
  final String query;
  SearchMoviesRequested(this.query);
}

/// Добавить фильм вручную (форма из Задания 9)
class AddMovie extends MoviesEvent {
  final Movie movie;
  AddMovie(this.movie);
}

/// Удалить фильм (свайп из Задания 7)
class RemoveMovie extends MoviesEvent {
  final int movieId;
  RemoveMovie(this.movieId);
}

/// Перемешать список (кнопка из Задания 7)
class ShuffleMovies extends MoviesEvent {}
```

> Событие поиска названо `SearchMoviesRequested`, а не `SearchMovies`: в Задании 15 появится use case `SearchMovies`, и одинаковые имена классов приведут к конфликту импортов.

### 3. Создать состояния (States)

Создайте файл `lib/blocs/movies/movies_state.dart`:

```dart
import '../../models/movie.dart';

abstract class MoviesState {}

/// Начальное состояние (до первой загрузки)
class MoviesInitial extends MoviesState {}

/// Загрузка
class MoviesLoading extends MoviesState {}

/// Данные загружены успешно
class MoviesLoaded extends MoviesState {
  final List<Movie> movies;
  MoviesLoaded(this.movies);
}

/// Произошла ошибка
class MoviesError extends MoviesState {
  final String message;
  MoviesError(this.message);
}
```

### 4. Создать `MoviesBloc`

Создайте файл `lib/blocs/movies/movies_bloc.dart`:

```dart
import 'package:flutter_bloc/flutter_bloc.dart';
import '../../services/movie_api_service.dart';
import 'movies_event.dart';
import 'movies_state.dart';

class MoviesBloc extends Bloc<MoviesEvent, MoviesState> {
  final MovieApiService _apiService;

  /// Последний запрошенный поиск — чтобы отбросить устаревшие ответы.
  String? _latestQuery;

  MoviesBloc(this._apiService) : super(MoviesInitial()) {
    on<LoadMovies>(_onLoadMovies);
    on<RefreshMovies>(_onRefreshMovies);
    on<SearchMoviesRequested>(_onSearchMoviesRequested);
    on<AddMovie>(_onAddMovie);
    on<RemoveMovie>(_onRemoveMovie);
    on<ShuffleMovies>(_onShuffleMovies);
  }

  Future<void> _onLoadMovies(LoadMovies event, Emitter<MoviesState> emit) async {
    emit(MoviesLoading());
    try {
      final movies = await _apiService.getPopularMovies();
      emit(MoviesLoaded(movies));
    } catch (e) {
      emit(MoviesError(e.toString()));
    }
  }

  Future<void> _onRefreshMovies(RefreshMovies event, Emitter<MoviesState> emit) async {
    // Не показываем лоадер — просто обновляем данные
    try {
      final movies = await _apiService.getPopularMovies();
      emit(MoviesLoaded(movies));
    } catch (e) {
      emit(MoviesError(e.toString()));
    }
  }

  Future<void> _onSearchMoviesRequested(
    SearchMoviesRequested event,
    Emitter<MoviesState> emit,
  ) async {
    final query = event.query.trim();
    _latestQuery = query;
    // Пустой запрос (пользователь очистил поле) — возвращаемся к подсказке
    if (query.isEmpty) {
      emit(MoviesInitial());
      return;
    }

    emit(MoviesLoading());
    try {
      final movies = await _apiService.searchMovies(query);
      if (query != _latestQuery) return; // ответ устарел — пришёл новый запрос
      emit(MoviesLoaded(movies));
    } catch (e) {
      if (query != _latestQuery) return;
      emit(MoviesError(e.toString()));
    }
  }

  // Операции со списком меняют только уже загруженное состояние

  void _onAddMovie(AddMovie event, Emitter<MoviesState> emit) {
    final current = state;
    if (current is MoviesLoaded) {
      emit(MoviesLoaded([event.movie, ...current.movies]));
    }
  }

  void _onRemoveMovie(RemoveMovie event, Emitter<MoviesState> emit) {
    final current = state;
    if (current is MoviesLoaded) {
      emit(MoviesLoaded(
        current.movies.where((m) => m.id != event.movieId).toList(),
      ));
    }
  }

  void _onShuffleMovies(ShuffleMovies event, Emitter<MoviesState> emit) {
    final current = state;
    if (current is MoviesLoaded) {
      emit(MoviesLoaded([...current.movies]..shuffle()));
    }
  }
}
```

Обратите внимание: обработчики не меняют список `current.movies` на месте, а создают новый и выдают новое состояние. Состояние в BLoC должно быть неизменяемым — иначе `BlocBuilder` может не заметить изменения.

Два момента в обработчике поиска:

- **Пустой запрос** возвращает блок в `MoviesInitial`. Иначе после очистки поля `searchMovies('')` вернул бы пустой список, и экран поиска показал бы «Ничего не найдено» вместо подсказки «Введите название фильма».
- **Устаревшие ответы отбрасываются.** Bloc по умолчанию обрабатывает события **параллельно**: если пользователь ввёл «Дюна», подождал, а потом исправил запрос на «Дюна 2», оба запроса идут одновременно. Ответ на первый может прийти позже второго и затереть правильные результаты. Поэтому блок запоминает последний запрос в `_latestQuery` и не выдаёт состояние, если ответ пришёл на более старый. В Задании 11 эту же проверку делал `SearchScreen`; теперь логика поиска живёт в блоке, и проверка переезжает вместе с ней. В больших проектах для этого используют пакет `bloc_concurrency` и трансформер `restartable()`, который отменяет предыдущий обработчик.

### 5. Подключить `MoviesBloc` в дерево виджетов

В `main.dart` замените `ChangeNotifierProvider` для `MoviesProvider` на `BlocProvider` внутри `MultiProvider`:

```dart
MultiProvider(
  providers: [
    BlocProvider(create: (_) => MoviesBloc(MovieApiService())..add(LoadMovies())),
    ChangeNotifierProvider(create: (_) => FavoritesProvider()),
    ChangeNotifierProvider(create: (_) => RatingsProvider()),
  ],
  child: const MyApp(),
)
```

Событие `LoadMovies` отправляется сразу при создании блока, поэтому удалите вызов `loadMovies()` из `initState` у `HomeScreen`. Сам `HomeScreen` можно оставить `StatefulWidget`: обработчик добавления фильма из Задания 12 после `await` проверяет `mounted`. `FavoritesProvider` и `RatingsProvider` остаются провайдерами — в BLoC переезжает только список фильмов.

### 6. Обновить `HomeScreen` для работы с `BlocBuilder`

Замените чтение из `MoviesProvider` на `BlocBuilder`, а вызовы методов провайдера — на отправку событий:

| Было (Задание 12) | Стало |
|---|---|
| `context.read<MoviesProvider>().shuffle()` | `context.read<MoviesBloc>().add(ShuffleMovies())` |
| `context.read<MoviesProvider>().removeMovie(movie.id)` | `context.read<MoviesBloc>().add(RemoveMovie(movie.id))` |
| `context.read<MoviesProvider>().addMovie(movie)` | `context.read<MoviesBloc>().add(AddMovie(movie))` |

Тело экрана:


### 7. Добавить pull-to-refresh

`RefreshIndicator` показывает индикатор обновления, когда пользователь тянет прокручиваемый список вниз от верхнего края, и вызывает `onRefresh`. Индикатор крутится, пока не завершится `Future`, который вернул `onRefresh`.

Оберните вертикальный список «Все фильмы» в `RefreshIndicator`:

```dart
Expanded(
  child: RefreshIndicator(
    onRefresh: () {
      final bloc = context.read<MoviesBloc>()..add(RefreshMovies());
      // ждём следующее состояние, чтобы индикатор не пропал раньше времени
      return bloc.stream.first;
    },
    child: ListView.builder(/* список из Задания 8 */),
  ),
)
```

### 8. Перевести `SearchScreen` на `MoviesBloc`

Поиск использует тот же класс `MoviesBloc`, но **свой экземпляр** блока. Если отправлять `SearchMoviesRequested` в общий блок из `main.dart`, результаты поиска заменят список на главном экране. Поэтому `SearchScreen` создаёт собственный `BlocProvider` — его блок живёт, пока открыт экран поиска, и не влияет на главный экран:

```dart
class SearchScreen extends StatelessWidget {
  const SearchScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return BlocProvider(
      create: (_) => MoviesBloc(MovieApiService()),
      child: const _SearchView(),
    );
  }
}
```

Перенесите прежнее содержимое `SearchScreen` (контроллер, таймер debounce, `Scaffold` с `TextField`) в `StatefulWidget` `_SearchView`. Поле `_results` и вызов `_apiService` больше не нужны — в обработчике таймера отправляйте событие:

```dart
_debounce = Timer(const Duration(milliseconds: 500), () {
  context.read<MoviesBloc>().add(SearchMoviesRequested(query));
});
```

Тело экрана постройте через `BlocBuilder`:

```dart
body: BlocBuilder<MoviesBloc, MoviesState>(

    );
  },
),
```
