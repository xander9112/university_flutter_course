# Задание 10 — BLoC: рефакторинг управления состоянием

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы заменяете `MoviesProvider` на архитектурный паттерн **BLoC** (Business Logic Component). BLoC чётко разделяет UI-события, бизнес-логику и состояния — это важно для масштабируемости приложения.

---

## Задачи

### 1. Добавить пакет `flutter_bloc`

В `pubspec.yaml`:

```yaml
dependencies:
  flutter_bloc: ^8.1.6
```

### 2. Создать события (Events)

Создайте файл `lib/blocs/movies/movies_event.dart`:

```dart
abstract class MoviesEvent {}

/// Загрузить популярные фильмы
class LoadMovies extends MoviesEvent {}

/// Обновить список (pull-to-refresh)
class RefreshMovies extends MoviesEvent {}

/// Поиск фильмов по запросу
class SearchMovies extends MoviesEvent {
  final String query;
  SearchMovies(this.query);
}
```

### 3. Создать состояния (States)

Создайте файл `lib/blocs/movies/movies_state.dart`:

```dart
import '../../models/movie.dart';

abstract class MoviesState {}

/// Начальное состояние (до первой загрузки)
class MoviesInitial extends MoviesState {}

/// Загрузка
class MoviesLoading extends MoviesState {}

/// Данные загружены успешно
class MoviesLoaded extends MoviesState {
  final List<Movie> movies;
  MoviesLoaded(this.movies);
}

/// Произошла ошибка
class MoviesError extends MoviesState {
  final String message;
  MoviesError(this.message);
}
```

### 4. Создать `MovieBloc`

Создайте файл `lib/blocs/movies/movies_bloc.dart`:

```dart
import 'package:flutter_bloc/flutter_bloc.dart';
import '../../services/movie_api_service.dart';
import 'movies_event.dart';
import 'movies_state.dart';

class MoviesBloc extends Bloc<MoviesEvent, MoviesState> {
  final MovieApiService _apiService;

  MoviesBloc(this._apiService) : super(MoviesInitial()) {
    on<LoadMovies>(_onLoadMovies);
    on<RefreshMovies>(_onRefreshMovies);
    on<SearchMovies>(_onSearchMovies);
  }

  Future<void> _onLoadMovies(LoadMovies event, Emitter<MoviesState> emit) async {
    emit(MoviesLoading());
    try {
      final movies = await _apiService.getPopularMovies();
      emit(MoviesLoaded(movies));
    } catch (e) {
      emit(MoviesError(e.toString()));
    }
  }

  Future<void> _onRefreshMovies(RefreshMovies event, Emitter<MoviesState> emit) async {
    // Не показываем лоадер — просто обновляем данные
    try {
      final movies = await _apiService.getPopularMovies();
      emit(MoviesLoaded(movies));
    } catch (e) {
      emit(MoviesError(e.toString()));
    }
  }

  Future<void> _onSearchMovies(SearchMovies event, Emitter<MoviesState> emit) async {
    emit(MoviesLoading());
    try {
      final movies = await _apiService.searchMovies(event.query);
      emit(MoviesLoaded(movies));
    } catch (e) {
      emit(MoviesError(e.toString()));
    }
  }
}
```

### 5. Подключить `MoviesBloc` в дерево виджетов

В `main.dart` добавьте `BlocProvider` рядом с `MultiProvider`:

```dart
BlocProvider(
  create: (_) => MoviesBloc(MovieApiService())..add(LoadMovies()),
),
```

Либо вложите `BlocProvider` в `MultiProvider`:

```dart
MultiProvider(
  providers: [
    BlocProvider(create: (_) => MoviesBloc(MovieApiService())..add(LoadMovies())),
    ChangeNotifierProvider(create: (_) => FavoritesProvider()),
  ],
  child: const MyApp(),
)
```

### 6. Обновить `HomeScreen` для работы с `BlocBuilder`

Замените чтение из `MoviesProvider` на `BlocBuilder`:

```dart
BlocBuilder<MoviesBloc, MoviesState>(
  builder: (context, state) {
    if (state is MoviesLoading) {
      return const Center(child: CircularProgressIndicator());
    }
    if (state is MoviesError) {
      return Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text('Ошибка: ${state.message}'),
            ElevatedButton(
              onPressed: () => context.read<MoviesBloc>().add(LoadMovies()),
              child: const Text('Повторить'),
            ),
          ],
        ),
      );
    }
    if (state is MoviesLoaded) {
      return RefreshIndicator(
        onRefresh: () async => context.read<MoviesBloc>().add(RefreshMovies()),
        child: ListView.builder(
          itemCount: state.movies.length,
          itemBuilder: (context, index) => MovieCard(movie: state.movies[index]),
        ),
      );
    }
    return const SizedBox();
  },
)
```

### 7. Обновить `SearchScreen` для работы с `SearchMovies` событием

```dart
void _onSearch(String query) {
  context.read<MoviesBloc>().add(SearchMovies(query));
}
```

### 8. Удалить `MoviesProvider`

После успешного рефакторинга удалите `lib/providers/movies_provider.dart` — его логика теперь в `MoviesBloc`.
