# Лекция 10 - BLoC

## BLoC теория

Чтобы использовать библиотеку bloc, очень важно иметь общее представление о потоках и о том, как они работают.

Если вы не знакомы с потоками, просто подумайте о трубе, по которой течет вода. Труба — это поток, а вода — асинхронные данные.

Мы можем создать поток в Dart, написав функцию async* (асинхронный генератор).

Stream<int> countStream(int max) async* {

```dart
    for (int i = 0; i < max; i++) {
        yield i;
    }
}
```

Пометив функцию как aync*, мы можем использовать ключевое слово yield и возвращать поток данных. В приведенном выше примере мы возвращаем поток целых чисел до максимального целочисленного параметра. Каждый раз, когда мы возвращаем значение в async* функции, мы передаем этот фрагмент данных через поток.

Мы можем использовать вышеуказанный поток несколькими способами. Если бы мы хотели написать функцию, возвращающую сумму Stream целых чисел, она могла бы выглядеть примерно так:

Future<int> sumStream(Stream<int> stream) async {

```dart
    int sum = 0;
    await for (int value in stream) {
        sum += value;
    }
    return sum;
}
```

Пометив вышеуказанную функцию как асинхронную, мы можем использовать ключевое слово await и возвращать Future целых чисел. В этом примере мы ожидаем каждое значение в потоке и возвращаем сумму всех целых чисел в потоке.

```dart
void main() async {
    /// Initialize a stream of integers 0-9
    Stream<int> stream = countStream(10);
    /// Compute the sum of the stream of integers
    int sum = await sumStream(stream);
    /// Print the sum
    print(sum); // 45
}
```

Теперь, когда у нас есть общее представление о том, как работают потоки в Dart, мы готовы узнать об основных компонентах пакета bloc.

Flutter Bloc предлагает простой подход для управления различными состояниями в приложении. Как только вы во всем разберетесь, то сможете легко работать с этой библиотекой и масштабировать приложения любого размера.

Flutter Blocs упрощает процесс управления состояниями в приложении. Она предоставляет простые API, которые абстрагируют множество деталей и облегчают работу с состояниями. Это одна из самых популярных библиотек такого рода во Flutter. Она активно поддерживается Felix Angelov и другими разработчиками на основе открытого исходного кода.

Судя по названию, Blocs обрабатывает всю бизнес-логику: будь то взаимодействие с уровнем данных для отображения чего-либо на UI или сложные вычисления.

BLOC это простой класс у которого:

все выходы потоки

все входы потоки

этот класс должен убирать логику из визуального интерфейса

Также есть упрощенный вариант, называемый Cubit. 

В Cubit входной поток заменен на методы кубита, в остальном механизм работы остается тем же.

## BLoC практика, создание событие/состояний

Давайте создадим приложение с цветом из предыдущего урока используя для управления состоянием пакет flutter_bloc.

Для того чтобы создать блок нам нужно создать эвенты, которые может обрабатывать этот блок.

Создадим абстрактный класс ColorEvent, который будет родительским классом для всех эвентов блока. 

```dart
abstract class ColorEvent {}
```

Далее нам нужно создать эвент, который будет генерировать при нажатии кнопки для смены цвета. Назовем его ColorChangePressed

```dart
class ColorChangePressed extends ColorEvent {}
```

Теперь мы можем создать наш блок. 

```dart
class ColorBloc extends Bloc<ColorEvent, Color> {
  ColorBloc() : super(Colors.green) {
    on<ColorChangePressed>(
      (event, emit) => emit(Util.randomColor()),
    );
  }
}
```

Здесь мы определяем что наш блок может принимать эвенты ColorEvent, а в качестве состояния будет использовать класс Color.

В конструкторе мы указываем какое состояние у нас будет при создании блока 

ColorBloc() : super(Colors.green) 

В теле конструктора мы устанавливаем обработчики эвентов. В данном примере нам нужно обработать эвент нажатия кнопки ColorChangePressed. При нажатии мы отправляем новый стейт с помощью метода emit со случайным цветом. 

```dart
  (event, emit) => emit(Util.randomColor()),
```

Далее нам нужно создать страницу, которая бы отображала стейт блока.

```dart
class HomePage extends StatelessWidget {
  const HomePage({super.key});
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(),
      body: BlocProvider(
        create: (context) => ColorBloc(),
        child: Center(child: BlocBuilder<ColorBloc, Color>(
          builder: (context, state) {
            return Container(
              width: 200,
              height: 200,
              color: state,
              child: Column(
                children: [
                  Text(state.toString()),
                  ElevatedButton(
                      onPressed: () {
                        context.read<ColorBloc>().add(ColorChangePressed());
                      },
                      child: const Text('Change color'))
                ],
              ),
            );
          },
        )),
      ),
    );
  }
}
```
