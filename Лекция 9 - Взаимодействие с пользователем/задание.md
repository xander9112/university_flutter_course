# Задание 9 — Взаимодействие с пользователем: поиск, добавление и жесты

## Контекст

Продолжаем разработку **CineTrack**. В этом задании вы добавите интерактивность: экран поиска с текстовым полем, форму для добавления фильма вручную, диалоговые окна и жесты на карточках.

Новые экраны открываются так же, как экран деталей в Задании 8, — через `Navigator.push`. Подробно навигацию разберём в Лекции 10, а пока достаточно знать, что `Navigator.pop(context, значение)` возвращает значение на предыдущий экран — точно так же, как вы возвращаете результат из `AlertDialog` в задаче 4.

## Задачи

### 1. Создать `SearchScreen`

Создайте файл `lib/screens/search_screen.dart` и реализуйте поиск по тестовым данным с помощью функции `searchByTitle` из Задания 3:

```dart
import 'package:flutter/material.dart';

import '../data/mock_movies.dart';
import '../models/movie.dart';
import '../utils/movie_utils.dart';
import '../widgets/movie_card.dart';

class SearchScreen extends StatefulWidget {
  const SearchScreen({super.key});

  @override
  State<SearchScreen> createState() => _SearchScreenState();
}

class _SearchScreenState extends State<SearchScreen> {
  final _controller = TextEditingController();
  List<Movie> _results = mockMovies; // при пустом запросе показываем все фильмы

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  void _onSearch(String query) {
    setState(() {
      _results = searchByTitle(mockMovies, query);
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: TextField(
          controller: _controller,
          onChanged: _onSearch,
          decoration: const InputDecoration(
            hintText: 'Название фильма...',
            border: InputBorder.none,
          ),
        ),
      ),
      body: ListView.builder(
        itemCount: _results.length,
        itemBuilder: (context, index) => MovieCard(movie: _results[index]),
      ),
    );
  }
}
```

> Поиск идёт по исходному списку `mockMovies`, поэтому фильмы, добавленные или удалённые на главном экране, в результатах не учитываются. Это нормально для учебного шага: в Задании 11 поиск будет работать через API.

Откройте `SearchScreen` с главного экрана — добавьте в `AppBar` у `HomeScreen` кнопку поиска:

```dart
actions: [
  IconButton(
    icon: const Icon(Icons.search),
    onPressed: () => Navigator.push(
      context,
      MaterialPageRoute(builder: (_) => const SearchScreen()),
    ),
  ),
  // кнопка «Перемешать» из Задания 7
],
```

### 2. Создать `AddMovieScreen` с формой

Создайте файл `lib/screens/add_movie_screen.dart` (`StatefulWidget`). Форма должна содержать:

| Поле | Тип | Валидация |
|------|-----|-----------|
| Название | `TextFormField` | обязательное, минимум 2 символа |
| Год выпуска | `TextFormField` | обязательное, 4 цифры |
| Описание | `TextFormField` | необязательное |
| Рейтинг | `TextFormField` | необязательное; если заполнено — число от 0 до 10 |

Для каждого поля заведите `TextEditingController` (и не забудьте освободить их в `dispose`). Оберните поля в `Form` с `GlobalKey<FormState>`:

```dart
final _formKey = GlobalKey<FormState>();
final _titleController = TextEditingController();
// ... контроллеры для года, описания и рейтинга

Form(
  key: _formKey,
  child: Column(
    children: [
      TextFormField(
        controller: _titleController,
        decoration: const InputDecoration(labelText: 'Название *'),
        validator: (value) {
          if (value == null || value.trim().length < 2) {
            return 'Введите название (минимум 2 символа)';
          }
          return null;
        },
      ),
      // ... остальные поля
      ElevatedButton(
        onPressed: () {
          if (_formKey.currentState!.validate()) {
            final overview = _overviewController.text.trim();
            final newMovie = Movie(
              id: DateTime.now().millisecondsSinceEpoch, // уникальный id для ValueKey
              title: _titleController.text.trim(),
              overview: overview.isEmpty ? null : overview,
              voteAverage: double.tryParse(_ratingController.text.replaceAll(',', '.')),
              releaseDate: '${_yearController.text}-01-01',
            );
            Navigator.pop(context, newMovie); // возвращаем фильм на главный экран
          }
        },
        child: const Text('Добавить фильм'),
      ),
    ],
  ),
)
```

Обратите внимание: необязательные описание и рейтинг попадают в nullable-поля `Movie` — если пользователь их не заполнил, там будет `null`, и карточка покажет заглушки из Задания 6.

### 3. Добавить кнопку открытия `AddMovieScreen`

На `HomeScreen` добавьте `FloatingActionButton`. `Navigator.push<Movie>` вернёт фильм, переданный в `Navigator.pop`, или `null`, если пользователь вышел с экрана кнопкой «Назад»:

```dart
floatingActionButton: FloatingActionButton(
  onPressed: () async {
    final movie = await Navigator.push<Movie>(
      context,
      MaterialPageRoute(builder: (_) => const AddMovieScreen()),
    );
    if (movie == null || !mounted) return;

    setState(() => _movies.insert(0, movie));
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('«${movie.title}» добавлен!')),
    );
  },
  child: const Icon(Icons.add),
),
```

Проверка `mounted` нужна, потому что после `await` экран мог быть уже закрыт, и обращаться к его `context` нельзя.

### 5. Добавить жест двойного тапа для добавления в избранное

В Задании 8 вы уже обернули `MovieCard` в `GestureDetector` с `onTap` для перехода на экран деталей. Добавьте в тот же `GestureDetector` обработчик `onDoubleTap`. В итоге элемент списка на главном экране устроен так: `Dismissible` → `GestureDetector` → `MovieCard`:

```dart
Dismissible(
  key: ValueKey(movie.id),
  // ... direction, background, confirmDismiss, onDismissed
  child: GestureDetector(
    onTap: () { /* переход на MovieDetailScreen из Задания 8 */ },
    onDoubleTap: () {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('«${movie.title}» добавлен в избранное'),
          duration: const Duration(seconds: 2),
        ),
      );
    },
    child: MovieCard(movie: movie),
  ),
)
```

Само избранное пока нигде не хранится — это сделаем в Задании 12.
