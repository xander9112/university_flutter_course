# Лекция 8 - Dart - работа с Null Safety

Тема лекции — механизм null safety в языке Dart и работа с nullable-типами.

Рассматриваются принципы надёжной нулевой безопасности Dart, иерархия типов с учётом nullable- и non-nullable-областей (Object?, Never), а также null-aware операторы ??, ??=, ?., ?.. и оператор принудительного разыменования !. Отдельно разбирается модификатор late, особенности работы с nullable-коллекциями и параметрами класса (required, значения по умолчанию) в контексте null safety.
