# Задание 1 — ответы на вопросы

**За что отвечает директория `lib/`?**
Здесь лежит весь Dart-код приложения. Точка входа — `lib/main.dart` с функцией `main()`, которая вызывает `runApp()`. Все экраны, виджеты, модели и сервисы CineTrack будут располагаться внутри `lib/`.

**Что описывает файл `pubspec.yaml`?**
Это манифест проекта: имя пакета (`cine_track`), описание, версия приложения (`1.0.0+1` — версия и номер сборки), требуемая версия Dart SDK, зависимости (`dependencies`) и зависимости для разработки (`dev_dependencies`), а также ресурсы — шрифты, изображения (секция `flutter:`). После изменения зависимостей выполняется `flutter pub get`.

**Зачем нужны директории `android/` и `ios/`?**
Это нативные проекты-обёртки для каждой платформы: Gradle-проект для Android и Xcode-проект для iOS. В них настраиваются идентификатор приложения, иконки, разрешения (`AndroidManifest.xml`, `Info.plist`), подпись релизной сборки. Flutter-код из `lib/` встраивается в эти проекты при сборке. Аналогично `web/` — обёртка для веб-версии.

**Что происходит в папке `build/` при запуске проекта?**
В `build/` Flutter складывает результаты сборки: скомпилированный Dart-код, ресурсы, промежуточные файлы Gradle/Xcode и итоговые артефакты (`.apk`, `.app`, веб-бандл). Папка генерируется автоматически при каждой сборке, её можно удалить командой `flutter clean`, и она не хранится в Git (указана в `.gitignore`).
