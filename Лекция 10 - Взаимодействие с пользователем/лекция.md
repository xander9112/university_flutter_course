# Лекция 7 - Взаимодействие с пользователем

Приложения часто требуют, чтобы пользователи вводили информацию в текстовое поле. Например, вы можете потребовать, чтобы пользователи входили в систему, используя комбинацию адреса электронной почты и пароля. Чтобы сделать приложения безопасными и простыми в использовании, проверьте достоверность предоставленной пользователем информации. Если пользователь правильно заполнил форму, обработайте информацию. Если пользователь отправляет неверную информацию, отобразите понятное сообщение об ошибке, сообщающее ему, что пошло не так.

## Form

Виджет Form действует как контейнер для группировки и проверки нескольких полей формы. При создании формы укажите GlobalKey. Ключ однозначно идентифицирует форму и позволяет проверить форму на более позднем этапе.

```dart
import 'package:flutter/material.dart';
```

// Define a custom Form widget.

```dart
class MyCustomForm extends StatefulWidget {
  const MyCustomForm({super.key});
  @override
  MyCustomFormState createState() {
    return MyCustomFormState();
  }
}
```

// Define a corresponding State class.

```dart
// This class holds data related to the form.
class MyCustomFormState extends State<MyCustomForm> {
  // Create a global key that uniquely identifies the Form widget
  // and allows validation of the form.
  //
  // Note: This is a `GlobalKey<FormState>`,
  // not a GlobalKey<MyCustomFormState>.
  final _formKey = GlobalKey<FormState>();
  @override
  Widget build(BuildContext context) {
    // Build a Form widget using the _formKey created above.
    return Form(
      key: _formKey,
      child: const Column(
        children: <Widget>[
          // Add TextFormFields and ElevatedButton here.
        ],
      ),
    );
  }
}
```

Несмотря на наличие формы, пользователи не могут вводить текст. Для этого применим TextFormField. Виджет TextFormField отображает текстовое поле в стиле Material Design и может отображать ошибки проверки при их возникновении. Проверьте ввод, предоставив функцию validator() для TextFormField. Если ввод пользователя недействителен, функция валидатора возвращает строку, содержащую сообщение об ошибке. Если ошибок нет, валидатор должен вернуть null. В этом примере создадим валидатор, который гарантирует, что TextFormField не пуст. Если он пуст, вернем сообщение об ошибке.

TextFormField(

```dart
  // The validator receives the text that the user has entered.
  validator: (value) {
    if (value == null || value.isEmpty) {
      return 'Please enter some text';
    }
    return null;
  },
),
```

Теперь, когда у вас есть форма с текстовым полем, добавим кнопку, которую пользователь может нажать, чтобы отправить информацию. Когда пользователь пытается отправить форму, проверяем, действительна ли форма. Если это так, отобразим сообщение об успешном завершении. Если это не так (в текстовом поле нет содержимого), выведем сообщение об ошибке.

ElevatedButton(

```dart
  onPressed: () {
    // Validate returns true if the form is valid, or false otherwise.
    if (_formKey.currentState!.validate()) {
      // If the form is valid, display a snackbar. In the real world,
      // you'd often call a server or save the information in a database.
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Processing Data')),
      );
    }
  },
  child: const Text('Submit'),
),
```

Чтобы проверить форму, используем _formKey, созданный в процессе создания формы. Вы можете использовать метод _formKey.currentState() для доступа к FormState, который автоматически создается Flutter при создании формы. Класс FormState содержит метод validate(). Когда вызывается метод validate(), он запускает функцию validator() для каждого текстового поля в форме. Если все выглядит хорошо, метод validate() возвращает true. Если какое-либо текстовое поле содержит ошибки, метод validate() перестраивает форму для отображения любых сообщений об ошибках и возвращает false.

## TextField и TextFormField

Для ввода текста во Flutter может применяться виджет TextField:

Конструктор виджета принимает довольно много параметров, поэтому ниже представлены основные:

```dart
decoration: задает стилизацию виджета с помощью объекта InputDecoration
enabled: значение типа bool, которое указывает, доступно ли для ввода текстовое поле (при значении false поле для ввода недоступно)
expands: значение типа bool, которое указывает, будет ли виджет заполнять все доступное пространство контейнера
keyboardType: устанавливает тип клавиатуры в виде объекта TextInputType
maxLength: максимальное количество символов, которое можно ввести в текстовое поле
maxLines: максимальное количество строк
minLines: минимальное количество строк
obscureText: значение типа bool, которое указывает, будет ли виджет скрывать с помощью маски вводимые символы (например, при вводе пароля)
obscuringCharacter: задает символы, которые применяются в качестве маски для вводимых символов, если параметр obscureText равен true.
readOnly: значение типа bool, которое указывает, можно ли изменять текст в виджете
style: стиль вводимого текста в виде объекта TextStyle
textAlign: задает горизонтальное выравнивание текста в виде объекта TextAlign
textAlignVertical: задает вертикальное выравнивание текста в виде объекта TextAlignVertical
textDirection: устанавливает направление текста с помощью объекта TextDirection
```

С помощью параметров onChanged и onSubmitted конструктора мы можем установить функции, которые будут вызываться при вводе текста. Функция onChanged вызывается при каждом изменении текста в виджете. Функция onSubmitted вызывается, если пользователь завершил ввод, например, нажал кнопку ввода на клавиатуре.

```dart
Обе эти функции представляют функцию void ValueChanged (String value), которая в качестве параметра принимает строку - введенный текст.
import 'package:flutter/material.dart';
void main() {
  runApp(MaterialApp(
      home:  Scaffold(
        body: TextField(
            onSubmitted: (text) {
              print("onSubmitted");
              print("Введенный текст: $text");
            },
            onChanged: (text) {
              print("onChanged");
              print("Введенный текст: $text");
        }),
     )
  ));
}
```

Виджет TextFormField во многом аналогичен TextField, также представляет текстовое поле и предоставляет те же возможности за тем исключением, что он добавляет к параметрам конструктора параметр initialValue, с помощью которого можно указать начальное значение в текстовом поле, а также возможностью его использования в форме для валидации ввода.

Для этого необходимо использовать параметр validator:

TextFormField(

## Ограничения ввода в поля формы

Часто бывают задачи, когда нужно ограничить ввод данных в текстовые поля, например разрешить вводить только цифры или ограничить длину строик.  Для реализации таких ограничений используется InputFormatter.

Фреймворк Flutter предоставляет нам два встроенных TextInputFormatter: 

FilteringTextInputFormatter — создает инструмент форматирования, который разрешает или блокирует символы, соответствующие шаблону. 

LengthLimitingTextInputFormatter — позволяет вставить только определенное количество символов.

Пример ниже настраивает TextFormField так, чтобы можно было ввести только цифры, причем не более 4.

TextFormField(

```dart
            inputFormatters: [
              FilteringTextInputFormatter.allow(RegExp(r'[0-9]')),
              LengthLimitingTextInputFormatter(4)
            ],
          ),
```

В примере мы использовали конструктор FilteringTextInputFormatter.allow который разрешает ввод указанных символов. Для запрета ввода этим символов можно использовать другой конструктор FilteringTextInputFormatter.deny:

TextFormField(

```dart
            inputFormatters: [
              FilteringTextInputFormatter.deny(RegExp(r'[0-9]')),
              LengthLimitingTextInputFormatter(4)
            ],
          ),
```

В примере выше мы запретили ввод цифр и ограничили длину ввода 4 символами.

Также у FilteringTextInputFormatter есть еще два статичных метода, которые возвращают уже настроенные TextInputFormatter

digitsOnly → TextInputFormatter

A TextInputFormatter that takes in digits [0-9] only.

singleLineFormatter → TextInputFormatter

A TextInputFormatter that forces input to be a single line.

Мы можем создать собственный TextInputFormatter, расширив TextInput Formatter и реализовав метод formatEditUpdate, который принимает два параметра типа TextEditingValue: oldValue и old newValue. 

Ниже пример кастомного TextInputFormatter, который заменяет все введенные запятые на точки.

```dart
class CommaTextInputFormatter extends TextInputFormatter {
  @override
  TextEditingValue formatEditUpdate(
      TextEditingValue oldValue, TextEditingValue newValue) {
    String truncated = newValue.text;
    final TextSelection newSelection = newValue.selection;
    if (newValue.text.contains(',')) {
      truncated = newValue.text.replaceFirst(',', '.');
    }
    return TextEditingValue(text: truncated, selection: newSelection);
  }
}
```

## Получение текста из полей формы

Класс TextEditingController предназначен для управления ввода текста в виджет TextField.

TextEditingController устанавливается с помощью параметра controller конструктора классов TextField и TextFormField.

Данный класс имеет два конструктора:

TextEditingController({String text})

TextEditingController.fromValue(TextEditingValue value)

Первый конструктор в качестве параметра принимает начальное значение, которое затем будет отображаться в ассоциированном текстовом поле. Второй конструктор также принимает начальное значение, но в виде объекта TextEditingValue

TextEditingController позволяет контроллировать введенный и выделенный текст в поле ввода, для чего у него определены три свойства:

```dart
selection: выделенный текст в виде объекта TextSelection
text: текущий введенный текст в виде объекта String
value: текущее значение в виде объекта TextEditingValue
```

При изменении ввода в текстовом поле связанный объект TextEditingController уведомляет слушателей об изменении. Для добавления слушателей - функций обратного вызова в классе определен метод addListener(). Все добавленные слушатели могут считать введенный текст, а также выделенный текст и таким образом узнать о произошедших изменениях.

Когда объект TextEditingController больше не нужен, у него надо вызвать метод dispose(). Это позволит освободить все ресурсы, используемые объектом.

Вначале определим простейшее приложение с использованием TextEditingController, который задает начальное значение для текстового поля:

```dart
import 'package:flutter/material.dart';
void main() {
  runApp(MaterialApp(
      home:  Scaffold(
        body: Person(),
       )
  ));
}
class Person extends StatefulWidget {
  Person({ Key key}) : super(key: key);
  @override
  _PersonState createState() => _PersonState();
}
class _PersonState extends State<Person>{
  String _name = "Tom";
  final _controller = TextEditingController();
  @override
  void initState() {
    super.initState();
    _controller.text = _name;
  }
  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }
  @override
  Widget build(BuildContext context) {
    return Column(children:[
      Text("Имя пользователя: $_name", style: TextStyle(fontSize: 22)),
      TextField(
          style: TextStyle(fontSize: 22),
          controller: _controller)
    ],
    crossAxisAlignment: CrossAxisAlignment.start);
  }
}
```

Для виджета Person в данном случае определяется состояние в виде класса _PersonState. Класс _PersonState хранит состояние в виде переменной _name - условное имя пользователя. Но кроме того _PersonState также определяет константу _controller, которая представляет объект TextEditingController, с помощью которого мы будем отслеживать измнения переменной _name.

По умолчанию переменная _name уже имеет начальное значение - "Tom". И чтобы передать это значение в контроллер, переопределяем метод initState класса State. Этот метод призван инициализировать состояние объекта State. И в данном случае мы передаем свойству text объекта TextEditingController значение переменной _name. Благодаря этому текстовое поле получит начальное значение.

Для того, чтобы объект TextEditingController освободил все связанные с ним ресурсы, в классе состояния переопределяем метод dispose(), в котором вызываем метод dispose() контроллера.

Далее при создании виджета TextField в его конструкторе устанавливаем используемый контроллер:

```dart
controller: _controller
```

Теперь добавим обработку изменения текста:

_changeName(){

```dart
    setState(() =>_name = _controller.text);
  }
  @override
  void initState() {
    super.initState();
    _controller.text = _name;
    _controller.addListener(_changeName);
  }
```

При вводе весь вводимый текст будет храниться в свойстве text объекта TextEditingController. Для его получения и изменения переменной _name здесь определен метод _changeName:

Для отслеживания изменений при инициализации состояния в методе initState() вызываем у TextEditingController метод addListener() и в него передаем ту функцию, которая будет выполняться при изменении текста в TextEditingController.

Метод addListener() принимает функцию, которая не принимает никаких параметров и ничего не возвращает - то есть в данном случае соответствует определению метода _changeName(). Однако мы могли и явным образом вызвать метод _changeName:

_controller.addListener((){

```dart
      _changeName();
});
```

В итоге при изменении текста в текстовом поле также будет изменяться и состояние виджета Person.

## Валидация полей формы

Чтобы проверить ввода, необходимо установить функцию  validator() для TextFormField. Если ввод пользователя недействителен, функция валидатора возвращает строку, содержащую сообщение об ошибке. Если ошибок нет, валидатор должен вернуть null. В этом примере создадим валидатор, который гарантирует, что TextFormField не пуст. Если он пуст, вернем сообщение об ошибке.

TextFormField(

```dart
  // The validator receives the text that the user has entered.
  validator: (value) {
    if (value == null || value.isEmpty) {
      return 'Please enter some text';
    }
    return null;
  },
),
```

Далее мы можем сконфигурировать режим автовалидации установ свойство autovalidateMode.

Возможные значения:

Values

```dart
disabled → const AutovalidateMode
```

No auto validation will occur.

```dart
always → const AutovalidateMode
```

Used to auto-validate Form and FormField even without user interaction.

```dart
onUserInteraction → const AutovalidateMode
```

Used to auto-validate Form and FormField only after each user interaction.

Также мы можем вызвать валидацию используя _formKey, созданный в процессе создания формы. Вы можете использовать метод _formKey.currentState() для доступа к FormState, который автоматически создается Flutter при создании формы. Класс FormState содержит метод validate(). Когда вызывается метод validate(), он запускает функцию validator() для каждого текстового поля в форме. Если все выглядит хорошо, метод validate() возвращает true. Если какое-либо текстовое поле содержит ошибки, метод validate() перестраивает форму для отображения любых сообщений об ошибках и возвращает false.

## Выпадающий список

Выпадающие списки позволяют пользователям выбирать одно значение из списка доступных значений, и они являются обычным виджетом в любом современном приложении. 

В основном есть два типа виджетов, которые вам нужны для создания раскрывающегося списка во Flutter.

DropdownButton

DropdownMenuItem

Виджет DropdownButton содержит несколько обязательных свойств, необходимых для работы выпадающего списка. Основным обязательным свойством является свойство item. Свойство item принимает список виджетов DropdownMenuItem, которые должны показывать возможные варианты, которые можно выбрать.

В этом примере давайте создадим раскрывающийся список, содержащий список названий стран. Я создам отдельный метод, который будет возвращать список виджетов DropdownMenuItem, содержащих названия стран:

List<DropdownMenuItem<String>> get dropdownItems{

```dart
  List<DropdownMenuItem<String>> menuItems = [
    DropdownMenuItem(child: Text("USA"),value: "USA"),
    DropdownMenuItem(child: Text("Canada"),value: "Canada"),
    DropdownMenuItem(child: Text("Brazil"),value: "Brazil"),
    DropdownMenuItem(child: Text("England"),value: "England"),
  ];
  return menuItems;
}
```

Затем создадим виджет DropdownButton вместе со свойством items и зададим метод, который мы только что создали, для подачи значений в раскрывающийся список. Сделаем его как отдельный виджет с состоянием, потому что нам нужно изменить состояние раскрывающегося списка на более позднем этапе. 

```dart
class _DropdownItemState extends State<DropdownItem> {
  String selectedValue = "USA";
  @override
  Widget build(BuildContext context) {
    return DropdownButton(
      value: selectedValue,
      items: dropdownItems
      );
  }
}
```

Теперь вы можете видеть, что USA отображается как выбранное значение. Но, тем не менее, вы не можете взаимодействовать с раскрывающимся списком. Это потому, что мы еще не реализовали поведение раскрывающегося списка при изменении значения.

Обратный вызов onChange можно использовать для обработки изменений значения. Он вернет выбранное значение, и вы можете изменить состояние раскрывающегося списка, установив новое значение в раскрывающемся списке, как показано ниже:

DropdownButton(

```dart
      value: selectedValue,
      onChanged: (String? newValue){
        setState(() {
          selectedValue = newValue!;
        });
      },
      items: dropdownItems
      )
```

## "Фокусировка" полей ввода

Когда текстовое поле выбрано и принимает ввод, говорят, что оно имеет «фокус». Как правило, пользователи переключают фокус на текстовое поле, нажимая, а разработчики переключают фокус на текстовое поле программно. Управление фокусом — это основной инструмент для создания форм с интуитивно понятным потоком. Например, предположим, что у вас есть экран поиска с текстовым полем. Когда пользователь переходит к экрану поиска, вы можете установить фокус на текстовое поле для условия поиска. Это позволяет пользователю начать печатать, как только появится экран, без необходимости вручную касаться текстового поля. 

Чтобы выделить текстовое поле, как только оно станет видимым, используйте свойство autofocus.

TextField(

```dart
  autofocus: true,
);
```

Вместо того, чтобы сразу переключать фокус на конкретное текстовое поле, вам может понадобиться переключить фокус на текстовое поле в более поздний момент времени. В реальном мире вам также может понадобиться выделить определенное текстовое поле в ответ на вызов API или ошибку проверки. В этом примере передайте фокус текстовому полю после того, как пользователь нажмет кнопку, выполнив следующие действия:

Сначала создайте FocusNode. Используйте FocusNode, чтобы определить конкретное TextField в «дереве фокусов» Flutter. Это позволит вам установить фокус на TextField на следующих шагах. Поскольку узлы фокуса являются долгоживущими объектами, управляйте жизненным циклом с помощью объекта State. Используйте следующие инструкции, чтобы создать экземпляр FocusNode внутри метода initState() класса State и очистить его в методе dispose():

// Define a custom Form widget.

```dart
class MyCustomForm extends StatefulWidget {
  const MyCustomForm({super.key});
  @override
  State<MyCustomForm> createState() => _MyCustomFormState();
}
```

// Define a corresponding State class.

```dart
// This class holds data related to the form.
class _MyCustomFormState extends State<MyCustomForm> {
  // Define the focus node. To manage the lifecycle, create the FocusNode in
  // the initState method, and clean it up in the dispose method.
  late FocusNode myFocusNode;
  @override
  void initState() {
    super.initState();
    myFocusNode = FocusNode();
  }
  @override
  void dispose() {
    // Clean up the focus node when the Form is disposed.
    myFocusNode.dispose();
    super.dispose();
  }
  @override
  Widget build(BuildContext context) {
    // Fill this out in the next step.
  }
}
```

Теперь, когда у вас есть FocusNode, передайте его определенному TextField в методе build().

```dart
@override
Widget build(BuildContext context) {
  return TextField(
    focusNode: myFocusNode,
  );
}
```

Наконец, сфокусируйте текстовое поле, когда пользователь нажимает плавающую кнопку действия. Для установки фокуса следует использовать метод requestFocus() 

FloatingActionButton(

```dart
  // When the button is pressed,
  // give focus to the text field using myFocusNode.
  onPressed: () => myFocusNode.requestFocus(),
),
```

## SnackBar

SnackBar — это виджет Flutter, который позволяет вам временно отображать всплывающее сообщение в вашем приложении. Обычно он появляется в нижней части экрана приложения. Например, вы можете использовать виджет SnackBar, чтобы сообщить пользователю, когда выбранный товар был добавлен в корзину или удален, или указать, что форма была отправлена ​​или изображение успешно загружено.

Давайте отобразим SnackBar в нижней части экрана, не перекрывая другие важные виджеты, такие как FloatingActionButton. Виджет Scaffold из библиотеки Material Design создает эту визуальную структуру и гарантирует, что важные виджеты не перекрываются.

```dart
return MaterialApp(
  title: 'SnackBar Demo',
  home: Scaffold(
    appBar: AppBar(
      title: const Text('SnackBar Demo'),
    ),
    body: const SnackBarPage(),
  ),
);
```

Для того чтобы вывести сообщение необходимо создать SnackBar, а затем отобразить его с помощью ScaffoldMessenger.

```dart
const snackBar = SnackBar(
  content: Text('Yay! A SnackBar!'),
);
```

// Find the ScaffoldMessenger in the widget tree

// and use it to show a SnackBar.

ScaffoldMessenger.of(context).showSnackBar(snackBar);

Возможно, вы захотите предоставить пользователю действие при отображении SnackBar. Например, если пользователь случайно удалит сообщение, он может использовать дополнительное действие в SnackBar для восстановления сообщения. Вот пример предоставления дополнительного действия виджету SnackBar:

```dart
final snackBar = SnackBar(
  content: const Text('Yay! A SnackBar!'),
  action: SnackBarAction(
    label: 'Undo',
    onPressed: () {
      // Some code to undo the change.
    },
  ),
);
```

## AlertDialog

AlertDialog - это виджет (диалоговое окно оповещения) информирует пользователя о чем либо и требует подтверждения. AlertDialog имеет необязательный заголовок и необязательное содержимое. Заголовок отображается над содержимым, а действия (например кнопка 'Ok') отображаются под содержимым.

Для того чтобы показать диалог в Flutter необходимо использовать встроенную функцию showDialog. 

Вы должны предоставить функции showDialog(), context и функцию builder. Эта функция должна возвращать объект типа диалога.

```dart
return showDialog<void>(
    context: context,
    builder: (BuildContext context) {
      return AlertDialog(
        title: Text('Заголовок'),
        content: const Text(''),
        actions: <Widget>[
          FlatButton(
            child: Text('Ok'),
            onPressed: () {
              Navigator.of(context).pop();
            },
          ),
        ],
      );
    },
  );
```

## Использование жестов

Система жестов во Flutter состоит из двух отдельных слоев. Первый уровень содержит необработанные события указателя (Pointers), описывающие расположение и движение указателей (например, касания, мыши и стилусы) по экрану. Второй слой содержит жесты, описывающие семантические действия, состоящие из одного или нескольких движений указателя.

Pointers

Pointers представляют необработанные данные о взаимодействии пользователя с экраном устройства. Существует четыре типа событий:

PointerDownEvent

Указатель коснулся экрана в определенном месте.

PointerMoveEvent

Указатель переместился из одного места на экране в другое.

PointerUpEvent

Указатель перестал касаться экрана.

PointerCancelEvent

Ввод этого указателя больше не направлен на это приложение.

При наведении указателя фреймворк выполняет проверку вашего приложения, чтобы определить, какой виджет существует в том месте, где указатель соприкоснулся с экраном. Событие PointerDownEvent (и последующие события для этого указателя) затем отправляются самому внутреннему виджету, найденному в результате проверки нажатия. Оттуда события всплывают вверх по дереву и отправляются всем виджетам на пути от самого внутреннего виджета к корню дерева. Не существует механизма для отмены или прекращения дальнейшей отправки событий указателя.

Чтобы прослушивать события указателя непосредственно из слоя виджетов, используйте виджет Listener. 

Но есть более простой способ управления жестами.

Gestures

Жесты представляют собой семантические действия (например, касание, перетаскивание и масштабирование), которые распознаются из нескольких отдельных событий указателя, потенциально даже из нескольких отдельных указателей. Жесты могут отправлять несколько событий, соответствующих жизненному циклу жеста (например, начало перетаскивания, обновление перетаскивания и окончание перетаскивания).

Для обработки детектирования и обработки жестов используется виджет GestureDetector, который позволяет обрабатывать следующие события:

Tap

onTapDown

Указатель коснулся экрана в определенном месте.

onTapUp

Указатель, перестал касаться экрана в определенном месте.

onTap

Указатель, который ранее вызывал onTapDown, также вызвал onTapUp, что в конечном итоге является касанием.

onTapCancel

Указатель, который ранее вызывал onTapDown, не будет в конечном итоге вызывать касание.

Двойной тап

onDoubleTap

Пользователь коснулся экрана в одном и том же месте дважды подряд.

Длительное нажатие

onLongPress

Указатель оставался в контакте с экраном в одном и том же месте в течение длительного периода времени.

Вертикальное перетаскивание

onVerticalDragStart

Указатель коснулся экрана и может начать двигаться вертикально.

onVerticalDragUpdate

Указатель, находящийся в контакте с экраном и перемещающийся вертикально, переместился в вертикальном направлении.

onVerticalDragEnd

Указатель, который ранее находился в контакте с экраном и двигался вертикально, больше не касается экрана и двигался с определенной скоростью, когда перестал касаться экрана.

Горизонтальное перетаскивание

onHorizontalDragStart

Указатель коснулся экрана и может начать двигаться горизонтально.

onHorizontalDragUpdate

Указатель, находящийся в контакте с экраном и перемещающийся горизонтально, переместился в горизонтальном направлении.

onHorizontalDragEnd

Указатель, который ранее находился в контакте с экраном и двигался горизонтально, больше не касается экрана и двигался с определенной скоростью, когда перестал касаться экрана.

Pan

onPanStart

Указатель коснулся экрана и может начать двигаться горизонтально или вертикально. Этот обратный вызов аварийно завершает работу, если установлено значение onHorizontalDragStart или onVerticalDragStart.

onPanUpdate

Указатель, соприкасающийся с экраном и перемещающийся в вертикальном или горизонтальном направлении. Этот обратный вызов аварийно завершает работу, если установлено значение onHorizontalDragUpdate или onVerticalDragUpdate.

onPanEnd

Указатель, который ранее находился в контакте с экраном, больше не касается экрана и движется с определенной скоростью, когда перестал касаться экрана. Этот обратный вызов аварийно завершает работу, если установлено значение onHorizontalDragEnd или onVerticalDragEnd.

Пример ниже показывает, как сделать пользовательскую кнопку, которая показывает Snackbar при нажатии:

// The GestureDetector wraps the button.

GestureDetector(

```dart
  // When the child is tapped, show a snackbar.
  onTap: () {
    const snackBar = SnackBar(content: Text('Tap'));
    ScaffoldMessenger.of(context).showSnackBar(snackBar);
  },
  // The custom button
  child: Container(
    padding: const EdgeInsets.all(12),
    decoration: BoxDecoration(
      color: Colors.lightBlue,
      borderRadius: BorderRadius.circular(8),
    ),
    child: const Text('My Button'),
  ),
)
```
