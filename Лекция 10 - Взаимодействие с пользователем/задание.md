## Задачи

### 1. Реализовать `SearchScreen`

Откройте `lib/screens/search_screen.dart` и реализуйте поиск по моковым данным:

```dart
class SearchScreen extends StatefulWidget {
  const SearchScreen({super.key});

  @override
  State<SearchScreen> createState() => _SearchScreenState();
}

class _SearchScreenState extends State<SearchScreen> {
  final _controller = TextEditingController();
  List<Movie> _results = [];

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  void _onSearch(String query) {
    setState(() {
      _results = searchByTitle(mockMovies, query);
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: TextField(
          controller: _controller,
          onChanged: _onSearch,
          decoration: const InputDecoration(
            hintText: 'Название фильма...',
            border: InputBorder.none,
          ),
        ),
      ),
      body: ListView.builder(
        itemCount: _results.length,
        itemBuilder: (context, index) => MovieCard(movie: _results[index]),
      ),
    );
  }
}
```

### 2. Создать `AddMovieScreen` с формой

Создайте файл `lib/screens/add_movie_screen.dart`. Форма должна содержать:

| Поле | Тип | Валидация |
|------|-----|-----------|
| Название | `TextFormField` | обязательное, минимум 2 символа |
| Год выпуска | `TextFormField` | обязательное, 4 цифры |
| Описание | `TextFormField` | необязательное |
| Рейтинг | `TextFormField` | число от 0 до 10 |

Оберните поля в `Form` с `GlobalKey<FormState>`:

```dart
final _formKey = GlobalKey<FormState>();

Form(
  key: _formKey,
  child: Column(
    children: [
      TextFormField(
        decoration: const InputDecoration(labelText: 'Название *'),
        validator: (value) {
          if (value == null || value.trim().length < 2) {
            return 'Введите название (минимум 2 символа)';
          }
          return null;
        },
      ),
      // ... остальные поля
      ElevatedButton(
        onPressed: () {
          if (_formKey.currentState!.validate()) {
            // создать Movie и вернуть на предыдущий экран
            Navigator.pop(context, newMovie);
          }
        },
        child: const Text('Добавить фильм'),
      ),
    ],
  ),
)
```

### 3. Добавить кнопку открытия `AddMovieScreen`

На `HomeScreen` добавьте `FloatingActionButton`:

```dart
floatingActionButton: FloatingActionButton(
  onPressed: () async {
    final movie = await Navigator.pushNamed(context, '/add-movie');
    if (movie != null) {
      setState(() => _movies.insert(0, movie as Movie));
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('«${(movie as Movie).title}» добавлен!')),
```
