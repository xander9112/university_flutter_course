# Лекция 14 - Хранение данных на устройстве.

## Работа с файлами (Чтение/запись)

В некоторых случаях вам необходимо читать и записывать файлы на диск. Например, вам может потребоваться сохранять данные при запуске приложения или загружать данные из Интернета и сохранять их для последующего использования в автономном режиме.

Чтобы сохранять файлы на диск в мобильных или настольных приложениях, объедините плагин path_provider с библиотекой dart:io.

Где хранить эти данные? Пакет path_provider предоставляет независимый от платформы способ доступа к часто используемым местам в файловой системе устройства. Плагин в настоящее время поддерживает доступ к двум местоположениям файловой системы: 

Temporary directory. Временный каталог (кеш), который система может очистить в любое время. В iOS это соответствует каталогу NSCachesDirectory. В Android это значение, которое возвращает getCacheDir(). 

Future<String> get _tempPath async {

```dart
  final directory = await getTemporaryDirectory();
  return directory.path;
}
```

Documents directory.  Каталог, в котором приложение может хранить файлы, доступ к которым есть только у него. Система очищает каталог только при удалении приложения. В iOS это соответствует NSDocumentDirectory. В Android это каталог AppData. 

Future<String> get _localPath async {

```dart
  final directory = await getApplicationDocumentsDirectory();
  return directory.path;
}
```

Как только вы узнаете, где хранить файл, создайте ссылку на полное местоположение файла. Для этого вы можете использовать класс File из библиотеки dart:io.

Future<File> get _localFile async {

```dart
  final path = await _localPath;
  return File('$path/counter.txt');
}
```

Теперь, когда у вас есть файл для работы, используйте его для чтения и записи данных. Сначала запишите некоторые данные в файл. 

Future<File> writeData(String data) async {

```dart
  final file = await _localFile;
  // Write the file
  return file.writeAsString(data);
}
```

Теперь, когда у вас есть данные на диске, вы можете их прочитать. Еще раз используйте класс File.

Future<String> readData() async {

```dart
  try {
    final file = await _localFile;
    // Read the file
    final contents = await file.readAsString();
    return contents;
  } catch (e) {
    // If encountering an error, return empty string
    return '';
  }
}
```

Все возможные операции с файловой системой вы можете найти в пакете dart:io 

Стоит не забывать, что в Flutter Web нет прямого доступа к файловой системе и пакет dart:io будет выбрасывать исключения. 

## shared_preferences

shared_preferences это пакет для flutter, который является простым Key-value хранилищем и является по сути оберткой над платформенным реализациями.

Storage location by platform 

Этот пакет применяется повсеместно и пользуется большим спросом из-за своей простоты. Поддерживается flutter.dev командой.

Ниже представлен простой пример использования

Write data

// Obtain shared preferences.

```dart
final SharedPreferences prefs = await SharedPreferences.getInstance();
```

// Save an integer value to 'counter' key.

await prefs.setInt('counter', 10);

// Save an boolean value to 'repeat' key.

await prefs.setBool('repeat', true);

// Save an double value to 'decimal' key.

await prefs.setDouble('decimal', 1.5);

// Save an String value to 'action' key.

await prefs.setString('action', 'Start');

// Save an list of strings to 'items' key.

await prefs.setStringList('items', <String>['Earth', 'Moon', 'Sun']);

Read data

// Try reading data from the 'counter' key. If it doesn't exist, returns null.

```dart
final int? counter = prefs.getInt('counter');
```

// Try reading data from the 'repeat' key. If it doesn't exist, returns null.

```dart
final bool? repeat = prefs.getBool('repeat');
```

// Try reading data from the 'decimal' key. If it doesn't exist, returns null.

```dart
final double? decimal = prefs.getDouble('decimal');
```

// Try reading data from the 'action' key. If it doesn't exist, returns null.

```dart
final String? action = prefs.getString('action');
```

// Try reading data from the 'items' key. If it doesn't exist, returns null.

```dart
final List<String>? items = prefs.getStringList('items');
```

Remove an entry

// Remove data for the 'counter' key.

await prefs.remove('counter');

## работа с SQLite

Если вы пишете приложение, которое должно сохранять и запрашивать большие объемы данных на локальном устройстве, рассмотрите возможность использования базы данных вместо локального файла или хранилища ключей-значений. В целом базы данных обеспечивают более быструю вставку, обновление и запросы по сравнению с другими решениями для локального сохранения.

Приложения Flutter могут использовать базы данных SQLite через подключаемый модуль sqflite, доступный на pub.dev.

Для работы с базами данных SQLite импортируйте пакеты sqflite и path.

Пакет sqflite предоставляет классы и функции для взаимодействия с базой данных SQLite.

Пакет path предоставляет функции для определения места хранения базы данных на диске.

Чтобы добавить пакеты в качестве зависимости, запустите flutter pub add:

flutter pub add sqflite path

В этом уроке попробуем создать базу данных для хранения информации о собаках.

Перед созданием таблицы для хранения информации о собаках уделите несколько минут определению данных, которые необходимо сохранить. В этом примере определите класс Dog, который содержит три элемента данных: уникальный идентификатор, имя и возраст каждой собаки.

```dart
class Dog {
  final int id;
  final String name;
  final int age;
  const Dog({
    required this.id,
    required this.name,
    required this.age,
  });
}
```

Перед чтением и записью данных в базу данных откройте соединение с базой данных. Это включает в себя два шага:

Определите путь к файлу базы данных, используя getDatabasesPath() из пакета sqflite в сочетании с функцией соединения из пакета path.

Откройте базу данных с помощью функции openDatabase() из sqflite.

```dart
final database = openDatabase(
  // Set the path to the database. Note: Using the `join` function from the
  // `path` package is best practice to ensure the path is correctly
  // constructed for each platform.
  join(await getDatabasesPath(), 'doggie_database.db'),
);
```

Затем создайте таблицу для хранения информации о различных собаках. В этом примере создайте таблицу с именем Dogs, определяющую данные, которые можно сохранить. Каждая собака содержит идентификатор, имя и возраст. Поэтому они представлены в виде трех столбцов в таблице собак.

Id представляет собой Dart int и хранится как тип данных INTEGER SQLite. Также рекомендуется использовать идентификатор в качестве первичного ключа для таблицы, чтобы сократить время запроса и обновления.

Name представляет собой строку Dart и хранится как тип данных TEXT SQLite.

Age также является целым числом Dart и хранится как тип данных INTEGER.

```dart
final database = openDatabase(
  // Set the path to the database. Note: Using the `join` function from the
  // `path` package is best practice to ensure the path is correctly
  // constructed for each platform.
  join(await getDatabasesPath(), 'doggie_database.db'),
  // When the database is first created, create a table to store dogs.
  onCreate: (db, version) {
    // Run the CREATE TABLE statement on the database.
    return db.execute(
      'CREATE TABLE dogs(id INTEGER PRIMARY KEY, name TEXT, age INTEGER)',
    );
  },
  // Set the version. This executes the onCreate function and provides a
  // path to perform database upgrades and downgrades.
  version: 1,
);
```

Теперь, когда у вас есть база данных с таблицей, подходящей для хранения информации о различных собаках, пришло время читать и записывать данные.

Сначала вставьте Dog в таблицу dogs. Это включает в себя два шага:

Сконвертитровать Dog в Map

Использовать insert() для сохранения Map с данными в таблицe Dogs

```dart
class Dog {
  final int id;
  final String name;
  final int age;
  const Dog({
    required this.id,
    required this.name,
    required this.age,
  });
  // Convert a Dog into a Map. The keys must correspond to the names of the
  // columns in the database.
  Map<String, dynamic> toMap() {
    return {
      'id': id,
      'name': name,
      'age': age,
    };
  }
  // Implement toString to make it easier to see information about
  // each dog when using the print statement.
  @override
  String toString() {
    return 'Dog{id: $id, name: $name, age: $age}';
  }
}
```

// Define a function that inserts dogs into the database

Future<void> insertDog(Dog dog) async {

```dart
  // Get a reference to the database.
  final db = await database;
  // Insert the Dog into the correct table. You might also specify the
  // `conflictAlgorithm` to use in case the same dog is inserted twice.
  //
  // In this case, replace any previous data.
  await db.insert(
    'dogs',
    dog.toMap(),
    conflictAlgorithm: ConflictAlgorithm.replace,
  );
}
```

// Create a Dog and add it to the dogs table

```dart
var fido = const Dog(
  id: 0,
  name: 'Fido',
  age: 35,
);
```

await insertDog(fido);

Теперь, когда собака хранится в базе данных, запросите в базе данных конкретную собаку или список всех собак. Это включает в себя два шага: 

Запустите запрос к таблице собак, который вернет List<Map>.

Преобразуйте List<Map> в List<Dog>.

// A method that retrieves all the dogs from the dogs table.

Future<List<Dog>> dogs() async {

```dart
  // Get a reference to the database.
  final db = await database;
  // Query the table for all The Dogs.
  final List<Map<String, dynamic>> maps = await db.query('dogs');
  // Convert the List<Map<String, dynamic> into a List<Dog>.
  return List.generate(maps.length, (i) {
    return Dog(
      id: maps[i]['id'],
      name: maps[i]['name'],
      age: maps[i]['age'],
    );
  });
}
```

После вставки информации в базу данных вы, возможно, захотите обновить эту информацию позднее. Вы можете сделать это, используя метод update() из библиотеки sqflite.

Это включает в себя два шага:

Сконвертируйте Dog в Map.

Используйте where, чтобы убедиться, что вы обновляете правильную запись.

Future<void> updateDog(Dog dog) async {

```dart
  // Get a reference to the database.
  final db = await database;
  // Update the given Dog.
  await db.update(
    'dogs',
    dog.toMap(),
    // Ensure that the Dog has a matching id.
    where: 'id = ?',
    // Pass the Dog's id as a whereArg to prevent SQL injection.
    whereArgs: [dog.id],
  );
}
```

Помимо вставки и обновления информации о собаках, вы также можете удалять запись из базы данных. Чтобы удалить данные, используйте метод delete() из библиотеки sqflite.

В этом разделе создайте функцию, которая принимает идентификатор и удаляет собаку с совпадающим идентификатором из базы данных. Чтобы это работало, вы должны указать предложение where, чтобы ограничить количество удаляемых записей.

Future<void> deleteDog(int id) async {

```dart
  // Get a reference to the database.
  final db = await database;
  // Remove the Dog from the database.
  await db.delete(
    'dogs',
    // Use a `where` clause to delete a specific dog.
    where: 'id = ?',
    // Pass the Dog's id as a whereArg to prevent SQL injection.
    whereArgs: [id],
  );
}
```
