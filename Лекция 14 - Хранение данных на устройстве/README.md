# Лекция 14 - Хранение данных на устройстве

Тема лекции — способы локального хранения данных в Flutter-приложениях: файлы, ключ-значение и реляционная база данных.

В лекции рассматривается работа с файлами через пакет path_provider (временный каталог и каталог документов) и класс File из dart:io для чтения и записи данных на диск. Разбирается пакет shared_preferences для хранения простых пар ключ-значение, а также работа с локальной базой данных SQLite через пакет sqflite — создание таблиц, определение моделей данных и выполнение операций вставки, обновления и запросов.
