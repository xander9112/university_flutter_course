# Задание 14 — Хранение данных: SharedPreferences, SQLite и файлы

## Контекст

Продолжаем разработку **CineTrack**. Сейчас при закрытии приложения теряются все данные: список избранных фильмов и личные оценки пропадают, а без сети главный экран показывает только ошибку. В этом задании вы добавите персистентное хранение данных на устройстве тремя способами: тёмную тему и личные оценки (SharedPreferences), избранное в базе данных (SQLite) и кэш последнего ответа API (файл). CineTrack собирается для трёх платформ — Android, iOS и веба, — и всё это должно работать на каждой из них.

### 2. SharedPreferences: сохранение темы приложения

#### 2.1. Создать `ThemeProvider`

Создайте файл `lib/providers/theme_provider.dart`:

```dart
import 'package:flutter/material.dart';
import 'package:shared_preferences/shared_preferences.dart';

class ThemeProvider extends ChangeNotifier {
  static const _key = 'dark_mode';
  bool _isDark = false;

  bool get isDark => _isDark;
  ThemeMode get themeMode => _isDark ? ThemeMode.dark : ThemeMode.light;

  ThemeProvider() {
    _load();
  }

  Future<void> _load() async {
    final prefs = await SharedPreferences.getInstance();
    _isDark = prefs.getBool(_key) ?? false;
    notifyListeners();
  }

  Future<void> toggle() async {
    _isDark = !_isDark;
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(_key, _isDark);
    notifyListeners();
  }
}
```

#### 2.4. Сохранять личные оценки

Оценки из Задания 12 — это словарь «id фильма → оценка», для него тоже хватит `SharedPreferences`. Хранить можно только простые типы, поэтому словарь сохраняется строкой JSON — например, `{"27205": 8.5, "157336": 9.0}` (ключи в JSON всегда строки).

Обновите `lib/providers/ratings_provider.dart`:

```dart
import 'dart:convert';

import 'package:flutter/foundation.dart';
import 'package:shared_preferences/shared_preferences.dart';

class RatingsProvider extends ChangeNotifier {
  static const _key = 'user_ratings';
  final Map<int, double> _ratings = {};

  RatingsProvider() {
    _load();
  }

  Future<void> _load() async {
    final prefs = await SharedPreferences.getInstance();
    final json = prefs.getString(_key);
    if (json == null) return;
    final map = jsonDecode(json) as Map<String, dynamic>;
    _ratings
      ..clear()
      ..addAll(map.map((id, rating) =>
          MapEntry(int.parse(id), (rating as num).toDouble())));
    notifyListeners();
  }

  double? ratingOf(int movieId) => _ratings[movieId];

  Future<void> setRating(int movieId, double rating) async {
    _ratings[movieId] = rating;
    notifyListeners(); // экран обновляется сразу, не дожидаясь записи
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(
      _key,
      jsonEncode(_ratings.map((id, r) => MapEntry(id.toString(), r))),
    );
  }
}
```

Вызов `setRating` на экране деталей не меняется: метод стал асинхронным, но ждать его не нужно — оценка появится на экране сразу.

### 3. SQLite: сохранение избранных фильмов

#### 3.1. Создать `FavoritesDatabase`

Создайте файл `lib/database/favorites_database.dart`:

```dart
import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart';
import '../models/movie.dart';

class FavoritesDatabase {
  static Database? _db;

  static Future<Database> get database async {
    _db ??= await _initDb();
    return _db!;
  }

  static Future<Database> _initDb() async {
    final dbPath = await getDatabasesPath();
    final path = join(dbPath, 'cine_track.db');

    return openDatabase(
      path,
      version: 1,
      onCreate: (db, version) {
        return db.execute('''
          CREATE TABLE favorites (
            id INTEGER PRIMARY KEY,
            title TEXT NOT NULL,
            overview TEXT,
            poster_path TEXT,
            backdrop_path TEXT,
            vote_average REAL,
            release_date TEXT NOT NULL,
            genre_ids TEXT NOT NULL
          )
        ''');
      },
    );
  }

  static Future<void> insert(Movie movie) async {
    final db = await database;
    await db.insert(
      'favorites',
      {
        'id': movie.id,
        'title': movie.title,
        'overview': movie.overview,
        'poster_path': movie.posterPath,
        'backdrop_path': movie.backdropPath,
        'vote_average': movie.voteAverage,
        'release_date': movie.releaseDate,
        // SQLite не хранит списки — сохраняем жанры строкой «28,878,12»
        'genre_ids': movie.genreIds.join(','),
      },
      conflictAlgorithm: ConflictAlgorithm.replace,
    );
  }

  static Future<void> delete(int id) async {
    final db = await database;
    await db.delete('favorites', where: 'id = ?', whereArgs: [id]);
  }

  static Future<List<Movie>> getAll() async {
    final db = await database;
    final maps = await db.query('favorites');
    return maps.map((map) => Movie(
      id: map['id'] as int,
      title: map['title'] as String,
      overview: map['overview'] as String?,
      posterPath: map['poster_path'] as String?,
      backdropPath: map['backdrop_path'] as String?,
      voteAverage: (map['vote_average'] as num?)?.toDouble(),
      releaseDate: map['release_date'] as String,
      genreIds: (map['genre_ids'] as String)
          .split(',')
          .where((s) => s.isNotEmpty)
          .map(int.parse)
          .toList(),
    )).toList();
  }
}
```

#### 3.2. Обновить `FavoritesProvider` для работы с БД

```dart
class FavoritesProvider extends ChangeNotifier {
  List<Movie> _favorites = [];
  List<Movie> get favorites => List.unmodifiable(_favorites);

  FavoritesProvider() {
    _loadFromDb();
  }

  Future<void> _loadFromDb() async {
    _favorites = await FavoritesDatabase.getAll();
    notifyListeners();
  }

  bool isFavorite(int movieId) => _favorites.any((m) => m.id == movieId);

  Future<void> toggleFavorite(Movie movie) async {
    if (isFavorite(movie.id)) {
      await FavoritesDatabase.delete(movie.id);
      _favorites.removeWhere((m) => m.id == movie.id);
    } else {
      await FavoritesDatabase.insert(movie);
      _favorites.add(movie);
    }
    notifyListeners();
  }
}
```

#### 3.3. SQLite в веб-версии

`sqflite` работает через нативный SQLite Android и iOS — в браузере его нет. Если запустить приложение командой `flutter run -d chrome`, первое же обращение к `FavoritesDatabase` упадёт с ошибкой. Для веба есть пакет `sqflite_common_ffi_web`: он запускает SQLite, скомпилированный в WebAssembly, и хранит базу в IndexedDB браузера. Код `FavoritesDatabase` при этом не меняется.

1. Скопируйте в папку `web/` файлы движка — `sqlite3.wasm` и `sqflite_sw.js`:

   ```bash
   dart run sqflite_common_ffi_web:setup
   ```

   Эти файлы — часть приложения, их нужно закоммитить вместе с остальным кодом.

2. В начале `main()` подключите веб-фабрику базы данных:

   ```dart
   import 'package:flutter/foundation.dart';
   import 'package:sqflite/sqflite.dart';
   import 'package:sqflite_common_ffi_web/sqflite_ffi_web.dart';

   void main() {
     if (kIsWeb) {
       // В браузере SQLite работает через WebAssembly и хранит базу в IndexedDB
       databaseFactory = databaseFactoryFfiWeb;
     }

     runApp(/* MultiProvider из задачи 2.2 */);
   }
   ```

   `kIsWeb` равен `true` только в веб-сборке, поэтому на Android и iOS по-прежнему используется стандартный `sqflite`.

### 4. Файлы: кэширование последнего ответа API

Создайте файл `lib/services/cache_service.dart`. При загрузке фильмов из сети — сохраняйте JSON в файл. При ошибке сети — читайте из кэша.

В браузере файловой системы нет: `path_provider` не знает папку документов, а `File` из `dart:io` бросает исключение. Поэтому в веб-версии тот же JSON хранится в `SharedPreferences` — в браузере это `localStorage`:

```dart
import 'dart:io';

import 'package:flutter/foundation.dart';
import 'package:path_provider/path_provider.dart';
import 'package:shared_preferences/shared_preferences.dart';

class CacheService {
  static const _webKey = 'movies_cache';

  static Future<File> _getCacheFile() async {
    final dir = await getApplicationDocumentsDirectory();
    return File('${dir.path}/movies_cache.json');
  }

  static Future<void> saveMovies(String jsonString) async {
    // Кэш — вспомогательная функция: если сохранить не удалось,
    // загрузка фильмов не должна из-за этого ломаться
    try {
      if (kIsWeb) {
        final prefs = await SharedPreferences.getInstance();
        await prefs.setString(_webKey, jsonString);
        return;
      }
      final file = await _getCacheFile();
      await file.writeAsString(jsonString);
    } catch (_) {}
  }

  static Future<String?> loadMovies() async {
    try {
      if (kIsWeb) {
        final prefs = await SharedPreferences.getInstance();
        return prefs.getString(_webKey);
      }
      final file = await _getCacheFile();
      if (await file.exists()) {
        return await file.readAsString(); // await нужен, чтобы ошибку чтения поймал catch
      }
    } catch (_) {}
    return null;
  }
}
```

`try/catch` в `saveMovies` важен: в `getPopularMovies` ниже сохранение кэша стоит внутри `try`, и без него ошибка записи кэша превратила бы успешный ответ сервера в ошибку загрузки.

Обновите `MovieApiService.getPopularMovies()`. Разбор JSON вынесите в отдельный метод — он нужен и для ответа сервера, и для кэша:

```dart
Future<List<Movie>> getPopularMovies({int page = 1}) async {
  try {
    final response = await _send(/* uri из Задания 11 */);
    if (response.statusCode != 200) {
      throw Exception('Ошибка загрузки: ${response.statusCode}');
    }
    await CacheService.saveMovies(response.body); // сохраняем кэш
    return _parseMovies(response.body);
  } catch (e) {
    // при любой ошибке (нет сети или ошибка сервера) — читаем из кэша
    final cached = await CacheService.loadMovies();
    if (cached != null) {
      return _parseMovies(cached);
    }
    rethrow; // кэша нет — пробрасываем ошибку дальше, в MoviesBloc
  }
}

List<Movie> _parseMovies(String body) {
  final data = jsonDecode(body) as Map<String, dynamic>;
  final results = data['results'] as List<dynamic>;
  return results.map((j) => Movie.fromJson(j as Map<String, dynamic>)).toList();
}
```

## Критерии выполнения

- [ ] Тема (светлая/тёмная) сохраняется через `SharedPreferences` и восстанавливается при перезапуске
- [ ] `ThemeProvider` подключён в `MultiProvider`, переключатель темы работает в `AppBar`
- [ ] Личные оценки сохраняются через `SharedPreferences` и восстанавливаются при перезапуске
- [ ] Избранные фильмы сохраняются в SQLite со всеми полями и не теряются при перезапуске
- [ ] `FavoritesProvider` загружает данные из БД при инициализации
- [ ] При отсутствии сети — загружается кэшированный список из файла
- [ ] Кэш обновляется при каждом успешном ответе API
- [ ] Приложение работает на Android, iOS и в браузере: в веб-версии избранное хранится в SQLite через `sqflite_common_ffi_web`, а кэш — в `SharedPreferences`; всё сохраняется после перезагрузки страницы
