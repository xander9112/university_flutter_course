## Задание 1 — Функция приветствия

- Если возраст указан, возвращать `'Привет, Имя! Тебе age лет.'`

**Пример вывода:**
```
Привет, Анна!
Привет, Борис! Тебе 21 лет.
Привет, Виктор! Тебе 35 лет.
```

**Подсказка:**
```dart

  // используйте тернарный оператор или if/else
}
```

## Задание 2 — FizzBuzz

Напишите функцию `fizzbuzz(int n)`, которая выводит числа от `1` до `n`, но:
- вместо числа, **кратного 3**, выводит `'Fizz'`
- вместо числа, **кратного 5**, выводит `'Buzz'`
- вместо числа, **кратного и 3, и 5**, выводит `'FizzBuzz'`
- во всех остальных случаях выводит само число

Вызовите `fizzbuzz(20)`.

**Ожидаемый вывод (первые строки):**
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
...
```

**Подсказка:** Проверку на кратность и 3, и 5 ставьте **первой** в цепочке `if/else if`. Используйте оператор `%` для проверки на кратность.

## Задание 3 — Фильтрация списка

Создайте список `List<String>` из **5 названий фильмов** (придумайте сами или используйте реальные). Отфильтруйте из него только те названия, длина которых **больше 8 символов**, используя метод `.where()`. Выведите отфильтрованный список.

**Требования:**
- Список должен содержать ровно 5 названий.
- Среди них должны быть как короткие (≤ 8 символов), так и длинные (> 8 символов), чтобы фильтрация была заметна.
- Используйте `.where()` и `.toList()`.
- Выведите исходный список и отфильтрованный.

**Пример:**
```dart
List<String> movies = ['Дюна', 'Интерстеллар', 'Оно', 'Начало', 'Властелин колец'];
// 'Дюна' — 4 символа, не пройдёт
// 'Интерстеллар' — 12 символов, пройдёт
// ...
```

**Пример вывода:**
```
Все фильмы: [Дюна, Интерстеллар, Оно, Начало, Властелин колец]
Длинные названия: [Интерстеллар, Властелин колец]
```

## Задание 4 — Рейтинги фильмов

Создайте `Map<String, double>`, где ключи — названия фильмов, а значения — их рейтинги (числа от 0.0 до 10.0). Добавьте минимум **5 записей**. Выведите только те фильмы, у которых рейтинг **выше 8.0**.

**Требования:**
- В словаре должны быть фильмы с рейтингом > 8.0 и с рейтингом ≤ 8.0 — чтобы фильтрация была видна.
- Используйте цикл `forEach` или `for (var entry in map.entries)`.
- Вывод: строка вида `'Название: X.X'` для каждого подходящего фильма.

**Пример вывода:**
```
Фильмы с рейтингом выше 8.0:
Побег из Шоушенка: 9.3
Зелёная миля: 8.6
Интерстеллар: 8.7
```

## Задание 5 — Максимальный элемент с Null Safety

Напишите функцию `findMax`, которая принимает список целых чисел и возвращает **максимальный элемент**. Если список пустой — функция должна вернуть `null`.

**Требования:**
- Сигнатура: `int? findMax(List<int> numbers)`
- Нельзя использовать встроенный метод `.reduce()` или `.fold()` — реализуйте поиск максимума через цикл вручную.
- Правильно обрабатывайте пустой список (возврат `null`).
- Вызовите функцию минимум **три раза**: с непустым списком, с другим непустым списком, с пустым списком.
- Используйте оператор `??` при выводе результата.

**Пример вывода:**
```
Максимум [3, 7, 1, 9, 4]: 9
Максимум [-5, -2, -8]: -2
Максимум []: список пустой
```

**Подсказка:**
```dart
int? findMax(List<int> numbers) {
  if (numbers.isEmpty) {
    return null;
  }
  int max = numbers[0];
  for (int number in numbers) {
    // сравните number с max и обновите max если нужно
  }
  return max;
}
```
