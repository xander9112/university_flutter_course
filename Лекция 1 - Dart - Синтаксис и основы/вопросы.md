# Вопросы — Лекция 1: Dart — синтаксис и основы

---

1. В чём главное отличие `final` от `const`?

   a) `final` нельзя переприсвоить, а `const` можно
   b) `const` используется только для строк
   c) ✓ `final` получает значение во время выполнения программы, а `const` — во время компиляции
   d) Разницы нет, это синонимы

---

2. Какой синтаксис используется для интерполяции **выражения** (не просто переменной) в строку?

   a) `"Результат: #(a + b)"`
   b) `"Результат: @{a + b}"`
   c) `"Результат: $(a + b)"`
   d) ✓ `"Результат: ${a + b}"`

---

3. Что вернёт выражение `17 ~/ 5`?

   a) `3.4`
   b) `2`
   c) ✓ `3`
   d) `0.4`

---

4. Как правильно объявить функцию с **именованным** обязательным параметром `title` типа `String`?

   a) `void show(String title)`
   b) `void show([String title])`
   c) `void show(<String title>)`
   d) ✓ `void show({required String title})`

---

5. В чём ключевое отличие `Set` от `List`?

   a) `Set` хранит только числа, а `List` — строки
   b) В `Set` можно хранить не более 10 элементов
   c) `List` не поддерживает перебор в цикле, а `Set` поддерживает
   d) ✓ `Set` автоматически удаляет повторяющиеся элементы, `List` допускает дубликаты

---

6. Что делает оператор `??`?

   a) Проверяет, равны ли два значения
   b) Выполняет целочисленное деление
   c) ✓ Возвращает левый операнд, если он не `null`, иначе — правый
   d) Вызывает метод только если объект не `null`

---

7. Что означает тип возвращаемого значения `void` у функции?

   a) Функция возвращает пустую строку `""`
   b) Функция возвращает `null`
   c) Функция возвращает `0`
   d) ✓ Функция ничего не возвращает — она только выполняет действия

---

8. Какой цикл используется для перебора **каждого элемента** коллекции (например, `List<String>`)?

   a) `while (list)`
   b) `do { } while (list)`
   c) ✓ `for (String item in list)`
   d) `for (list; item; next)`
